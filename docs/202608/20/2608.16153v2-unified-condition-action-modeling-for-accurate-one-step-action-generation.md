## Abstract
Robot manipulation requires policies that are both accurate and efficient, as robot control must respond to changing observations under tight latency constraints. Recent diffusion and flow policies are promising, but they often treat conditions as auxiliary signals rather than jointly evolving them with action trajectories. We find that this limitation can be effectively mitigated by a \textbf{simple yet effective unified condition-action modeling design} that represents conditions and actions in a shared token space, allowing a compact model to achieve high performance while improving both inference speed and accuracy. Therefore, we propose UCA-Flow, a unified condition-action modeling framework for accurate one-step action generation. Our method unifies observation conditions, timestep conditions, interval conditions, and action tokens into a single sequence, and processes them with a Unified Condition-Action Transformer for joint condition-action representation learning. As a result, condition representations are dynamically reconstructed according to the current generation stage, highlighting information most relevant for action refinement. Furthermore, we introduce an improved dual-pass supervision scheme over $u$ and $v$ for stronger optimization of unified condition-action modeling. UCA-Flow improves the average success rate by 9.3 percentage points over the strongest baseline, while achieving $45.6\times$ and $33.4\times$ speedups over DP3 and Simple DP3, and remaining $4.3\times$ and $2.3\times$ faster than one-step FlowPolicy and MP1, respectively.

# UCA-Flow：统一条件-动作建模实现一步式动作生成——论文深度解析

## 1. 核心问题与整体含义（研究动机与背景）

机器人操作（Robot Manipulation）要求策略在**极低延迟约束**下，从复杂观测中准确生成可执行动作，用于抓取、推挤、装配、工具使用等物理交互任务。现有生成式机器人策略（如扩散策略、流匹配、MeanFlow）虽展现出强大潜力，但面临一个关键瓶颈：

- **效率-性能困境**：扩散策略依赖多次迭代采样，推理延迟高；而流匹配等改进虽实现了少步或一步生成，却往往以牺牲精度为代价。
- **条件注入瓶颈**：现有方法普遍遵循“条件→动作”范式（condition-to-action），将观测、时间步等条件编码为**外部辅助信号**，通过调制（如 AdaLN、Cross-Attention）注入动作生成骨干网络。条件不参与动作轨迹的演化过程，阻碍了条件与动作的联合表示学习，尤其限制了一步式生成器的精度上限。

论文的核心洞见是：**将条件与动作统一到共享 token 空间，使其在 Transformer 中联合演化**，可以同时突破精度与效率瓶颈。

## 2. 方法论：核心思想、关键技术细节

### 2.1 总体框架

UCA-Flow 采用 MeanFlow 作为生成目标。令专家动作轨迹为 $x \in \mathbb{R}^{T \times d_a}$，噪声为 $\epsilon \sim \mathcal{N}(0, I)$，定义插值轨迹：

$$z_t = (1-t)x + t\epsilon, \quad t \in [0,1]$$

瞬时速度为 $v = \epsilon - x$。模型学习区间感知的平均速度 $u_\theta(z_t, t, h, o)$，其中 $h = t - r$ 为间隔长度。推理时只需**一步**：从 $z_1 = \epsilon$ 出发，预测 $\hat{x} = z_1 - u_\theta(z_1, 1, 1, o)$。

### 2.2 统一条件-动作 Tokenization

UCA-Flow 将四类信息映射到统一的 token 序列：

- **观测条件 token**：点云特征 $p_i$ 与机器人状态特征 $s_i$ 拼接后经 MLP 投影，加上可学习的位置编码 $c_i = \phi_o([p_i; s_i]) + e_o^i$；
- **时间步条件 token**：通过正弦位置编码与可学习 MLP 得到 $\tau_j = \phi_t(\text{PE}(t)) + b_t^j$（共 $N_t$ 个）；
- **间隔条件 token**：类似地得到 $\eta_j = \phi_h(\text{PE}(h)) + b_h^j$（共 $N_h$ 个）；
- **动作 token**：将噪声动作轨迹逐时间步投影 $y_k = \phi_a(z_{t,k}) + e_a^k$。

统一输入序列为：

$$S_0 = [\underbrace{c_1, c_2, \tau_1, \ldots, \tau_{N_t}, \eta_1, \ldots, \eta_{N_h}}_{\text{条件 token 序列 } P}, \underbrace{y_1, \ldots, y_T}_{\text{动作 token 序列 } Y}]$$

### 2.3 统一条件-动作交互

序列经 **L 层 Unified Condition-Action Transformer** 块处理，每层通过自注意力与 FFN **同时更新条件 token 与动作 token**：

$$[P^{\ell+1}_{t,h,o}, Y^{\ell+1}] = \text{UCT}^{\ell}\left([P^{\ell}_{t,h,o}, Y^{\ell}]\right)$$

这种设计的关键优势在于形成 **动作→条件→动作** 的信息路径：条件 token 在每一层吸收当前动作状态的信息，动态重构条件表示，后续层的动作 token 再关注这些“动作感知”的条件表示，实现联合优化。最终仅保留动作 token 输出，通过输出头 $\psi(\cdot)$ 预测速度轨迹：

$$u_\theta(z_t, t, h, o) = \psi(Y^L)$$

### 2.4 双通道监督（Dual-Pass Supervision）

为增强训练稳定性与一步生成精度，引入双前向通道监督：

1. **第一通道**：设置 $h=0$，预测瞬时速度 $v_\theta = u_\theta(z_t, t, 0, o)$；
2. **第二通道**：使用采样的间隔 $h$，预测区间平均速度 $u_\theta(z_t, t, h, o)$；
3. 通过 Jacobian-vector product 构造复合速度：

$$D_t u_\theta = \nabla_z u_\theta \cdot \text{sg}(v_\theta) + \partial_t u_\theta + \partial_h u_\theta$$

$$V_\theta = u_\theta + h \cdot \text{sg}(D_t u_\theta)$$

4. 损失函数为两个速度视图与同一目标速度 $v$ 之间的自适应加权 L2 损失：

$$\mathcal{L} = \rho(V_\theta - \text{sg}(v)) + \rho(v_\theta - \text{sg}(v))$$

其中 $\rho(\Delta) = \text{sg}\left(\frac{1}{(\|\Delta\|_2^2 + c)^{1-\gamma}}\right) \|\Delta\|_2^2$。

推理时**仅需一次前向传播**，双通道仅为训练策略，不增加推理成本。

## 7. 方法亮点

- **设计简洁而有效**：仅通过统一 token 序列的设计即可带来显著提升，无需复杂架构或额外的推理成本；
