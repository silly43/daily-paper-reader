## 摘要
遥感基础模型提供跨传感器、分辨率和地理区域的可迁移地球观测表示，但大多数模型与自然语言的对齐仍然较弱，限制了自然语言档案检索、图像-文本检索和基于问题的分析。我们提出AlignJEPA，一个受JEPA启发的预测性视觉-语言对齐框架，用于遥感基础模型。AlignJEPA使用预训练的AnySat视觉编码器和RemoteCLIP文本编码器，同时仅训练一个轻量级的预测性对齐网络。该框架不依赖于全局图像-文本对比对齐，而是从遮蔽的视觉基础模型标记中预测遥感文本嵌入。其掩码感知的多尺度预测对齐器在细粒度、区域和全局尺度上聚合可见标记，通过跨尺度Transformer联合建模，并使用学习到的查询池化将所得表示投影到文本空间。训练结合了语义预测与双向对比检索。我们在BigEarthNet.txt上训练和评估AlignJEPA以进行自然语言Sentinel检索，在RSICD上评估跨数据集适应性，并将RSVQA仅用作闭集表示探针。AlignJEPA为将地球观测基础模型与语言对齐提供了一条参数高效的路径。

## Abstract
Remote sensing (RS) foundation models provide transferable Earth observation representations across sensors, resolutions, and geographies, yet most remain weakly aligned with natural language, limiting natural-language archive search, image-text retrieval, and question-conditioned analysis. We propose AlignJEPA, a JEPA-inspired predictive vision-language alignment framework for remote sensing foundation models. AlignJEPA uses a pretrained AnySat visual encoder and a RemoteCLIP text encoder while training only a lightweight predictive alignment network. Instead of relying on global image--text contrastive alignment alone, the framework predicts remote-sensing text embeddings from masked visual foundation-model tokens. Its mask-aware multi-scale predictive aligner aggregates visible tokens at fine, regional, and global scales, jointly models them with a cross-scale Transformer, and projects the resulting representation into the text space using learned query pooling. Training combines semantic prediction with bidirectional contrastive retrieval. We train and evaluate AlignJEPA on BigEarthNet.txt for natural-language Sentinel retrieval, evaluate cross-dataset adaptation on RSICD, and use RSVQA only as a closed-set representation probe. AlignJEPA provides a parameter-efficient route for aligning Earth observation foundation models with language.

### 2. 方法论

#### 2.1 核心思想

AlignJEPA 采用 JEPA（联合嵌入预测架构）的预测式学习理念，但**改变了预测目标空间**：不再从可见上下文预测缺失的视觉潜在表示（如I-JEPA），而是从**部分可见的EO视觉token**预测一个**冻结的遥感文本嵌入**。这使模型在语言语义层面学习对齐，而非像素级重建。

#### 2.2 问题形式化

给定图像-文本对 $(x, t)$：

- **视觉编码器** $E_v$（AnySat）提取空间视觉token：
  $$Z_v = E_v(x), \quad Z_v \in \mathbb{R}^{B \times N \times D_v}$$

- **文本编码器** $E_t$（RemoteCLIP）生成L2归一化文本嵌入：
  $$z_t = E_t(t), \quad z_t = \frac{z_t}{\|z_t\|_2}$$

- **预测目标**：学习预测器 $P_\theta$，从可见token子集（由掩码指示 $\Omega_c$）预测文本空间表示：
  $$\hat{z}_{v \to t} = P_\theta(Z_v, \Omega_c)$$

#### 2.3 关键组件

| 组件 | 说明 |
|---|---|
| **Token投影** | 线性层 + LayerNorm + 非线性激活，将视觉token投影到统一隐藏维度 $D$ |
| **视觉掩蔽** | 默认随机掩蔽50%的token，保留可见token用于预测 |
| **掩码感知多尺度上下文** | 构建三个尺度的表示：<br>• **细粒度**：可见token本身 $H_F$<br>• **区域级**：对每个非重叠2×2区域，用掩码感知池化聚合可见token：$$h_r^R = \frac{\sum_{i \in r} m_i h_i}{\sum_{i \in r} m_i + \epsilon}$$<br>• **全局级**：所有可见token的加权池化：$$h_G = \frac{\sum_{i=1}^{N} m_i h_i}{\sum_{i=1}^{N} m_i + \epsilon}$$ 掩码token不参与池化，防止信息泄漏 |
| **跨尺度Transformer** | 共享轻量Transformer编码器，联合建模三种尺度间的交互 |
| **学习查询池化** | 使用一个与输入caption无关的可学习查询向量，通过注意力机制池化为单一表示 |
| **文本空间投影** | 将池化表示投影到RemoteCLIP文本维度并L2归一化 |

#### 2.4 训练目标

训练损失由两部分组成：

- **语义预测损失**（余弦距离）：
  $$L_{pred} = \frac{1}{B} \sum_{i=1}^{B} \left(1 - \hat{z}_{v \to t,i}^{\top} z_{t,i}\right)$$

- **双向对比检索损失**（多正样本InfoNCE）：
  $$S_{ij} = \frac{\hat{z}_{v \to t,i}^{\top} z_{t,j}}{\tau}, \quad L_{con} = \frac{1}{2}(L_{v2t} + L_{t2v})$$

- **总损失**：
  $$\mathcal{L} = L_{pred} + \lambda L_{con}, \quad \lambda = 1.0, \tau = 0.07$$

#### 2.5 与现有方法的区别

- **vs. CLIP式全局对齐**：AlignJEPA 增加掩蔽预测机制，利用多尺度可见上下文推断语言语义，而非仅依赖全局对比。
- **vs. 传统JEPA（I-JEPA/V-JEPA）**：预测目标为冻结文本嵌入而非缺失视觉潜在表示，实现了跨模态预测对齐。

### 6. 主要结论与发现

1. **全模型显著优于所有基线**：在BigEarthNet.txt检索中，AlignJEPA的T2I R@1达到20.72%，I2T R@1达到21.89%，超过AnySat+对比对齐约4个百分点，超过RemoteCLIP/GeoRSCLIP zero-shot约7-8个百分点。
2. **掩蔽预测与对比学习互补**：仅用预测损失或仅用对比损失的效果均不如两者结合。预测-only优于对比-only，说明JEPA式语义预测在语言对齐中具有独立价值。
3. **中等掩蔽比例最优**：0.5随机掩蔽优于无掩蔽和0.75高掩蔽。适度的掩蔽迫使模型从分布式上下文证据中推断语义，而非依赖少量判别性局部token。
4. **多尺度设计有效**：多尺度预测器+学习查询池化优于线性投影、MLP和均值池化，证明掩码感知的层次化上下文聚合对语言对齐有贡献。
5. **跨数据集适应可行**：从BigEarthNet.txt（Sentinel多光谱）到RSICD（RGB航空图）的参数高效适应有效，R@1达到16.49%（T2I）和23.41%（I2T），说明AnySat的统一视觉表示具备跨传感泛化能力。
6. **表示质量提升**：在RSVQA探测中，AlignJEPA学习到的图像侧表示携带更丰富的语言条件信息，平均准确率超过AnySat和对比对齐基线。

### 7. 优点

- **参数高效**：仅训练约20M参数的轻量对齐网络，视觉和文本编码器完全冻结，大幅降低训练成本，适合遥感领域"编码器预训练昂贵"的现实约束。
- **范式创新**：将JEPA的预测式学习思想从视觉域迁移至视觉-语言对齐，预测目标是冻结的文本嵌入而非缺失视觉潜在表示，兼具自监督预测与跨模态语义对齐的优势。
- **掩码感知的多尺度设计**：精细token、区域池化、全局池化三层次互补，且掩码token不参与粗粒度池化，防止信息泄漏，设计严谨。
- **损失函数互补性**：语义预测损失（拉近预测与目标嵌入）与双向对比损失（增强检索判别力）相互补充，消融验证了这一组合的必要性。
- **任务覆盖全面**：同时验证了检索（Sentinel + RGB航空）、跨数据集适应、语言条件预测三类能力，结论具有一定普适性。
- **实验设计规范**：BigEarthNet.txt按图像级切分防止数据泄漏；RSVQA明确区分"表示探测"与"生成式VQA"，定位清晰，避免过度宣称。

### 8. 不足与局限

- **依赖冻结目标空间**：RemoteCLIP文本空间是固定的，AlignJEPA本质上是跨模态表示映射，不具组合式语言推理能力，其语义表达上限受限于RemoteCLIP嵌入空间的质量和范畴。
- **监督范围有限**：仅使用BigEarthNet.txt的图像-caption对（不使用VQA和引用表达标注），文本多样性有限，可能无法充分覆盖真实应用中的复杂自然语言查询。
- **域偏移问题**：RSICD实验结果虽优于基线，但整体绝对数值仍偏低，说明跨传感器/风格迁移仍然面临挑战，尤其从Sentinel-2多光谱到RGB航空图像时。
- **RSVQA定位局限**：RSVQA仅作为闭集表示探针，不构成生成式VQA能力证据。评估仅使用轻量分类头，与真实问答场景仍有距离。
- **缺乏更大规模文本基准验证**：未在GeoRSCLIP等更大规模数据集上训练或评测，也未验证在更长文本、引用表达或细粒度指代任务上的表现。
- **无定性分析**：缺少对失败案例、掩蔽模式可视化、检索结果定性展示，影响对方法行为的深入理解。
- **消融范围仍可扩展**：未测试不同冻结编码器组合（如用Prithvi-EO-2.0替换AnySat）、不同目标文本空间（如GeoRSCLIP替换RemoteCLIP）对结果的影响。
