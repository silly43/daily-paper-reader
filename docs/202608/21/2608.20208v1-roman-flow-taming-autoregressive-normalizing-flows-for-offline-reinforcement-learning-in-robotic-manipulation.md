## 摘要
离线强化学习利用先前收集的数据来改进机器人策略，无需进一步的环境交互。然而，流行的扩散和流匹配机器人策略缺乏可处理的似然性，限制了它们在基于似然的离线强化学习后训练中的应用。自回归归一化流（AR-NFs）既能提供表达力强的动作建模，又能进行精确的似然评估，但其顺序采样在策略优化和部署期间会产生大量的采样开销。我们提出了RoMAN-Flow（基于自回归归一化流的机器人操作），这是一个离线强化学习框架，通过解决这两个阶段的采样瓶颈，使AR-NF策略在机器人操作中变得实用。在策略优化期间，RoMAN-Flow采用一种无采样的、优势加权的似然目标，在不从自回归策略采样的情况下，为离线数据集中高优势的动作分配更高的似然。为了实现高效部署，它将优化后的自回归策略蒸馏为单步动作生成器，从而实现低延迟的动作预测。在多个模拟操作基准和真实机器人平台上的实验表明，RoMAN-Flow在显著降低推理延迟的同时，实现了具有竞争力的策略性能。代码可在https://github.com/konnyaku28/RoMAN-Flow获取。

## Abstract
Offline reinforcement learning improves robotic policies using previously collected data without further environment interaction. Yet prevalent diffusion- and flow-matching robot policies lack tractable likelihoods, limiting their use in likelihood-based offline RL post-training. AR-NFs offer both expressive action modeling and exact likelihood evaluation, but their sequential sampling incurs substantial sampling overhead during policy optimization and deployment. We present RoMAN-Flow (Robotic Manipulation with Autoregressive Normalizing Flows), an offline reinforcement learning framework that makes AR-NF policies practical for robotic manipulation by addressing this sampling bottleneck in both stages. During policy optimization, RoMAN-Flow employs a sampling-free, advantage-weighted likelihood objective that assigns higher likelihood to high-advantage actions from the offline dataset without sampling from the autoregressive policy. For efficient deployment, it distills the optimized autoregressive policy into a one-step action generator, enabling low-latency action prediction. Experiments across multiple simulated manipulation benchmarks and real-world robotic platforms demonstrate that RoMAN-Flow achieves competitive policy performance while substantially reducing inference latency. Code is available at https://github.com/konnyaku28/RoMAN-Flow.

## 1. 核心问题与整体含义

RoMAN-Flow 解决的是**机器人操作中离线强化学习（Offline RL）策略后训练的效率与可似然性问题**。背景如下：

- 离线 RL 可以通过固定数据集优化策略，无需与环境交互，非常适合机器人策略后训练。
- 当前主流的机器人策略（如 Diffusion Policy、π0 等扩散/流匹配策略）虽然表达力强，但**无法提供低成本的精确条件动作似然**，难以直接进行基于似然的离线优化。
- 自回归归一化流（AR-NF）既能建模复杂连续动作分布，又能提供**可精确计算的似然**，但其生成过程是逐位置自回归的，导致**训练阶段和部署阶段的采样开销都很大**。

RoMAN-Flow 的核心目标就是：**让 AR-NF 策略在离线 RL 后训练和实际部署中变得实用**，同时保留其表达力与精确似然的优势。

## 2. 论文提出的方法论

### 2.1 整体思想

RoMAN-Flow 采用“两阶段解耦”策略：

1. **训练阶段**：利用 AR-NF 前向变换的并行性，直接在离线数据集上做**免采样的优势加权似然优化**，避免从自回归策略中采样。
2. **部署阶段**：将训练好的 AR-NF 策略**蒸馏为一步生成器**，消除自回归逆变换带来的推理延迟。

### 2.2 AR-NF 策略结构

- 以 **SimFlow** 为骨干，构建条件 AR-NF，将动作块 $a_t$ 映射为隐变量 $z_t$。
- 使用预训练的视觉-语言模型（如 SmolVLM）作为多模态编码器，将视觉、语言和本体感觉编码为上下文 token $C_t$。
- 每个流模块使用 Transformer 和前缀因果掩码，预测仿射变换参数：
$$(\mu_{t,j}^{(l)}, s_{t,j}^{(l)}) = T_l(C_t, h_{t,<j}^{(l-1)})$$
- 前向变换为：
$$h_{t,j}^{(l)} = (h_{t,j}^{(l-1)} - \mu_{t,j}^{(l)}) \odot \exp(-s_{t,j}^{(l)})$$
- 由于雅可比矩阵为三角阵，精确条件对数似然为：
$$\log \pi_\theta(a_t | c_t) = \log p_0(z_t) - \sum_{l=1}^{L}\sum_{j=1}^{H} s_{t,j}^{(l)}$$

### 2.3 NF-IQL 后训练

NF-IQL 基于 IQL（Implicit Q-Learning）框架，包含两个部分：

1. **Chunk 级价值学习**：使用多个 Critic 网络（Chunk Transformer）以因果掩码方式同时输出所有动作前缀的 Q 值；目标值由前缀内折扣回报与后续状态值 bootstrap 构成：
$$y_{t,j} = \sum_{i=0}^{j}\gamma^i r_{t+i} + \gamma^{j+1} \mathrm{sg}[V_\phi(c_{t+j+1})]$$
   状态值函数通过 expectile 回归学习：
$$\mathcal{L}_V = \mathbb{E}\left[\rho_\tau\left(\mathrm{sg}[\bar{Q}_{\bar{\omega}}(c_t,a_t)] - V_\phi(c_t)\right)\right]$$

2. **免采样优势加权似然优化**：优势定义为：
$$A_t = \bar{Q}_{\bar{\omega}}(c_t, a_t) - V_\phi(c_t), \quad w_t = \exp(\beta A_t)$$
   策略更新为：
$$\mathcal{L}_\pi = -\mathbb{E}_{(c_t,a_t)\sim D_H}\left[\mathrm{sg}[w_t]\log \pi_\theta(a_t|c_t)\right]$$
   由于优化目标只依赖离线数据中的动作块，整个过程**不需要从当前策略采样**，避免了 AR-NF 自回归逆变换带来的开销。

### 2.4 一步蒸馏

- 将 NF-IQL 训练好的 AR-NF 作为教师，蒸馏为双向 Transformer 学生。
- 学生输入隐变量 $z_t$，并行输出整段动作块和中间状态。
- 损失包含两部分：
  - **数据诱导轨迹蒸馏**：对离线动作加高斯扰动，对齐教师和学生中间状态及最终动作。
  - **先验采样轨迹蒸馏**：从标准高斯先验采样隐变量，用教师解码生成轨迹，再让学生对齐。
- 总损失为：
$$\mathcal{L}_{\text{distill}} = \mathcal{L}_{\text{data}} + \lambda_p \mathcal{L}_{\text{prior}}$$

1. **NF-IQL 能有效提升策略性能**：
   - MetaWorld-MT50：平均成功率从 IL 的 72.8% 提升到 81.1%，在 Medium/Hard/Very Hard 上提升明显。

   - 真实机器人：从 57.3% 提升到 81.5%，提高 24.2 个百分点。

2. **RoMAN-Flow 达到或超越强基线**：
   - MetaWorld 上 NF-IQL 超过使用在线交互的 π0+Flow-SDE 3.0 个百分点。

4. **AR-NF 策略容量需要足够大**：
   - 在 RoboMimic Square-MH 上，S/B/L 规模（33.8M–466.2M 参数）成功率均为 77%–78%，扩展到 XL（685.5M）后才提升至 85%，表明足够大的容量对精细操作很重要。

## 7. 优点

- **方法设计巧妙**：利用 AR-NF“前向并行、逆向串行”的不对称性，在训练阶段彻底避开自回归采样，是一大亮点。
- **免采样离线 RL**：NF-IQL 在离线数据上直接做优势加权似然优化，为 AR-NF 政策提供了高效的 RL 后训练途径。
- **训练/部署两段式加速**：训练端免采样、部署端蒸馏，两头都解决了 AR-NF 的瓶颈。
- **验证充分**：在模拟多基准和真实机器人上均进行了验证，并且与多个 SOTA 方法进行了对比。
- **开源**：提供了代码，便于复现。
- **模型与推理效率平衡**：蒸馏学生参数量更少（0.56B vs 1.45B），同时保持较高性能，说明其具有工程实用潜力。
