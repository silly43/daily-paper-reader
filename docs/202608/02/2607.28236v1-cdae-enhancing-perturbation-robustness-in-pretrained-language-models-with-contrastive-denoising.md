## 摘要
预训练语言模型显著提升了句子表示学习，然而它们的嵌入对同义词替换、掩码和词丢弃等保留语义的文本扰动仍然敏感。本工作提出了一种轻量级对比去噪自编码器（CDAE），通过联合优化对比学习与重构目标来改进预训练 BERT 嵌入，从而学习扰动不变的表示。我们使用多种强度不同的扰动策略对所提框架进行评估，并将其与原始 BERT 嵌入和 SimCSE 进行比较。实验结果表明，CDAE 在扰动下始终能保持更高的嵌入相似度，随着框架有效增强表示稳定性并保留语义信息，其改进效果愈发显著，这凸显了扰动不变学习作为改进句子嵌入的一个有前景的方向。源代码公开于：https://github.com/ComputationIASBS/CDAE

## Abstract
Pre-trained language models have significantly improved sentence representation learning, yet their embedding remain sensitive to semantic preserving textual perturbations such as synonym substitution, masking and word dropout. This work proposes a lightweight Contrastive Denoising Autoencoder (CDAE) that refines pre-trained BERT embedding by jointly optimizing contrastive and reconstruction objective to learn perturbation-invariant representation. We evaluate the proposed framework using multiple perturbation strategies with varying strengths and compare it against the original BERT embeddings and SimCSE. Experimental results show that CDAE consistently preserves higher embedding similarity under perturbations, with the improvements becoming more pronounced as framework effectively enhances representation stability while preserving semantic information, highlighting perturbation-invariant learning as a promising direction for improving sentence embeddings. The source code is publicly available at: https://github.com/ComputationIASBS/CDAE

## 1. 论文的核心问题与整体含义

- **研究背景**：预训练语言模型（如 BERT）生成的句子嵌入在语义相似度计算、信息检索、推荐系统等下游任务中至关重要。然而，现有研究表明，这些嵌入对**语义保持型扰动**（如近义词替换、掩码、词丢弃）非常敏感——输入句子的微小自然变化会导致嵌入向量发生较大偏移，这与模型"语义理解"的目标相悖。
- **核心问题**：作者强调"扰动"（perturbation）与"对抗攻击"（adversarial attack）的本质区别——前者是语言本身固有的自然变化，而非恶意构造的输入。现有研究大多聚焦于提升语义对齐、下游任务性能或对抗鲁棒性，而对**自然语义保持扰动下的表示稳定性**关注不足。
- **研究意义**：如果句子嵌入在微小语义变化下不稳定，将直接影响下游任务的可靠性。因此，学习**扰动不变（perturbation-invariant）表示**具有重要的理论价值和实践意义，可以作为改进句子嵌入的一个新方向。

## 2. 论文提出的方法论

### 核心思想

提出一种**轻量级对比去噪自编码器（CDAE）**，在**冻结的预训练 BERT 编码器之上**训练一个小型细化网络，联合优化对比学习目标与重建目标，使学到的低维潜在表示对语义保持扰动具有不变性，同时保留原嵌入的语义信息。

### 技术细节与流程

1. **扰动句子生成**：对每个句子 $s_i^o$，使用三种扰动策略生成对应变体 $s_i^p$：
   - **同义词替换**（Synonym Replacement）：基于 WordNet 和 POS 标注，替换内容词（名词、动词、形容词、副词）；
   - **词丢弃**（Word Dropout）：独立删除内容词；
   - **掩码**（Masking）：将内容词替换为 `[MASK]` token。
   - 每种策略由强度参数 $\rho \in [0,1]$ 控制扰动程度。

2. **句子嵌入**：使用冻结的 `bert-base-uncased` 作为骨干编码器，对句子 $s$ 通过均值池化得到 768 维嵌入：
   $$z = \text{BERT}(s) = \frac{\sum_{j=1}^{L} m_j \cdot h_j}{\sum_{j=1}^{L} m_j}$$
   其中 $h_j$ 是 token $j$ 的上下文表示，$m_j$ 是注意力掩码。骨干参数全部冻结，$z$ 作为固定输入特征。

3. **CDAE 架构**：
   - **编码器**：MLP，隐层维度 $512 \rightarrow 256$，每层后接批归一化、ReLU、Dropout（$p=0.30$），最终投影到 **128 维潜在空间**（$\bar{z}_i = \text{Enc}(z_i;\phi) \in \mathbb{R}^{128}$）。最后一层无激活函数（因使用 InfoNCE 损失直接基于 $z_i$）。
   - **解码器**：与编码器镜像对称，$256 \rightarrow 512$，将潜在码映射回 768 维空间。

4. **损失函数**：
   - **对比损失（InfoNCE）**：在一个批次中，将句子 $i$ 的扰动视图与其原始视图视为正对，批次中其他所有句子（包括干净和扰动视图）为负例，计算对称 InfoNCE 损失：
     $$L_{\text{contrast}} = -\frac{1}{2}\left[ \frac{1}{B}\sum_{i=1}^{B} \log \frac{\exp(\text{logits}_{ii})}{\sum_{j=1; j\neq i}^{B} \exp(\text{logits}_{ij})} + \frac{1}{B}\sum_{i=1}^{B} \log \frac{\exp(\text{logits}_{ii})}{\sum_{j=1; j\neq i}^{B} \exp(\text{logits}_{ji})} \right]$$
     其中 $\text{logits}_{ij} = z_i^\top \tilde{z}_j / \tau$，$\tau$ 为温度超参数。不使用 memory bank 或动量编码器。
   - **重建损失**：组合**去噪项**（从扰动嵌入重建干净嵌入）和**恒等项**（从干净嵌入重建自身），均使用均方误差：
     $$L_{\text{recon}} = \| \hat{z}_p - z_p \|_2^2 + \| \hat{z}_o - z_o \|_2^2$$
   - **联合目标**：
     $$L_{\text{total}} = \lambda_{\text{recon}} L_{\text{recon}} + \lambda_{\text{contrast}} L_{\text{contrast}}$$

5. **梯度流分析（独特设计）**：
   - 对比损失仅更新编码器（$\partial L_{\text{contrast}} / \partial \psi = 0$），因为其只依赖潜在码；
   - 重建损失同时更新编码器和解码器；
   - 这种**不对称性是有意设计**的：让潜在空间主要由语义相似性组织，同时保持足够的信息以重建原嵌入。解码器纯粹由重建目标塑造。

## 3. 实验设计

- **数据集**：Stanford Natural Language Inference（**SNLI**）语料库。去重后得到 **568,484 个句子**，划分为训练集 548,820、验证集 9,840、测试集 9,824。句子长度集中在 5–15 个词（均值 8.8，中位数 8.0），最大长度设为 64。
- **扰动策略**：同义词替换、掩码、词丢弃三种策略，每种策略在 9 个强度水平（$\rho = 0.1, 0.2, \ldots, 0.9$）下进行评测。
- **评估协议**：从测试集采样固定 $N = 1000$ 个句子，对每个句子的干净表示和扰动表示计算余弦相似度，取均值。分别计算 CDAE 潜在空间（128 维）、原始 BERT 嵌入（768 维）和 SimCSE 嵌入的相似度。
- **对比方法**：
  - **原始 BERT 嵌入**（`bert-base-uncased`，均值池化）；
  - **SimCSE**（无监督对比学习基线）。
- **评价指标**：干净与扰动表示间的平均余弦相似度 $\bar{c}_{m,\rho}$，以及 CDAE 相对基线的差距 $\Delta_{m,\rho}$（正值表示 CDAE 更好地保持语义一致性）。

## 6. 论文的主要结论与发现

- CDAE 在**所有三种扰动策略、所有扰动强度**下，均一致性地优于原始 BERT 和 SimCSE，保持了更高的干净–扰动嵌入余弦相似度。
- **优势随扰动强度增大而扩大**：在掩码和词丢弃条件下最为明显——强度 0.9 时，CDAE 相似度仍高于 0.7，而 BERT 和 SimCSE 降至 0.6 以下；同义词条件下的优势较小但持续存在。
- 表明 CDAE 能够学习到**更稳定、更鲁棒的句子表示**，同时保留预训练模型编码的语义知识。
- 作者将扰动不变学习视为改进句子嵌入的一个**有前景的新方向**。

## 7. 优点

- **轻量高效**：在冻结的预训练编码器之上训练，仅引入少量可训练参数（两层 MLP 编码器 + 两层解码器），算力需求低（单块 RTX 4060 Laptop GPU 即可完成），易于与不同嵌入架构集成。
- **设计巧妙**：
  - 梯度流的不对称设计（对比损失只更新编码器、重建损失同时更新两者）具有清晰的理论依据，让潜在空间兼顾语义对齐与信息保持；
  - 重建损失中同时包含去噪项和恒等项，防止过度去噪导致信息丢失；
  - 训练时随机选择扰动策略，增强泛化性。
- **问题定位准确**：将"自然语义保持扰动"与"对抗攻击"明确区分，聚焦于语言内在变异而非恶意输入，具有实践意义。
- **评估较系统**：对三种扰动策略 × 九种强度进行全面评测，揭示了鲁棒性随扰动强度的变化趋势，而非仅报告单一强度下的结果。

## 8. 不足与局限

- **实验覆盖不足**：仅有单一数据集（SNLI），缺乏其他领域/语言的验证；没有在标准语义相似度基准（如 STS-B）或大规模文本嵌入基准（如 MTEB）上评测。
- **缺少消融与敏感性分析**：未分析 $\lambda$ 权重、温度、潜在维度、网络深度、训练扰动强度等关键超参数的影响，难以判断方法的稳健性和最佳配置。
- **基线公平性存疑**：与 SimCSE 的比较不一定完全公平——两者训练范式、维度、训练数据使用方式不同；作者也未与更多最新句子嵌入模型（如 E5、SBERT 等）对比。
- **评测方式局限**：仅用余弦相似度衡量鲁棒性，缺乏对**语义信息保持程度**的直接检验（如保留了多少语义相似度判别能力）；未检验 CDAE 嵌入在下游任务中的实际效果。
- **潜在偏差风险**：测试基于一次固定采样（$N=1000$），未报告多次重复实验的统计显著性；BERT 均值池化与官方 `[CLS]` 嵌入可能存在差异，但未作讨论。
- **泛化性未验证**：方法仅在 `bert-base-uncased` 上验证，未测试其他 PLM（RoBERTa、ELECTRA、T5 等）或不同规模的模型。
