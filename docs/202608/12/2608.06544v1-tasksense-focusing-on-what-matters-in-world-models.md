## 摘要
用于视觉控制的世界模型通常通过重构观测来学习紧凑的潜状态，这隐含地鼓励表征保留整个视觉输入中的信息。然而，任务相关内容往往只占据观测的一小部分，而背景杂乱和干扰物消耗了宝贵的表征容量。视觉重构与控制目标之间的这种不匹配使得潜表征倾向于建模与任务无关的视觉内容，稀释了与控制相关特征的学习信号，并在视觉干扰下严重降低下游性能。我们提出了TaskSense，一种以任务为中心的世界模型框架，通过一个以先前潜状态为条件的可微分随机空间注意力机制，在潜编码之前强制任务相关性。为了将注意力引导到控制相关区域，我们通过一个辅助逆动力学目标来增强训练。世界模型不重构完整观测，而只重构被关注的区域，从而鼓励潜表征在丢弃无关视觉内容的同时保留任务相关信息。解码器进一步以采样的注意力图为条件，使得在随机注意力下仍能保持一致的重构。与DreamerV3基线相比，TaskSense在DeepMind控制套件上保持了有竞争力的性能，同时在干扰控制套件上持续优于DreamerV3，显著提升了对视觉干扰的鲁棒性。定性分析进一步证实，在逆动力学监督引导下，学习到的注意力能够一致地定位控制相关区域，同时抑制无关视觉内容。

## Abstract
World models for visual control typically learn compact latent states by reconstructing observations, implicitly encouraging representations to preserve information across the entire visual input. However, task-relevant content often occupies only a small fraction of the observation, while background clutter and distractors consume valuable representational capacity. This mismatch between visual reconstruction and control objectives biases latent representations to model task-irrelevant visual content, diluting learning signals for control-relevant features and severely degrading downstream performance under visual distractions. We introduce TaskSense, a task-centric world modeling framework that enforces task relevance before latent encoding through a differentiable stochastic spatial attention mechanism conditioned on the previous latent state. To steer attention toward control-relevant regions, we augment training with an auxiliary inverse-dynamics objective. Rather than reconstructing the full observation, the world model reconstructs only the attended regions, encouraging latent representations to preserve task-relevant information while discarding irrelevant visual content. The decoder is further conditioned on the sampled attention map, enabling consistent reconstruction despite stochastic attention. Compared with the DreamerV3 baseline, TaskSense maintains competitive performance on the DeepMind Control Suite while consistently outperforming DreamerV3 on the Distracting Control Suite, demonstrating substantially improved robustness to visual distractions. Qualitative analysis further confirms that the learned attention, guided by inverse-dynamics supervision, consistently localizes control-relevant regions while suppressing irrelevant visual content.

## 一、核心问题与研究动机

世界模型（World Models）在视觉控制任务中通常通过**重构完整观测**来学习紧凑的潜状态表征。然而，这种方式存在一个根本性矛盾：

- **重构目标鼓励保留所有视觉信息**，包括背景、干扰物等与任务无关的内容；
- **控制任务往往只依赖观测中的一小部分区域**（如机器人的关节、肢体等）；
- 两者之间的不匹配导致潜表征浪费大量容量在无关信息上，稀释了控制相关特征的学习信号；
- 在存在视觉干扰的环境（如动态自然背景）中，性能显著下降。

现有解决思路各有不足：

- 放弃像素重构、改用对比学习等方法，会**失去生成式世界模型**，无法支持基于想象的规划；
- 在编码后对特征做掩码或注意力处理，只能改变"如何编码"，**无法决定哪些信息进入潜模型**；
- Task-Informed Abstraction (TIA) 需要同时训练两个世界模型来分离任务相关/无关信息，**模型复杂度和训练开销较大**。

**核心研究问题**：能否让世界模型直接控制哪些视觉信息进入潜动力学模型，从而在编码之前就强制任务相关性？

## 二、方法论：TaskSense 框架

### 2.1 核心思想

TaskSense 在 DreamerV3 基础上，引入一个**基于前一个潜状态的条件随机空间注意力模块**，在观测进入编码器之前进行过滤，只允许任务相关区域通过。世界模型仅重构被注意的区域，而不是完整观测。

整体架构：保留 DreamerV3 的 RSSM 潜动力学模型，修改其观测接口。

### 2.2 任务中心空间注意力（Task-Centric Spatial Attention）

注意力定义在一个粗粒度格 $\Lambda = \{0,\ldots,H'-1\} \times \{0,\ldots,W'-1\}$ 上，每个格点对应 $s \times s$ 的图像块（实验中 $H'=W'=8$），由轻量级 MLP $f_\phi$ 根据前一个潜状态 $s_{t-1} = (h_{t-1}, z_{t-1})$ 预测：

$$l_t = f_\phi\big(\text{SG}(s_{t-1})\big), \quad \theta_t = \sigma(l_t)$$

其中 $\sigma$ 为 sigmoid，$\theta_{t,i,j}$ 表示关注格点 $(i,j)$ 的概率。使用 stop-gradient (SG) 防止梯度经注意力预测器回传到 RSSM 动力学优化。

注意力场建模为**均值场 Binary Concrete（Relaxed Bernoulli）分布**：

$$q_\phi(m_t|s_{t-1}) = \prod_{(i,j)\in\Lambda} q_\phi(m_{t,i,j}|s_{t-1})$$

训练时通过 Binary Concrete 重参数化采样，温度 $\tau = 1.0$ 固定；推理时取均值 $\theta$。与此同时引入**稀疏正则化**，鼓励注意力紧凑：

$$L_{\text{sparse}} = \frac{1}{|\Lambda|} \sum_{(i,j)\in\Lambda} \theta_{t,i,j}$$

### 2.3 注意力感知编码（Attention-Aware Encoding）

将采样的注意力掩码上采样到原始分辨率，对观测做元素级相乘，并将掩码作为额外通道拼接：

$$o_t^{\text{att}} = \text{Concat}\big(o_t \odot m_t^{\text{up}},\; m_t^{\text{up}}\big)$$

得到的注意力感知观测直接输入标准 DreamerV3 卷积编码器，仅在输入通道上增加一个注意力通道。

### 2.4 辅助逆动力学目标（Auxiliary Inverse Dynamics）

为防止注意力均匀收缩（全部抑制观测）、退化为平凡解，引入逆动力学目标：从相邻两帧编码特征的差分预测上一动作：

$$\hat{a}_t = g_\psi\big(f_t - \text{SG}(f_{t-1})\big), \quad L_{\text{inv}} = \|\hat{a}_t - a_t\|_2^2$$

通过 stop-gradient 截断跨时间步的梯度传播，使注意力保留与动作预测相关的视觉特征。

### 2.5 注意力条件化重构（Attention-Conditioned Reconstruction）

重构目标仅为被注意的调制观测，且解码器以采样注意力图作为条件变量（使用 stop-gradient，防止解码器操纵注意力表示）：

$$L_{\text{rec}} = -\log p_\psi\big(o_t^{\text{att}} \mid s_t, \text{SG}(m_t)\big)$$

### 2.6 总训练目标

$$L_{\text{WM}} = L_{\text{dyn}} + L_{\text{rec}} + \lambda_{\text{sparse}} L_{\text{sparse}} + \lambda_{\text{inv}} L_{\text{inv}}$$

其中 $L_{\text{dyn}}$ 是 DreamerV3 原有的潜动力学损失，$\lambda_{\text{sparse}} = 0.1$，$\lambda_{\text{inv}} = 1.0$；actor-critic 优化保持不变。

## 三、实验设计

### 3.1 基准与环境

| 基准 | 说明 |
|---|---|
| **DeepMind Control Suite (DMC)** | 标准连续控制，静态背景，评估是否丢失任务相关信息 |
| **Distracting Control Suite (DCS)** | 同一任务叠加 DAVIS 数据集动态自然背景；本文进一步强化——**每一步独立采样背景帧**，移除时间连续性，构成更具挑战性的干扰设置 |

**具体任务（6个）**：Cartpole Swingup、Cheetah Run、Hopper Hop、Walker Stand、Walker Walk、Walker Run，覆盖多种动力学和控制难度。

### 3.2 对比方法

主要对比**DreamerV3**基线（官方实现），两者共享相同网络架构、优化流程、回放缓冲区与训练计划。TaskSense 仅增加注意力模块、注意力条件重构损失和逆动力学目标。

### 3.3 超参数设置

- 注意力格大小：$8 \times 8$
- Binary Concrete 温度：$\tau = 1.0$
- $\lambda_{\text{sparse}} = 0.1$，$\lambda_{\text{inv}} = 1.0$
- 注意力预测器与逆动力学头均为 3 层 MLP，隐藏维度 256
- 动作重复（action repeat）：2

## 六、主要结论与发现

1. **性能匹配**：在标准 DMC 上，TaskSense 与 DreamerV3 基本持平（虽然部分任务如 Cheetah Run、Walker Run 有差距，但总体相近），说明选择性编码不损害正常场景下的控制性能；
2. **鲁棒性显著提升**：在 DCS 上，TaskSense 在全部 6 个任务上均优于 DreamerV3（任务均值 490.2 vs 397.03，中位数 466.4 vs 276.8），其中 Cheetah Run 和 Walker Run 提升最为显著；
3. **注意力定位准确**：学习到的注意力一致聚焦在猎豹腿部等控制相关区域，抑制躯干和背景干扰；逆动力学监督是注意力准确性的关键——没有它注意力变得分散；
4. **组件均必要**：随机注意力、逆动力学目标、注意力条件重构三者缺一不可，其中随机注意力和逆动力学贡献最大。

## 七、方法亮点与优点

1. **在编码前过滤**：与其他在编码后处理特征的方法不同，TaskSense 在观测入口处施加注意力，从根本上阻止无关信息进入潜模型；
2. **保留重构式世界模型**：不像对比学习等方法完全放弃解码器，TaskSense 保留了解码器，从而维持基于想象的规划能力；
3. **优雅的注意力设计**：
   - 粗粒度格参数化天然引入局部一致性，避免逐像素注意力的计算开销；
   - 使用 Binary Concrete 而非 softmax 归一化，允许多个区域同时被关注（任务相关信息不一定是竞争关系）；
   - 注意力图中拼接作为额外通道，避免了遮挡注意力值本身的信息混淆；
4. **逆动力学监督的创新应用**：将逆动力学从"表征正则化"角色转变为"注意力定位"的信号来源，借助 stop-gradient 隔离不同目标的梯度流；
5. **注意力条件重构**：解码器以注意力图为条件，解耦了随机采样与重构的不确定性，设计思路清晰；
6. **实现轻量**：仅改变 DreamerV3 的观测接口，不改变潜动力学模型和策略优化流程，易于复现和集成。

## 八、不足与局限

### 8.1 概念层面的局限

- **任务相关 = 控制相关**这一假设可能不成立。逆动力学监督确保注意力聚焦于"能预测动作"的信息，但长期奖励相关的信息不一定都体现在即时动作预测中；存在某些视觉特征虽然不直接决定当前动作、却对长期回报至关重要的情况；
- 论文作者自己承认这一局限，并指出未来需要更好的长时程任务相关性监督信号。

### 8.2 实验层面的局限

- 消融实验只覆盖 2 个任务，结论的泛化性有一定风险；
- 尚未与其他专门针对干扰鲁棒性的方法（如 Masked World Models、SOLD、TIA 等）进行直接对比；
- 注意力可视化仅展示单一任务（Cheetah Run），缺乏对更多任务行为模式的展示；
- DCS 的动态背景设置（每步独立采样）与原始 DCS 基准不同，虽然更具挑战性，但也使结果难以与既有文献直接比较。

### 8.3 方法本身的局限

- 注意力基于前一时刻的潜状态预测当前注意力，存在**时序滞后**问题——当任务相关区域快速变化时可能错过关键信息；
- 稀疏正则化系数 $\lambda_{\text{sparse}}$ 和逆动力学系数 $\lambda_{\text{inv}}$ 没有进行敏感性分析，最优值可能随任务变化；
- Binary Concrete 温度固定为 1.0，未探索温度退火策略可能带来的收益。

### 8.4 潜在偏差风险

- 逆动力学目标以 L2 回归预测连续动作，适用于 DMC 这类连续控制任务；对于离散动作空间或高维动作空间，其适用性需要进一步验证；
- 论文只在 MuJoCo 系控制任务上验证，未涉及部分可观测或具身操作等更复杂场景。

## 总结

TaskSense 提出了一条简洁而有效的思路：**与其在编码后费尽心思筛选信息，不如直接在观测入口用"以任务为中心的注意力"决定哪些信息允许进入世界模型**。该方法在保持 DreamerV3 标准场景性能的同时，显著提升了视觉干扰下的鲁棒性，为重构式世界模型提供了更有针对性的表示学习范式。尽管存在"控制相关与任务相关等同"的假设局限和实验覆盖范围的问题，其核心思想——在观测接口处施加任务相关性——为后续研究提供了一个有价值的方向。
