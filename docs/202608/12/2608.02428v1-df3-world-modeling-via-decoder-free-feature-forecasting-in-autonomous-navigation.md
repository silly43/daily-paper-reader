## 摘要
从视频序列预测未来状态是自主机器人系统面临的关键挑战，也是世界建模的基本目标。以往的像素级生成方法不可避免地过度关注与任务无关的细节，导致计算开销过大。虽然基于潜空间的方法试图通过直接预测特征来缓解这一问题，但状态到任务映射中对重型解码器的持续依赖仍然是一个计算瓶颈。在这项工作中，我们提出了无解码器特征预测（DF$^3$），一种全新的框架，完全在潜空间内建模世界演化并直接生成任务输出，彻底消除了对解码器的需求。具体来说，DF$^3$ 将可学习的空间查询注入冻结的视觉基础模型的末端模块，以直接提取未来状态表示。通过采用一种轻量级、统一的运动感知上下文融合（MACF）机制，该机制将粗粒度光流扭曲与细粒度潜空间互相关无缝集成，这些查询与历史标记表示交互，以显式对齐和预测下一帧的特征。随后，一组专门的任务查询探测这些预测特征以用于下游任务。在公共基准测试和机器人模拟器中的零样本部署上进行的大量实验表明，DF$^3$ 在实现与最先进方法相当的性能的同时，为集成感知与控制提供了卓越的效率和灵活性。

## Abstract
Forecasting future states from video sequences is a critical challenge for autonomous robotic systems and a fundamental objective of world modeling. Prior generative methods operating at the pixel level inevitably overemphasize task-irrelevant details, leading to prohibitive computational overhead. While latent-based approaches attempt to mitigate this by predicting features directly, the persistent reliance on heavy decoders for state-to-task mapping remains a computational bottleneck. In this work, we propose Decoder-Free Feature Forecasting (DF$^3$), a novel framework that models world evolution entirely within the latent space and directly derives task outputs, completely eliminating the need for a decoder. Specifically, DF$^3$ injects learnable spatial queries into the terminal blocks of a frozen vision foundation model to extract future state representations directly. By employing a lightweight, unified Motion-Aware Context Fusion (MACF) mechanism that seamlessly integrates coarse flow warping with fine-grained latent cross-correlation, these queries interact with historical token representations to explicitly align and forecast the feature of the next frame. Subsequently, a specialized set of task queries probes these forecasted features for the downstream task. Extensive experiments on public benchmarks and zero-shot deployment in a robotic simulator demonstrate that DF$^3$ achieves performance comparable to state-of-the-art methods while offering superior efficiency and flexibility for integrated perception and control.

  - **潜空间预测方法**：在语义特征空间中预测未来状态，比像素级方法更加高效，但依然依赖**重型解码器**来完成状态到任务输出的映射，形成新的计算瓶颈。
- **核心研究问题**：能否在**视觉基础模型（VFM）的编码器内部**完成特征预测，并直接导出下游任务输出，从而完全消除解码器？

## 2. 论文提出的方法论

### 2.1 核心思想

- 采用**冻结的 DINO 系 ViT 编码器**作为基础模型，利用其自监督预训练获得的丰富语义特征。
- 通过向编码器**末端模块注入可学习的预测查询（prediction queries）**，与历史上下文特征交互，直接预测下一帧的潜空间特征。
- 再通过**任务查询（task queries）** 在同一个冻结编码器内探测预测特征，直接输出语义分割等任务结果。全程无需任何独立解码器。

### 2.2 技术细节

1. **特征表示与查询注入**：
   - 历史帧 $\{I_1,\dots,I_T\}$ 经编码器早期层 $L_1$ 提取上下文特征 $F_{L_1}(I_t)=\{f^{pref}_{L_1}(I_t), f^{patch}_{L_1}(I_t)\}$。
   - 预测查询 $Q_{pred}\in\mathbb{R}^{(H'W'+N_{pref})\times C}$ 与历史特征拼接后送入末端层 $L_2$，输出经运动感知融合后得到预测特征 $\hat{F}_{L_1}(I_{T+1})$。
   - 任务查询 $Q_{task}$ 再与预测特征拼接送入 $L_2$，输出经轻量 MLP 头生成分割 logits。

2. **结构化查询注意力（Structured Query Attention）**：
   - 在注入查询的注意力层中设计**非对称注意力掩码**，保证上下文 token 不被预测查询“污染”，只能相互注意；而预测查询可以关注所有 token，避免信息泄漏。

3. **运动感知上下文融合（MACF）**：
   - **光流扭曲分支**：由预测查询预测潜空间光流 $\Delta p = \text{MLP}_{flow}(q_{patch})$，将最近帧特征扭曲到目标时刻，并与当前查询特征作差形成粗略更新方向 $M_{warp}$。
   - **潜空间互相关分支**：在相邻两帧的局部邻域内进行软匹配，计算历史运动向量 $V_{hist}$，再投影为细粒度运动注入 $M_{xcorr}$。
   - **动态融合**：通过 sigmoid 门控 $G(q_{patch})$ 加权融合两个分支的残差，更新预测查询：
     $$\hat{f}^{patch}_{L_1}(I_{T+1}) = q_{patch} + G(q_{patch}) \odot \text{MLP}_{fuse}([M_{warp}, M_{xcorr}])$$
   - 全局 prefix token 使用轻量时间外推器预测其动态。

4. **训练目标**：
   - 完全采用**特征级监督**，不依赖下游解码器联合训练：
     $$\mathcal{L}_{sim} = \mathbb{E}_t\left[1 - \cos\left(\hat{F}_{L_1}(I_{t+1}), F_{L_1}(I_{t+1})\right) + \lambda_{huber}\,\text{Huber}\left(\hat{F}_{L_1}(I_{t+1}), F_{L_1}(I_{t+1})\right)\right]$$
   - 对 patch token 和 prefix token 都计算损失，保证整体场景表征。

## 6. 论文的主要结论与发现

- DF$^3$ 能够**在完全冻结的视觉编码器中完成未来特征预测和任务输出**，无需解码器，验证了"ViT 编码器内部即可进行世界建模"的核心假设。
- 在 Cityscapes 上，DF$^3$ 的短期预测 mIoU 为 **69.9**、MO-mIoU 为 **68.7**，中期（$T+3$）分别为 **58.2** 和 **56.5**，与 DINO-Foresight 相比略有下降（约 1.6–1.9 mIoU），但显著降低计算开销：
  - FLOPs 降低 **36%**（1440.63 vs 2256.07 GFLOPs）
  - 推理延迟降低 **70%**（292.4 ms vs 971.1 ms）
  - 峰值显存降低 **67%**（3.1 vs 9.5 GB）
  - 参数量降低 **41%**（177.0 vs 302.5 MB）
- **MACF 机制是关键组件**：光流粗对齐分支擅长处理整体位移及遮挡，互相关分支擅长局部快速运动匹配，两者结合后 mIoU 从单一分支的约 63–65 提升至 69.9，证明显式运动建模对冻结编码器捕获时序动态至关重要。
- 在 MATRiX 四足机器人模拟器上，DF$^3$ 无需微调即可直接提供与 Oracle 规划轨迹高度一致的前瞻信息，表明潜空间预测特征具有跨视角、跨本体的可迁移性。

## 7. 优点

- **架构创新性强**：首次实现"完全无解码器"的潜空间未来预测，将世界建模和下游任务集成在同一个冻结 ViT 内部，概念简洁且落地价值高。
- **效率优势突出**：相比现有潜空间方法，在推理延迟、显存占用、参数量和计算量上均有大幅削减，且性能代价较小，具有明显的准确率–效率权衡优势。
- **运动建模设计精巧**：MACF 将光流扭曲（宏观位移）与潜空间互相关（局部细粒度对齐）有机结合，并利用门控机制动态融合，避免了直接修改预训练权重，保持了编码器的通用性。
- **注意力掩码设计严谨**：结构化非对称注意力防止了查询对上下文表示的干扰，保证了特征预测的因果性和信息流正确性。
- **经验证充分**：400 epochs 训练与多尺度搜索半径消融提供了较扎实的实验基础；零样本跨本体部署实验进一步展示了实际应用潜力。

## 8. 不足与局限

- **应用局限**：DF$^3$ 目前仅支持纯观测式未来预测，**不支持动作条件预测**，无法模拟具体动作对未来的影响，限制了其在闭环控制与交互式规划中的直接使用。
- **对比基线不足**：主要对比仅有 DINO-Foresight 一个潜空间方法，未与像素级生成方法或更多近期世界模型进行比较，论证力度有所欠缺。
- **数据集单一**：仅在 Cityscapes 上训练和评估，缺乏多种场景、天气、光照和多传感器模态的验证，可能存在过拟合到城市道路视角的风险。
- **输出精度受限**：由于在低分辨率特征空间内预测，生成的物体边界较粗、边缘有噪声、薄结构易丢失，视觉保真度不如像素级生成方法；虽然对导航影响有限，但在需要精细感知的任务中受限。
- **模拟器部署缺乏量化指标**：MATRiX 实验仅有定性轨迹可视化，未报告规划成功率、平均轨迹误差等定量结果，影响零样本泛化结论的客观性。
- **计算细节披露不完整**：未报告总训练时长、训练吞吐量、消融实验的统计显著性/多次重复方差等信息，降低了可复现性评估的完整度。
