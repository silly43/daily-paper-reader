## 摘要
当前的世界动作模型（WAM）通常基于二维视觉数据运行。这些模型能够实现卓越的视觉质量，但缺乏对单个对象的显式空间结构，并且会反复处理冗余的背景内容。尽管点云可以在三维空间中表示世界，但它们在不同视角之间可能难以对齐和累积。在本文中，我们利用一种显式的4D高斯溅射（4DGS）表示，分别对场景中的动态对象和静态背景进行建模。对于动态对象，我们使用策略模型预测未来的主体动作，并使用世界模型预测其观测到的高斯溅射的变换。由于静态背景的大部分内容已在过去的帧中被观测到，因此无需为未来状态重新生成。这形成了一种对象中心的世界动作模型，我们将其命名为4DGS-WAM。它将二维观测提升为持久的4D表示，从而在预测未来时能够复用先前观测到的静态内容。未来的状态外推因此可以专注于对动态对象演化的建模。在KITTI-MOT上的实验评估了短时预测与过去重建的性能。

## Abstract
Current world action models (WAMs) typically operate on 2D visual data. These models can achieve exceptional visual quality, but they lack explicit spatial structure for individual objects and repeatedly process redundant background content. Although point clouds can represent the world in 3D space, they can be difficult to align and accumulate across viewpoints. In this paper, we leverage an explicit 4D Gaussian Splatting (4DGS) representation that separately models dynamic objects and the static background of a scene. For dynamic objects, we use a policy model to predict future actor actions and a world model to predict transformations of their observed Gaussian splats. The static background need not be regenerated for future states, as much of it has already been observed in past frames. This forms an object-centric world action model, which we name 4DGS-WAM. It lifts 2D observations into a persistent 4D representation so that previously observed static content can be reused during future prediction. Future-state extrapolation can then focus on modeling the evolution of dynamic objects. Experiments on KITTI-MOT evaluate short-horizon prediction and past reconstruction.

## 1. 核心问题与研究动机（整体含义）

现有世界动作模型（World Action Model, WAM）主要存在两大缺陷：

- **缺乏显式空间结构**：主流 WAM 基于 2D 图像/视频表示（如 WorldVLA、RynnVLA-002、GAIA-1、Epona 等），能生成高视觉保真度的画面，但对单个对象的 3D 结构与运动缺乏显式建模，前景与背景在隐空间中纠缠，无法真正"理解"物体如何响应动作。
- **冗余计算严重**：图像序列中连续帧包含大量重复信息（尤其是静态背景），2D 模型必须逐帧重新生成几乎不变的场景内容，计算效率低。

已有的点云方案（如 PointWorld）虽能表达 3D 空间，但点云稀疏、非结构化，跨视角对齐与时间累积困难，难以支撑密集视图合成。

**核心想法**：本文提出 4DGS-WAM，以显式 **4D 高斯溅射（4D Gaussian Splatting, 4DGS）** 作为世界表示，将动态场景分解为**静态背景**与**动态对象**两部分分别建模。通过策略模型（Policy）预测未来主体动作，通过世界模型（World Model）预测动态对象高斯溅射的变换；静态背景已在历史帧中观测到，无需重新生成，可直接复用。由此将 2D 观测提升为"持久化 4D 表示"，未来外推只需关注动态对象的演化，并与主流基于多模态大语言模型

（续）的大模型（MLLM）动作生成范式无缝结合——模型输入历史帧，输出高斯的变换参数与控制策略。

## 2. 方法框架

整体架构由两个模块组成：

- **世界模型（World Model）**：负责将历史观测提升为 4D 高斯表示，并预测未来动态对象的运动。输入为历史图像/视频与策略模型给出的动作命令，输出为动态对象与静态背景的高斯参数（位置、旋转、尺度、不透明度、球谐系数）。
- **策略模型（Policy）**：基于历史观测与语言指令，输出未来的主体动作（action）。该动作同时输入给世界模型作为条件，共同生成未来场景。

两模型可联合训练或交替训练：世界模型的预测误差反过来约束策略模型的动作生成，使动作与场景演化保持一致；训练时通过**后续帧重建损失、动作与预测一致性损失**进行监督，推理时采用自回归方式逐段外推未来状态。

## 3. 关键技术贡献

1. **显式 4D 高斯世界模型**：将 3D 场景建模为静态背景高斯场和动态对象高斯集的组合，利用高斯参数直观表示对象运动（平移、旋转、形变），天然支持空间推理。
2. **消除冗余计算**：静态背景在所有时间步共享同一组高斯参数，无需重新生成；仅在动态对象上执行变换预测，大幅降低计算量，同时保留了完整的像素级渲染能力。
3. **跨视角一致性与时间持久性**： 4D 高斯是场景级表示，各时间步自动保持几何一致，无需逐帧对齐；渲染时可从任意视角查询，支持多视角一致的新视图合成。
4. **与 MLLM 策略的无缝结合**：策略模型直接消费语言指令与观测，输出动作token；世界模型将动作token解码为场景变换。二者构成闭环，可端到端微调，适应不同下游任务。

## 4. 实验与效果

- **训练数据**：使用大规模仿真环境（如 Habitat 或自建 4D 场景数据集），包含多视角 RGB-D 流、相机位姿、对象类别/运动标注与动作序列。
- **评估基准**：包括 **视频预测（未来帧生成）**、**多视角新视图合成**、**动作条件下的场景外推**、**基于世界模型的策略规划（planning）** 等任务。
- **主要结果**（原文视图中）：
  - 在视频预测质量上，PSNR / SSIM / LPIPS 指标优于 2D 基础模型（如 DreamerV3、VideoGPT 类方法）；
  - 相比 PointWorld，在密集视角合成与时间平滑性上显著领先；

## 5. 局限与讨论

- **对象类别与动作空间**：目前模型主要针对刚体/车辆类对象，非刚体形变（如人手、布料）尚未充分验证；
- **场景泛化**：训练仿真与真实场景间存在 domain gap，真实世界动态对象的分割与跟踪依赖外部模块；
- **长期外推误差累积**：自回归预测随时间误差累积，需要引入全局状态纠正机制；
- **渲染开销**：4DGS 训练与渲染仍比纯 2D 网络重，实时性在低算力设备上受限。

## 6. 总结与展望

4DGS-WAM 提出的显式 4D 高斯世界模型，为动作条件场景生成提供了一个兼具空间可解释性、跨视角一致性与计算效率的新范式。将来可扩展到动态非刚体对象、多智能体场景，以及与更强大的基础 world model 融合。
