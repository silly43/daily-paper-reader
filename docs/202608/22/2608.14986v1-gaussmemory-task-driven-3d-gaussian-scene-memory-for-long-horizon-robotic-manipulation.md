## 摘要
长时程机器人操作从根本上依赖于持久的空间记忆。然而，现有的3D记忆系统仅充当被动记录器：它们使用固定的、手工设计的规则来存储观察结果，对每个场景元素——无论是关键的抓取目标还是无关的背景墙壁——都赋予同等重要性。本文提出了一种从被动存储向主动的、任务驱动空间记忆的范式转变。我们认为，机器人的记忆不应仅仅记录其所见，而应主动学习如何记忆——发现哪些物体需要精确跟踪、如何激进地更新它们以及应丢弃什么，所有这些都无需手工设计规则，而是端到端学习而来。关键的是，这种主动范式通过将记忆更新和读取统一为同一认知过程的两个方面来实现，从而实现双向流动，使任务需求塑造更新策略，反之亦然。为了具体实现这一愿景，我们引入了GaussMemory，它利用3D高斯泼溅作为持久几何基础。在LIBERO上，GaussMemory在Goal和Long-10任务上优于MemoryVLA；在VLABench上，其性能超过$π_0$-FAST，在Track 1和Track 6上分别提高了+5.2%和+6.0%。

## Abstract
Long-horizon robotic manipulation fundamentally relies on persistent spatial memory. However, existing 3D memory systems function merely as passive recorders: they store observations using fixed, hand-crafted rules, treating every scene element--whether a critical grasp target or an irrelevant background wall--with equal importance. In this paper, we propose a paradigm shift from passive storage to active, task-driven spatial memory. We argue that a robot's memory should not simply record what it sees, but actively learn how to remember--discovering which objects to track precisely, how aggressively to update them, and what to discard, all learned end-to-end without hand-designed rules. Crucially, this active paradigm is realized by unifying memory update and readout as two sides of the same cognitive process, enabling bidirectional flow where task needs shape update strategies and vice versa. To instantiate this vision, we introduce GaussMemory, which leverages 3D Gaussian Splatting as a persistent geometric substrate. On LIBERO, GaussMemory outperforms MemoryVLA on Goal and Long-10; on VLABench, it surpasses $π_0$-FAST by +5.2% (Track 1) and +6.0% (Track 6).

- **核心问题**：长时程（Long-Horizon）机器人操作任务中，当前的视觉观察往往不足以支撑决策（例如物体被放入抽屉后遮挡，RGB图像无法判断其位置），因此需要**持久空间记忆**。然而，现有3D记忆系统只是"被动的记录器"：它们用固定手工规则无差别地存储所有场景元素——无论关键抓取目标还是无关背景，均等对待；且记忆的**更新与读取被割裂**为两个独立过程，缺乏双向信息流动。
- **背景不足**：
  - 语言记忆（如SayPlan）：损失几何精度，"杯子在桌上"无法回答"相对于盘子在哪"。

  - 3D结构记忆（如ConceptGraphs）：依赖手工更新规则（阈值匹配、固定速率平均、硬剪枝），与任务性能完全脱钩。

- **整体含义**：这是从"被动存储"到"主动、任务驱动空间记忆"的范式迁移，首次将3D高斯泼溅（3DGS）作为VLA框架内的持久时序记忆基底，使任务损失真正"雕刻"记忆行为。

### 2. 方法论：核心思想、关键技术细节与算法流程

#### 2.1 核心思想
- 以**3D高斯泼溅（3DGS）** 为持久几何基底，以**统一记忆注意力（UMA）** 为核心机制，在共享的跨注意力模块中**同时完成记忆读取（读流）与记忆更新（写流）**，实现端到端可微的双向信息流。
- 3DGS的三大适配性：(1) 天然增量性——可单独增删/移动高斯不影响全局；(2) 显式几何——每个高斯携带位置 $\mu$、协方差 $\Sigma$、不透明度 $\alpha$，提供操作规划所需的精确定位；(3) 可令牌化——高斯特征可编码为紧凑token注入LLM骨干。

#### 2.2 系统组成
- **时序高斯场景记忆 $M_t$**：持久维护的增强高斯原语集合。
  - 每个高斯包含：标准3DGS属性（位置 $\mu_i$、协方差 $\Sigma_i$、不透明度 $\alpha_i$、颜色 $c_i$、球谐特征 $h_i$）+ 时序元数据（创建/修改时间戳 $t_i^c/t_i^m$、子任务索引 $\tau_i$、物体ID $o_i$、存在概率 $e_i$）。
  - 特征编码：
    $$
    g_i^{mem} = \mathrm{MLP}_{enc}\big([\mu_i; \mathrm{vec}(\Sigma_i); \alpha_i; h_i]\big) + \mathrm{PE}_{3D}(\mu_i) + \mathrm{PE}_T^{rel}(t_i^m, t)
    $$
  - 物体中心组织：通过Gaussian Grouping + DINO特征获取实例ID，将高斯分组为逐对象组。

- **统一记忆注意力（UMA）**：四个阶段的数据流。
  1. **构建统一查询**：观察token（FF-3DGS从多视图RGB生成8192个实时高斯 → 按物体池化为约20个对象级token）+ 任务条件读取查询（$K=64$个可学习token，注入CLIP语言指令编码与子任务时序编码）。
  2. **自注意力（观察-任务交换）**：读取查询与观察token相互注意，使观察token"任务感知"、读取查询"感知觉grounded"，形成上下文统一查询 $U_{ctx}$。
  3. **跨注意力（存取记忆）**：统一查询作为Query，记忆高斯作为Key/Value，进行跨注意力并引入**时序相对偏置** $B_T$（基于相对时间编码 $\mathrm{PE}_T^{rel}(t_i^m,t)$）；每个UMA层包含自注意力→跨注意力→FFN，各带LayerNorm和残差连接。
  4. **读/写双流输出**：
     - **读流**：读取查询输出经线性投影送入LLM（Llama-2-7B）用于动作预测。
     - **写流**：观察行最终交叉注意力得到软对应矩阵 $A^{match} \in \mathbb{R}^{N_o \times N_m}$，驱动整个记忆生命周期：
       - 证据聚合 $w_k = \sum_j A^{match}_{jk}$；
       - 位置软聚合估算 $\tilde{\mu}^{obs}_k$；
       - **学习更新门**：
         $$
         \eta_k = \sigma\big(\mathrm{MLP}_\eta\big([\tilde{h}^{obs}_k; w_k; \mathrm{PE}_T^{rel}(t_k^m,t)]\big)\big)
         $$
         位置更新：$\mu^{new}_k = (1-\eta_k)\mu^{mem}_k + \eta_k \tilde{\mu}^{obs}_k$；
       - 存在概率更新 $e^{new}_k = \sigma\big(\mathrm{logit}(e_k) + \gamma \cdot \log(w_k+\epsilon)\big)$，低于阈值 $\theta_e=0.1$ 则剪枝；
       - 新物体插入：低匹配的观察以概率 $p^{new}_j = \sigma\big(\mathrm{MLP}_{ins}(q^{obs,(L)}_j) - \lambda \cdot \max_k A^{match}_{jk}\big)$ 插入记忆。

- **LLM骨干与动作生成**：采用与OpenVLA/CogACT/MemoryVLA相同的Prismatic VLM（DINOv2+SigLIP + Llama-2-7B），token序列为 $Z=[Z_{mem}; Z_{2D}; Z_L; Z_S]$，扩散动作头输出 $a_t=[\Delta p, \Delta r, g]$，另输出子任务完成信号。

- **训练**：总损失 $L = L_{action} + \lambda_c L_{complete} + \lambda_t L_{temporal} + \lambda_u L_{update}$，梯度经 $\eta_k$ 与 $A^{match}$ 直接传导，使任务损失真正塑造记忆行为；两阶段训练（FF-3DGS预训练冻结 → UMA+投影器+LLM(LoRA)联合训练）。

### 6. 主要结论与发现

- **主动记忆范式有效**：从被动记录到主动任务驱动，任务损失端到端塑造记忆行为是可行的，且产生清晰可解释的**紧急行为**——操作物体更新系数平均约$\eta \approx 0.74$，背景仅约0.06，完全来自梯度学习而非手工规则（图5、图9）。
- **性能提升显著**：
  - LIBERO：Goal 96.8%（超MemoryVLA的96.4%）、Long-10 94.1%（超93.4%）；Long-10上9/10任务排名第一；相比无记忆基线增益随任务周期单调增加（+4.0 → +8.6 → +11.7）。
  - VLABench：Track 1达56.4%（超π0-FAST 5.2%），Track 6达24.0%（超6.0%）。
- **记忆收益随任务周期增长**：从LIBERO到VLABench（约120步 vs 500+步），改进幅度持续扩大，验证"记忆随周期规模放大"的规律。
- **3D几何表示是关键**：2D token记忆替换3D高斯记忆后，Long-10从94.1%降至90.2%，VLABench两个track分别降至51.4%/19.0%——明确显示3D几何本身是决定性因素，而非仅"有记忆"。
- **统一读写优于解耦**：UMA相对解耦基线提升2.3个百分点，验证了"如何用记忆应塑造如何存记忆"的核心假说。
- **记忆容量存在最优规模**：32K高斯达到性能峰值，64K不再提升（93.6%），说明学习的存在管理有效防止冗余堆积。

### 7. 优点

- **范式创新性**：首次明确提出并实现"主动、任务驱动记忆"——从"记住什么"转向"如何记忆"，将记忆更新与读取统一为同一可微过程，概念新颖且有认知科学（测试效应）支撑，非单纯工程拼凑。
- **端到端可微闭环**：动作损失梯度一路传导至记忆更新门 $\eta_k$、对应矩阵 $A^{match}$、存在概率 $e_k$，使记忆行为真正被任务目标"雕刻"，而非辅助损失启发式约束——这是与所有先前工作的根本区别。
- **3D高斯作为记忆基底的合理性**：充分利用3DGS的增量性（增删/移动不破坏全局）、显式几何（精确定位）、可令牌化（自然整合进LLM），选型有据可依。

- **量化了紧急记忆行为**：通过η热力图、时序动态、记忆大小变化等可视化，将"学习到的记忆策略"直观呈现，增强结果可信度。
- **跨benchmark一致性**：在LIBERO与VLABench两个设计迥异的基准上获得一致的三大规律，提高结论泛化性。

### 8. 不足与局限

- **任务覆盖仍有限**：LIBERO全部套件但每个任务仅20次试验、3个种子；VLABench仅覆盖100类任务中的2个track（30个任务），未全面评估其余类别；全部实验限于仿真环境，**无真实机器人部署验证**——真实场景中3DGS重建质量、相机标定误差、遮挡模式等均可能影响性能。
- **多视角输入依赖**：FF-3DGS编码器需要多视角RGB，LIBERO原本单视角，必须从模拟器额外渲染两个虚拟视角——这在实际物理机器人系统中可能难以获得，部署条件受限；单视角适配方案未见探讨。
- **训练算力需求高**：4×A100训练120K步（具体时长未披露），LLM骨干为7B规模（即使LoRA），对大多数研究团队门槛较高；FF-3DGS生成8192个高斯+32K记忆高斯的推理效率（延迟/FPS）未报告，长时程任务中实时性存疑。
- **全面超越性不足**：LIBERO Spatial/Object套件上MemoryVLA（98.4%）仍高于GaussMemory（96.4%/96.2%）；在短周期、语义识别主导的任务中，3D记忆优势不显著甚至略有劣势，表明2D与3D记忆各有适用场景，而非绝对替代。
- **部分基准对比非同一环境复跑**：多个baseline（OpenVLA、π0-FAST等）结果引用论文官方数据，而非在同一代码框架、同一多视角设置下重新训练——尽管"+2D token记忆"消融部分弥补了这一差距，但严格同条件对比仍不完整。
- **超参数与容量工程的敏感性未充分分析**：记忆上限32K是从4K→64K消融选出的，但训练对不同容量、η初始值、阈值 $\theta_e$、$\lambda_c/\lambda_t/\lambda_u$ 权重组合的鲁棒性未详查；64K性能略降（93.6%）的原因也未深入解释。
- **缺少对记忆中信息"错误固化"的处理**：若初始观测由于传感器噪声或遮挡产生错误位置估计，且后续无高置信度更新，记忆会以低η长期保留错误信息——论文未讨论这种"错误记忆"的纠正机制。
- **紧急行为分析为描述性而非因果性**：η=0.74 vs 0.06的行为模式虽直观展示，但未通过干预实验（如人为固定任务无关物体η）证明该模式是性能提升的必要条件。
