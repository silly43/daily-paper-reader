## 摘要
我们提出了一种测试时世界模型推断（Twin）系统，其中前沿编码代理编写一个可执行的世界模型，用于完成持续学习任务，例如ARC-AGI-3游戏。传统方法为每个任务手工设计专用模型。每个游戏隐藏其规则和目标，而我们的系统仅通过模拟和交互来构建它们。其对网格游戏的归纳先验足够强，能够在几乎所有关卡中恢复真实的游戏转换和目标。回放验证发生在孪生世界模型中。测试框架强制执行：在程序复现每一个先前观察到的游戏转换之前，不得采取任何动作。世界模型预测与实际动作结果之间的每一次不匹配都会成为一个反例，用于修复世界模型。Twin在183个关卡中通过了179个（97.8%），并且在179个关卡中的158个（88.3%）中比人类更高效。该系统在156个（87.2%）通过的关卡中，在获得任何奖励之前就推断出目标，并在其余关卡中通过搜索自动发现目标。基准测试以0到100的分数衡量完成度和行动效率，与首次游玩每款游戏的人类进行比较。直接运行时，基础模型仅得7.8%；使用现成测试框架可提升至61.1%，而我们的孪生世界模型将相同基础模型提升至93.3%，通过了25款游戏中的23款。构建一个可用的世界模型比预期的要简单，而更困难的问题是推断正确的目标。

## Abstract
We present a Test-time World-model Inference (Twin) system, in which a frontier coding agent writes an executable world model for completing continual learning tasks, such as ARC-AGI-3 games. Traditional approaches hand-engineer such models, one custom design per task. Each game hides its rules and goal, and our system constructs them from simulation and interaction alone. Its inductive prior over grid games is strong enough to recover the true transitions of the game and the goal on nearly all levels. Replay validation happens in a twin world model. The harness enforces that an action is not made until the program reproduces every previous observed game transition. Each mismatch between a world model prediction and the actual action result becomes a counterexample that is used to repair the world model. Twin clears 179 out of 183 levels (97.8%), and does so more efficiently than humans in 158 out of 179 levels (88.3%). The system infers the goal before any reward on 156 of the levels it clears (87.2%), and in the remaining levels automatically discovers the goal by search. The benchmark scores completion and action efficiency, between 0 and 100, against humans playing each game for the first time. Played directly, the base model scores only 7.8%; an off-the-shelf harness increases it to 61.1%, whereas our twin world model increases the same base model to 93.3%, clearing 23 out of 25 games. Building a usable world model is simpler than anticipated, whereas the harder problem is inferring the right goal.

## 2. 论文提出的方法论

### 2.1 核心思想

Twin 将未知游戏视为一个确定性马尔可夫决策过程 $M = (S, A, T, R, s_0)$，其中：

- 状态 $s \in S$ 是 64×64 颜色网格
- 动作 $A$ 是 4~6 个按钮及点击坐标
- 转换函数 $T$ 和奖励谓词 $R$ 均未知

代理维护一个**可执行的孪生模型**（Python 文件），包含两个函数：
- `step(grid, action) -> grid`：模拟转换函数 $\hat{T}$
- `goal_reached(grid) -> bool`：判断目标谓词 $\hat{R}$

### 2.2 核心配管流程（Validate–Explore–Plan–ExecuteChecked）

**① Validate（重放验证）**：孪生模型必须复现日志中每一个观测到的转换三元组 $(s, a, s')$：

$$\phi_{\text{fit}}(D, \hat{T}) \iff \forall (s, a, s') \in D,\ \hat{T}(s,a) = s'$$

这是**硬约束**：在验证通过之前，禁止任何计分动作发出。重放失败产生反例，用于修复模型。

**② Explore（诊断与目标发现）**：根据"卡住"的类型分为两个分支：

- **动力学墙**（动力学失败）：将反例按上下文分组，按失配率、效果多样性、支持度排序，生成修复报告。
- **目标墙**（模型正确但找不到目标）：在不使用 $\hat{R}$ 的情况下，用更大预算（深度 14，30,000 节点）在孪生模型中枚举可达状态，按五种视觉变化信号排列候选目标：
  - `color_gone`：某颜色完全消失
  - `color_new`：出现新颜色
  - `local_burst`：局部紧凑区域发生 ≥5 格变化
  - `big_change`：超过 1/4 格同时变化
  - `frontier`：与当前帧差异最大的可达状态

候选目标须通过**一致性检查**：$\hat{R}$ 必须对所有已记录帧返回 false（因为获胜帧会被替换，所有已记录帧都是确定性的负样本）。

**③ Plan（模型内规划）**：在通过验证的孪生模型内执行广度优先搜索（BFS），以 $\hat{R}$ 为目标测试：

$$\phi_{\text{reach}}^H(s, \hat{T}, \hat{R}) \iff \exists k \le H,\ \exists a_1,...,a_k,\ s_1,...,s_k: s_0 = s,\ s_i = \hat{T}(s_{i-1}, a_i),\ \hat{R}(s_k) = 1$$

默认预算为深度 8、20,000 节点。BFS 找到的第一条路径即最短计划。

**④ ExecuteChecked（受检执行）**：计划逐动作提交，每次提交前预测下一帧并哈希存档。若预测与实际一致则继续；若出现失配，则停止并将该转换追加到日志中，孪生模型失效，进入修复循环。判定公式：

$$i^\star = \min\{i : s_i \neq \hat{s}_i\}$$

### 2.3 目标发现（Goal Discovery）

这是本文的核心创新之一：

- 在未获得任何奖励前，候选目标状态先由 Explore 生成，编码代理将其编辑为 `goal_reached` 谓词。
- 经过两个过滤器：（1）对日志中所有帧返回 false；（2）先前到达过但未通关的状态被永久排除。
- 执行测试路线后有三种结果：
  1. 到达关卡边界 → 目标假设被确认
  2. 精确到达预测状态但无边界 → 候选被拒绝
  3. 预测与实际失配 → 动力学被修复，目标保持待定

### 2.4 算法（Algorithm 1）

每场游戏启动身份孪生（identity twin）和空日志，循环执行：Perceive → Validate →（失败则 Repair）→ Plan →（无路线则 Explore 目标墙 → ProposeGoal → 一致性检查 → 重新 Plan）→ 若无路线则 Probe → ExecuteChecked。直到关卡完成或预算耗尽。

1. **Twin 在 ARC-AGI-3 上达到 93.3 分，清除 179/183 关卡（97.8%）和 23/25 个游戏**，在 18 个游戏上达到满分 100.0
2. **行动效率超过人类**：在 179 个清除关卡中，158 个（88.3%）使用的行动数不超过首次游玩的人类；平均行动数为人类的 0.61 倍
3. **硬约束验证是关键**：Twin 是唯一完整清除 bp35（9 关）、lf52（10 关）和 sk48（8 关）的系统，这归功于框架强制的"未验证不动"原则
4. **目标推断是真正的瓶颈**：第一个目标假设在 179 个通关关卡中的 156 个（87.2%）是正确的；未通关游戏（sc25、sp80）的问题在于目标而非动力学
5. **世界模型可泛化**：最终孪生模型对从未见过的状态-动作对精确预测完整下一帧的比例为 70.1%（20,790 次测试），远高于纯记忆
6. **动力学与目标的标签不对称**：11,557 个动力学标签对 179 个目标标签（约 65:1），这是目标精度（0.214）远低于在线动力学精度（79.4%）的结构性原因
7. **搜索预算限制**：固定搜索预算（深度 8/14、20,000/30,000 节点）意味着超出视界的目标无法被发现
8. **部分可观测性可控**：bp35 的滚动摄像机证明，通过"一次一探测"的方式可以应对部分可观测场景

## 7. 优点

- **新颖的范式**：提出"测试时数字孪生"这一明确方法论，将未知环境从黑盒转化为可检查、可证伪、可修复、可规划的可执行假设
- **硬约束而非提示**：与依赖 prompt 指令请求验证的方法不同，Twin 由框架强制执行"重放验证不通过不得行动"的约束，这是其长游戏表现的关键
- **不对称目标的形式化**：明确区分"拟合动力学"（对所有观测的一致性）和"乐观可达性"（通过搜索），避免了将两者混合优化的不稳定性
- **目标先于奖励发现**：在 87.2% 的通关关卡上，第一个目标假设即在获得任何奖励前正确，这使得大多数关卡从第一步就具备目标导向
- **可解释性**：学习到的世界模型是源代码，可读、可审计、可复现，而非隐含在权重中
- **严谨的验证体系**：预测在动作发出前哈希存档，不可事后修改；逐动作分类（MODEL/PROBE）可审计
- **全面的消融和泛化分析**：不仅报告聚合分数，还深入分析预测精度、空间误差分布、目标声明精度/召回等深层指标
- **对反直觉现象的深入剖析**：如框架预测精度（92%）与游戏得分（未通关）脱钩，归因于目标墙而非动力学墙

## 8. 不足与局限

### 方法论局限

- **确定性假设**：重放验证假定环境是确定性的且可由程序表示。真实的概率环境或需要连续状态表示的场景不在范围内
- **单帧观测**：`step` 只读取当前帧，无法处理隐藏状态（如随游戏进程变化的计数器、跨帧记忆）。tn36 和 sc25 正是因此失败
- **固定搜索预算**：超出深度 14 或 30,000 节点的目标不可达；长视界任务需要更多计算
- **可扩展性存疑**：平均每计分动作 224k token 的计算成本（是消融的 4.7 倍）可能限制在更大规模环境的适用性
- **程序可压缩性假设**：方法依赖"规则可以用 Python 程序简洁表达"这一先验，对于不能用代码表示的复杂动力学效果有限

### 实验局限

- **单

**单次运行**：由于基础模型服务具有随机性，论文仅报告了单次运行结果，未提供多次运行的方差、置信区间或稳定性分析。这对于一个依赖 LLM 生成代码的方法而言，其鲁棒性尚不明确。

- **对比方法复现缺失**：OPINE-World（Claude Opus 4.8）和 EWM（GPT-5.5）的结果来自各自原始报告，论文未在同一软硬件条件下复现这些方法。基础模型的差异使得"框架贡献 vs 模型能力"的归因不够干净。
- **计算成本高昂**：平均每计分动作消耗约 224k token，是直接游玩消融（48k/动作）的 4.7 倍；单游戏最大消耗 625M token（ka59），总消耗 2.60B token。这种成本模式在大规模部署或面临时间限制的场景中可能不可行。
- **超参数固定**：搜索预算（深度 8/14、20,000/30,000 节点）和候选目标信号的阈值（≥5 格、>1/4 格）未进行系统敏感性分析，其最优性或稳健性未知。
- **98 次跨级/跨游戏探测仅 16.3% 精确率**：虽然论文将其定位为"目标发现的一种手段"，但这一实验揭示出部分候选目标可能具有误导性，论文未详细分析错误探测的代价。

## 9. 对领域的影响与未来方向

### 对基础模型评估的启示

- ARC-AGI-3 基准揭示了基础模型在"交互式规则发现"上的显著短板：直接游玩得分仅 7.8%。Twin 分数提升至 93.3% 的关键不在于更强的推理模型，而在于将"生成"与"验证"分离的架构性改变。这暗示：基础模型在 ARC-AGI-3 上的失败可能不是能力不足，而是缺乏"验证闭环"这一交互范式。
- 论文提出的**可执行代码作为世界模型**的表示方式，意味着 LLM 生成的代码可以被形式化验证（重放）、被测试（泛化评估）、被审计（人类可读）。这与隐式世界模型（如神经网络编码的 latent dynamics）形成鲜明对比，为可解释 AI 提供了一个具体实例。

### 对世界模型研究的启示

- 论文的核心反直觉结论——**"构建可用世界模型比预期简单，真正困难的是推断正确目标"**——挑战了世界模型研究中以动力学学习为中心的主流思路。在 ARC-AGI-3 环境中，动力学规律的发现可以通过受约束的程序合成在极少交互内完成，而目标推断缺乏类似的监督信号。
- "动力学与目标的标签不对称"（65:1）这一观察具有普适意义：在大多数未知环境的探索任务中，agent 从每次动作中都能获得转换反馈，但目标相关的正样本可能永远不出现（除非偶然达到）。这提示目标发现可能需要额外的归纳偏置或先验。

### 未来工作方向

1. **处理随机性与部分可观测状态**：将确定性重放验证推广到概率转移和隐藏状态推理，例如通过维护多个候选孪生模型或概率分布
2. **降低计算成本**：目标发现（GenerateGoal）是 token 消耗的主要来源之一；通过更好的候选排序或小型验证模型进行预筛，可能降低一个数量级的消耗
3. **跨游戏迁移**：目前孪生模型每场游戏从头构建，未来可探索跨游戏共享的规则知识库或先验
4. **人类认知对比**：论文提到人类的首次游玩行动数，但未深入分析人类在目标发现上的策略；将探针式目标发现与人类学习曲线对照可能产生新的洞见
5. **扩展到非网格环境**：64×64 网格的离散性简化了状态表示；将"验证闭环"范式推广到连续控制或自然语言指令环境是一个开放性挑战

## 10. 总体评价

这是一篇方法新颖、实验严谨、写作清晰的研究论文。其主要贡献不在于提出一个新的神经网络架构或训练算法，而在于将"测试时程序合成 + 硬约束验证 + 模型内规划"这一工程系统化地应用于未知游戏环境，并在 ARC-AGI-3 基准上取得了显著优于现有方法的成绩。

论文最值得称道之处在于其**方法论自觉**：作者不仅报告分数，还深入分析了框架各部分的行为学特征（逐动作分类、目标声明精度、预测空间误差分布），使得读者能够理解系统在哪里成功、在哪里失败、为什么。这种透明度在当今 AI 论文中尤为珍贵。

主要的批评点在于：计算成本的高昂、单次运行缺乏统计稳健性、以及与对比方法的基础模型不一致。这些不足并不削弱核心结论，但提示读者在将结果泛化到其他环境时应保持谨慎。

从更宏观的视角看，Twin 代表了一种"**以验证为中心的人工智能**"（verification-centric AI）趋势：与其让模型直接行动，不如让模型先构建一个可以被严格检验的世界假设，再在假设内进行优化。这种范式在安全关键场景中具有天然吸引力，其局限（确定性、程序可压缩性）也为未来研究划定了清晰的边界。综合而言，这是一篇对该领域具有实质贡献和启发意义的论文。
