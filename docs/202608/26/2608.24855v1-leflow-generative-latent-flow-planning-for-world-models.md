## 摘要
潜在世界模型本质上是强大的编码器，能够将图像像素转换为潜在嵌入，然而现有的世界模型在动作规划中仍然依赖在线轨迹优化：对于每个状态-目标对，需要从零开始运行迭代优化器以搜索最优动作序列，将世界模型视为黑盒模拟器。这种方法在每次重新规划时都要重新支付完整的迭代优化成本，并且跨查询不复用任何规划经验。在这项工作中，我们探讨一旦学习了潜在世界模型，规划本身是否可以被摊销。我们提出了LeFlow，它直接在世界模型的潜在动态空间中学习一个可复用的潜在轨迹先验。LeFlow将规划重新表述为条件潜在轨迹生成：一个修正流模型在当前嵌入与目标嵌入之间想象未来的潜在路径，逆动力学解码器将潜在转换转化为动作块，冻结的世界模型通过自回归展开验证每个候选。在四个主要的目标条件像素控制基准上，LeFlow用摊销的潜在规划和固定预算的展开选择取代了迭代动作空间优化，在规划时间上实现了一个数量级的减少，同时持续获得成功率提升。我们的结果表明，潜在世界模型不仅应支持预测，还应支持可复用的规划先验。我们的代码可在https://github.com/hsiangwei0903/LeFlow获取。

## Abstract
Latent world models are inherently strong encoders that transform image pixel to latent embedding, yet existing world models still rely on online trajectory optimization for action planning: for every state-goal pair, an iterative optimizer is run from scratch to search for optimal action sequences, treating the world model as a black-box simulator. This approach pays the full iterative optimization cost anew at every replanning step and reuses no planning experience across queries. In this work, we ask whether planning itself can be amortized once a latent world model has been learned. We present LeFlow, which learns a reusable latent trajectory prior operating directly in the latent dynamics space from the world model. LeFlow recasts planning as conditional latent trajectory generation: a rectified-flow model imagines a future latent path between the current and goal embeddings, an inverse dynamics decoder turns latent transitions into action chunks, and the frozen world model verifies each candidate by autoregressive rollout. Across four major goal-conditioned pixel-control benchmarks, LeFlow replaces iterative action-space optimization with amortized latent planning and fixed-budget rollout selection, achieving consistent success-rate gains with an order-of-magnitude reduction in planning time. Our results argue that latent world models should support not only prediction but reusable planning priors. Our code is available at https://github.com/hsiangwei0903/LeFlow.

- **研究背景**：潜在世界模型（如 LeWM）通过联合嵌入预测架构（JEPA）将像素观测压缩为潜在嵌入，并在该潜在空间中学习动力学模型，已成为强预测器。
- **核心问题**：尽管世界模型的预测能力已很强，但现有方法在规划时仍普遍采用“在线轨迹优化”范式。典型做法如 LeWM+CEM，对每个状态-目标对都从零运行迭代优化（如交叉熵方法），将世界模型当作黑盒模拟器：
  - 每个重规划步骤都重复支付完整的迭代优化成本；
  - 查询之间不共享任何规划经验；
  - 世界模型虽已编码了任务相关的潜在几何结构与可达动态，却未被用于“引导搜索”，而是被反复黑盒调用。
- **核心主张**：规划本身也可以被摊销（amortized）。一旦潜在世界模型被训练好，可以离线学习一个“可重用的潜在轨迹先验”，使规划变成一次条件生成加固定预算的候选验证，而不需要在每个时刻重新求解最优控制问题。
- **整体含义**：潜在世界模型不仅应当支持预测，还应支持可重用的规划先验，从而显著降低在线推理代价，同时保持甚至提升任务成功率。

## 2. 论文提出的方法论

- **核心思想**：将规划重新表述为“条件潜在轨迹生成”。具体地：
  - 给定当前观测编码 $z_{\text{start}}$ 和目标观测编码 $z_{\text{goal}}$；
  - 用一个生成模型（修正流模型）生成两端固定的潜在路径 $z_{0:H}$（只生成内部 $H-1$ 个潜在状态）；
  - 用逆动力学解码器将每一个潜在转移 $(z_t, z_{t+1})$ 解码为可执行的动作块 $a_t$；
  - 用冻结的世界模型预测器对所有候选路径进行自回归展开，按最终潜在状态与目标的距离对候选排序，选出最优者执行。
- **三个可训练组件**（LeWM 完全冻结）：
  1. **潜在流规划器（Latent Flow Planner）**：修正流模型 $v_\psi$，学习从高斯噪声 $u_0$ 到数据潜在路径内部状态 $u_1$ 的直线传输。训练目标为：
  
     $$
     L_{\text{flow}} = \mathbb{E}_{\tau, u_0, u_1} \left\| v_\psi\left(u_\tau, \tau \mid z_{\text{start}}, z_{\text{goal}}\right) - (u_1 - u_0) \right\|_2^2,
     $$
  
     其中 $u_\tau = (1-\tau) u_0 + \tau u_1$。由于修正流在函数空间中轨迹近似直线，推理时仅需少量 Euler 积分步（论文中默认 16 步），可并行采样 $N$ 条候选路径。
  2. **逆动力学解码器（Inverse Dynamics Decoder）**：MLP $g_\omega$，输入当前潜在状态、下一潜在状态及其差向量，输出动作块：
  
     $$
     a_t = g_\omega\left(\left[ z_t,\; z_{t+1},\; z_{t+1} - z_t \right]\right).
     $$
  
     训练损失为均方误差 $L_{\text{inv}} = \mathbb{E}\|g_\omega([z_t,z_{t+1},z_{t+1}-z_t]) - a_t\|_2^2$。
  3. **展开重排序（Rollout Reranking）**：生成路径可能穿过不可达的潜在区域，因此对每个候选 $i$，将其解码为动作序列，用冻结预测器展开得到实际末端潜在状态 $\hat{z}_H^{(i)}$，并按到目标的距离排序：
  
     $$
     \text{score}^{(i)} = \left\| \hat{z}_H^{(i)} - z_{\text{goal}} \right\|_2^2,
     $$
  
     选择得分最低的候选执行。该过程不修改生成模型，只是对候选做选择。
- **总训练目标**：$L = L_{\text{flow}} + L_{\text{inv}} + \lambda_{\text{cons}} L_{\text{cons}}$，其中一致性损失 $L_{\text{cons}}$ 将生成的潜在转移解码为动作后用预测器单步展开，并惩罚预测的下一潜在状态与生成目标之间的偏差：
  
  $$
  L_{\text{cons}} = \mathbb{E} \left\| \hat{z}_{t+1} - z_{t+1} \right\|_2^2, \quad \hat{z}_{t+1} = \text{pred}_\phi(z_t, \hat{a}_t).
  $$
  
  默认 $\lambda_{\text{cons}}=0.1$，它把预测器的动态结构在训练期蒸馏进规划器，使生成分布偏向“可控潜在流形”，并与推理期重排序互补。
- **推理流程**：编码当前与目标观测 → 并行采样 $N$ 条潜在路径 → 逐条解码为动作块 → 冻结 LeWM 预测器批量展开 → 按式 (5) 重排序 → 执行最优动作块。整个过程在一个重规划周期内无任何迭代优化循环。

## 6. 论文的主要结论与发现

- **摊销规划可行**：LeFlow 替代 LeWM+CEM 的在线迭代优化，在所有四个基准上取得更高成功率——TwoRoom 100%、PushT 95.2%、Reacher 86.8%、OGBench-Cube 100%，对比 LeWM+CEM 分别提升 +18.0、+5.9、+18.8、+26.7 个百分点。
- **规划时间降低约一个数量级**：端到端时间上 LeFlow 比 LeWM+CEM 快 4.5×（OGBench-Cube）到 14.4×（TwoRoom），且由于对比包含环境步进与渲染的共享部分，规划侧加速实际更高。
- **潜在空间规划优于动作空间直接生成**：Action-Flow 基线在 PushT 和 Reacher 上分别低 3.0 和 4.5 个百分点，说明动作层多模性更强，不如先规划潜在路径再逆解码。
- **生成建模优于确定回归**：确定性潜在路径预测器在两个非饱和基准上均低于 LeFlow，与“规划本质多模”的论点一致。
- **滚动重排序至关重要**：去掉重排序后 Reacher 成功率降低 10.5 个百分点（77.0% vs 87.5%），证明生成路径必须通过冻结世界模型投影回可控潜在流形。
- **跨主干可迁移**：在 DINO-WM 上使用 512 个提案的 LeFlow 在 PushT 达到 86% 成功率，超过 DINO-WM+CEM 的 84%，候选展开数减少 17.6×，端到端时间减少 14.7×。

## 7. 优点

- **思想清晰**：将“规划”视为可摊销的条件轨迹生成，明确提出在潜在状态空间而非动作空间规划，具有较好的理论动机。
- **模块化设计**：潜在流规划器、逆动力学解码器、冻结世界模型验证三个模块解耦，各自可独立替换或改进。
- **训练高效**：仅训练中小规模的流量模型与 MLP，10 epochs 即可完成，且在数据量有限的 DINO-WM 迁移中也能生效。
- **推理计算可并行**：N 条候选路径的采样与展开均可在 GPU 上批次化，无在线优化循环，带来一个数量级的提速。
- **实验设计细致**：通过饱和/非饱和区分、冻结主干比较、多 seed 统计和跨主干迁移等设计，提高了结论的可信度。
- **消融与设计选择互相印证**：潜在空间 vs 动作空间、生成 vs 回归、是否重排序、一致性损失权重的实验都与方法阐述相对应。

## 8. 不足与局限

- **视界受限**：方法固定为短视界（$H=5$），当 $H=10$ 或 $20$ 时成功率急剧下降（PushT 上从 94% 到 32% / 6%），缺乏长程规划能力。论文承认需要分层规划或更强世界模型来缓解累计展开误差。
- **基准规模有限**：四个环境均属于二维或简单三维控制任务，未在更复杂视觉、更多步骤或真实机器人场景中验证。
- **消融覆盖面不足**：核心消融仅在 PushT 和 Reacher 上报告，对两个饱和基准无法给出有区分度的证据。
- **泛化验证有限**：虽然做了 80/20 持出集实验，但 LeFlow 仍依赖离线数据覆盖；对分布外目标、动态障碍等未测试。
- **DINO-WM 迁移实验的局限性**：仅一个任务（PushT），空间编码器只用 1k 轨迹训练，且需额外训练自动编码器引入偏差；不能证明对所有世界模型主干通用。
- **硬件与训练成本未披露**：论文未写明 GPU 类型、数量、训练时长，可复现性和成本评估有欠缺。
- **基准本身与长视界不匹配**：论文指出官方基准主要面向短视界控制，因此在长视界上的衰减部分归因于评价设置，但这同样限制了方法论在长期连续决策任务中的说服力。
