## 摘要
开发能够理解和操作物体的机器人需要紧凑、可解释且可泛化的表示。本工作提出了一种基于强化学习的机器人抓取精化框架，将基于关键点的物体表示与深度Q网络（DQN）相结合。利用模拟环境中捕获的二维俯视图像，一种基于几何的算法生成初始抓取候选，该框架对其进行迭代精化，将失败的抓取转化为成功的抓取。在Dex-Net数据集的300个物体上使用UR5机械臂进行的实验证明了该框架的有效性，在之前被几何方法认为不可抓取的物体上实现了100%的成功率。该框架的仿真到现实迁移能力进一步通过Delta并联机器人的物理实验得到验证，其中一次精化后的抓取成功操作了一个之前不可抓取的物体。研究结果强调了强化学习在解决机器人抓取挑战中的有效性，为接触丰富的操作任务提供了一种可扩展且适应性强的解决方案。

## Abstract
Developing robots capable of understanding and manipulating objects requires compact, interpretable, and generalizable representations. This work proposes a reinforcement learning-based framework for robotic grasp refinement, integrating keypoint-based object representations with a Deep Q-Network (DQN). Using 2D overhead images captured in a simulated environment, a geometric-based algorithm generates initial grasp candidates, which are iteratively refined by the proposed framework, transforming failed grasps into successful ones. Experiments conducted on 300 objects from the Dex-Net dataset using a UR5 manipulator demonstrate the framework's effectiveness, achieving a 100% success rate on objects previously deemed ungraspable by geometrical methods. The framework's sim-to-real transferability is further validated through physical experiments on a Delta parallel robot, where a refined grasp successfully manipulates an object that was previously ungraspable. The findings underscore the effectiveness of reinforcement learning in addressing challenges in robotic grasping, offering a scalable and adaptable solution for contact-rich manipulation tasks.

## 2. 方法论

### 2.1 总体框架

论文将抓取问题局部化：不学习全局的“如何从零开始抓取”，而是学习“如何在已有候选附近进行局部调整”。流程为：

1. 基于2D俯视图像，用几何算法（Sabzejou et al., 2023）生成初始抓取候选；
2. 将失败的抓取候选作为**初始状态**输入DQN精化模块；
3. 智能体通过交互选择离散动作，调整抓取矩形参数；
4. 模拟器返回成功率与稳定性评分，作为奖励信号指导迭代优化；
5. 最终输出精化后的最优抓取位姿。

### 2.2 状态与动作定义

- **状态** $s_t = (x, y, \theta, w)$，为一个四维向量，分别表示抓取矩形中心的笛卡尔坐标、面内旋转角和宽度（对应二指平行爪的抓取参数）。
- **动作空间**为9个离散动作（表I），包含对 $x$、$y$、$\theta$、$w$ 的微调以及一个空操作（no-op）：

| 动作索引 $a$ | 调整 $(\Delta x, \Delta y, \Delta \theta, \Delta w)$ | 描述 |
|---|---|---|
| 0 | $(+1, 0, 0, 0)$ | 调整X像素 |
| 1 | $(-1, 0, 0, 0)$ | 调整X像素 |
| 2 | $(0, +1, 0, 0)$ | 调整Y像素 |
| 3 | $(0, -1, 0, 0)$ | 调整Y像素 |
| 4 | $(0, 0, +2, 0)$ | 调整旋转 |
| 5 | $(0, 0, -2, 0)$ | 调整旋转 |
| 6 | $(0, 0, 0, +2)$ | 调整宽度 |
| 7 | $(0, 0, 0, -2)$ | 调整宽度 |
| 8 | $(0, 0, 0, 0)$ | 空操作 |

### 2.3 评分机制与奖励

评分基于物体在抓取前后的**旋转滑移量**（|∆θ|），即姿态偏转程度：

- 成功抓取（物体被稳定提升）：分数范围为 $[0, 1]$；
- 失败抓取（夹爪闭合但未提升物体、物体掉落或完全未接触）：分数范围为 $[-1, 0]$。

评分公式为：

$$
\text{Score} = 
\begin{cases}
1 - \frac{|\Delta \theta|}{\pi}, & \text{成功抓取} \\
-1 + \frac{|\Delta \theta|}{\pi}, & \text{失败抓取}
\end{cases}
$$

- 完全稳定、无倾斜的抓取得分为 $+1$；
- 完全错失物体（无接触）得分为 $-1$；
- 有接触但部分移动或抬升后掉落的，得分在 $(-1, 0)$ 之间，越接近0表示越接近成功。

### 2.4 DQN实现细节

- Q网络为**全连接神经网络**：3个隐藏层（256、128、64个神经元），激活函数为 ReLU，并使用 Layer Normalization。
- 优化器：Adam，学习率 0.005。
- 折扣因子 $\gamma = 0.9$。
- 探索策略：$\epsilon$-greedy，$\epsilon$ 初始为 1.0，每步衰减 0.999，下限 0.01。
- 训练规模：每个物体训练 $E = 25$ 个回合（episode），每回合最多 $T = 120$ 步。
- 经验回放缓冲区（replay buffer），批量大小（batch size）为 32。
- 目标Q网络定期同步参数（$\phi' \leftarrow \phi$）。
- 损失函数为均方误差（MSE）：

$$
L(\phi) = \mathbb{E}_{(s,a,r,s')} \left[ \left( Q(s,a|\phi) - y \right)^2 \right]
$$

其中目标值为：

$$
y = r + \gamma \max_{a'} Q(s', a'|\phi)
$$

### 2.5 训练算法（Algorithm 1 要点）

- 以初始失败抓取 $s_{\text{init}}$ 作为起点；
- 初始化 Q 网络、目标网络、经验回放缓冲区以及 $\epsilon$；
- 每回合从 $s_{\text{init}}$ 出发，执行 $\epsilon$-greedy 策略选择动作；
- 将精化后的抓取位姿 $s_{t+1}$ 在模拟器中**执行 N 次**，取平均得分作为即时奖励 $r_t$；
- 存储转移元组 $(s_t, a_t, r_t, s_{t+1})$ 到回放缓冲区；
- 若当前得分超过历史最优，则更新 $s_{\text{best}}$；
- 当得分达到 $+1$ 时提前终止；
- 最终输出最优精化抓取位姿 $s_{\text{best}}$。

## 6. 主要结论与发现

1. 将强化学习限定为**局部精化模块**（而非端到端全局学习）是一种可行且高效的策略，大幅简化了 RL 问题的搜索空间。
2. 所提出的 DQN 精化框架能够**系统性地将失败抓取转化为稳定成功的抓取**，在 38 个几何方法“不可抓取”的物体上实现 100% 成功率。
3. 精化过程不仅使失败抓取变为成功，还提升了已成功抓取的稳定性（通过最小化旋转滑移量衡量）。
4. 精化所得抓取位姿能够从仿真**直接迁移到真实机器人**，在 Delta 并联机器人上成功实现了稳定抓取，验证了 sim-to-real 可行性。
5. 评分函数有效地将姿态稳定性量化为奖励信号，成功引导 DQN 避开不合格抓取配置。

## 7. 优点与亮点

- **问题定位精准**：将 RL 应用于“局部精化”而非“全局抓取综合”，降低了学习难度，提高了样本效率和实用性。
- **可解释性强**：状态空间为直观的抓取矩形参数 $(x, y, \theta, w)$，无需高维图像输入或复杂特征提取器。
- **与现有几何方法互补**：不替代已有的几何标注器，而是作为其后续增强模块，形成“几何初筛 + RL 精化”的流水线，兼具两者的优点。
- **评分机制简洁有效**：以旋转滑移量作为唯一稳定性指标，归一化到 $[-1, 1]$，简单、可复现，且提供了失败范围内的连续信息（而非二元成败标签），有利于梯度学习。
- **鲁棒性验证**：每次抓取执行 3 次，确保结果非偶然；提前终止机制（得分=1 时退出）节省计算资源。
- **实物验证**：论文在真实 Delta 机器人上完成了从失败到成功的 sim-to-real 验证，增强了工作的实际参考价值。
