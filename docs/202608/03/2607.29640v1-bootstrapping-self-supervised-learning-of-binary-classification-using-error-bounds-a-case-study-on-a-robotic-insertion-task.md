## 摘要
柔性制造要求快速部署解决方案并最小化设置时间以保持竞争力。一个关键属性是控制误差水平的能力，因为失败可能从轻微的性能下降到严重的设备损坏。然而，传统部署通常涉及大量的设置、数据收集、模型训练或参数调优以及系统测试，导致显著延迟，阻碍商业可行性。我们提出了一种数据引擎，在执行任务的同时收集数据并提升其性能。该数据引擎由两个分类器组成：快速模型预测和昂贵的验证。首先进行模型预测，基于预测的置信水平，可以使用昂贵的验证。通过调整置信水平，用户可以控制可容忍的误差水平。我们的方法在真实世界的机器人插入任务上实现，该任务使用力数据进行模型预测。系统应用UMAP降维，并使用Wilson-Score计算预测的置信界。结果表明，系统能够在设定的误差率内学习并减少对昂贵验证的需求。结果突显了置信界在自我改进模型中增强机器人分类任务可靠性的潜力。

## Abstract
Flexible manufacturing requires rapid deployment of solutions and minimal setup time to remain competitive. An essential attribute is the ability to control error levels, as failures can range from minor performance degradation to severe equipment damage. However, conventional deployment often involves extensive setup, data collection, model training or parameter tuning, and system testing, resulting in significant delays that hinder commercial feasibility. We propose a data engine which gathers data and improves its performance while executing the task. The data engine consists of two classifiers, a fast model prediction and expensive verification. First, a model prediction is performed and based on the confidence level of the prediction, the expensive verification can be used. By adjusting the confidence level, users can control the level of tolerable error.   Our method is implemented on a real-world robotic insertion task, which uses force data for the model prediction. The system applies UMAP dimensionality reduction and uses Wilson-Score to compute the confidence bounds of the prediction. Results demonstrate the ability to learn and reduce the need for expensive verifications over time, while staying within the set error-rate. The results highlight the potential of confidence bounds in self-improving models to enhance reliability in robotic classification task.

### 2. 论文提出的方法论

#### 核心思想
构建一个双分类器数据引擎：先由机器学习模型进行快速预测，基于Wilson-Score计算的置信界判断预测是否可靠；若置信度不足，则回退到昂贵验证，并将验证结果作为训练数据存入数据库，持续改进模型。

#### 系统流程（见图3）
1. **插入任务执行**：机器人从料箱抓取物体并插入夹具，同时采集力数据。
2. **数据采集**：力觉传感器以500 Hz采样率记录2秒插入过程的z轴力数据，每样本形成1000维特征向量。
3. **维度约减**：使用UMAP将1000维高维数据降至2维，保留局部邻域结构，便于分类与可视化。
4. **分类**：使用Scikit-Learn的Radius Neighbors Classifier：以查询点为中心、固定半径r内的所有邻居进行多数投票密度分类。区别于k-NN固定邻居数，只比较查询点局部邻居。
5. **置信度量化**：
   - 基线方法为**Binomial Interval Score**：$$p = \frac{n_s}{k} \pm \frac{z_\alpha}{\sqrt{k}} \sqrt{\frac{n_s n_f}{k^2}}$$
   - 本文采用**Wilson Score Interval**（对样本量小或概率接近0/1时表现更好）：$$p = \frac{n_s + \frac{1}{2} z_\alpha^2}{k + z_\alpha^2} \pm \frac{z_\alpha}{k + z_\alpha^2} \sqrt{\frac{n_s n_f}{k} + \frac{z_\alpha^2}{4}}$$
   - 其中$n_s$、$n_f$为半径内正/负样本数，$k = n_s + n_f$，$z_\alpha$为对应目标误差率$\alpha$的标准正态分布$1-\alpha/2$分位数。
6. **决策逻辑**：若Wilson置信区间的**下界LB**（可理解为精度下界，用户可设定阈值）超过设定阈值，则采用模型预测；否则使用昂贵验证。
7. **数据反馈**：昂贵验证结果存入数据库；若模型误判为成功但后续动作出错（如系统停机），则将该样本也标记为假阳性存入数据库；周期性基于累积数据重新训练模型（含UMAP嵌入更新）。

#### 参数控制
- **α**：控制置信区间宽度（误差容忍度）。α越小，置信度要求越高，区间越宽，系统越晚开始自信预测（见表Ia）。
- **LB**：下界阈值。越高，则对模型精度的要求越高，假阳性越少但预测次数也越少（见表Ib）。例如α=0.05且LB=95%时，要求Wilson区间下界≥95%，意味着半径内几乎全部邻居须属于同一类才可自信预测。

### 6. 论文的主要结论与发现

- Wilson-Score置信界可以有效地将系统的**假阳性率控制在（100−LB）%阈值以内**（实验结果中平均假阳性率始终低于该阈值）。
- 参数α和LB为用户提供了**控制错误率与运行效率之间权衡**的旋钮：更高LB或更低α会推迟模型投入使用的时机，但精度更高。
- 在α=0.1、LB=90%的配置下，系统在后期的“确定预测”比例接近90%，意味着大部分情况下可跳过昂贵验证，显著缩短周期时间。
- 系统在初始配置之后，**可以自主运行而不需要人工干预**进行数据收集和标注，实现了真正的自监督在线学习。
- 对比Binomial Interval Score：该方法在置信度计算上存在缺陷——仅有一个邻居时下界即为[1.0, 1.0]，导致过早自信预测且无法调节；Wilson Score在邻居数量不足时仍保持保守，更适合小样本场景。

### 8. 不足与局限

- **单一任务验证**：仅在机器人插入任务上验证，缺乏在不同任务、不同传感器模态或不同制造场景中的泛化性证明。

- **类不平衡与先验问题**：数据集中正负样本接近平衡（803 vs 700），但真实应用中类别分布可能更偏斜；Wilson Score在极端概率下的区间行为虽优于Binomial，但极端类不平衡时仍需进一步评估。
- **假阳性代价不对称**：假阳性会导致机器人系统停机并需人工介入（该成本远高于假阴性），文中虽记录了假阳性样本，但未系统量化不同误分类代价下的最优策略。
