## 摘要
尽管在数据理解和决策方面能力强大，但自主数据科学代理仍然严重依赖于涉及昂贵计算的试错工作流程。这一瓶颈促使模型能够在实际执行之前预测数据科学操作的效果。在本文中，我们引入了数据科学世界模型的概念，该模型通过基于当前工作流状态和候选操作预测环境状态转移来建模数据科学执行环境。我们进一步提出了DSWorld，一个实用的框架，结合了结构化状态构建、成本感知路由、轻量级实际执行以及用于昂贵操作的基于LLM的模拟器。为了支持训练，我们构建了一个8K规模的转移轨迹数据集，并引入了反思性世界模型优化，这是一种用于改进转移预测的感知错误强化学习策略。实验表明，DSWorld将基于RL的代理训练加速了约14倍，基于搜索的推理加速了约3-6倍，同时保持了竞争力的性能，并在转移预测任务上比最强的LLM基线高出35.6%。代码可在https://anonymous.4open.science/r/DSWorld获取。

## Abstract
Despite strong capabilities in data understanding and decision-making, autonomous data science agents still heavily rely on trial-and-error workflows that involve expensive computation. This bottleneck motivates models that can anticipate the effects of data science operations before real execution. In this paper, we introduce the concept of Data Science World Model, which model the data science execution environment by predicting environment state transitions conditioned on current workflow states and candidate operations. We further propose DSWorld, a practical framework that combines structured state construction, cost-aware routing, lightweight real execution, and an LLM-based simulator for expensive operations. To support training, we construct an 8K-scale transition trajectory dataset and introduce Reflective World Model Optimization, an error-aware reinforcement learning strategy for improving transition prediction. Experiments show that DSWorld accelerates RL-based agent training by approximately $14\times$ and search-based inference by approximately $3$-$6\times$ while maintaining competitive performance, and outperforms the strongest LLM baseline by 35.6% on transition prediction tasks. The code is available at https://anonymous.4open.science/r/DSWorld.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：当前自主数据科学代理（如 ML-Master、AIDE 等）高度依赖试错工作流，需要反复执行昂贵的数据处理、模型训练和评估。例如，ML-Master 在 MLE-Bench 上超过 86% 的执行时间花在模型训练上。这种计算开销严重限制了系统的效率和可扩展性。
- **核心动机**：能否开发一种“数据科学世界模型”，使得代理在实际执行操作前就能预判该操作的效果（如数据集变化、模型性能、错误信息等），从而避免大量不必要的昂贵计算？
- **整体含义**：本文首次提出 **数据科学世界模型**（Data Science World Model）的概念，类比于视觉世界模型预测物理世界状态，数据科学世界模型预测数据科学操作后的环境状态，旨在**高效代理**（加速训练和推理）的同时保持性能。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
将数据科学执行环境视为“世界”，构建一个从当前状态和操作到下一状态的预测模型，使代理能够在实际执行前“想象”操作结果。

### DSWorld 框架组成（四个模块）
1. **State Constructor（状态构造器）**：规则化程序，将原始环境（任务描述、数据集统计、执行历史、日志等）转换为结构化状态表示 $S_t = \{T_t, D_t, P_t, L_t\}$。
2. **Router（路由器）**：将当前状态和编码后的操作输入路由器，判断该操作属于轻量级还是计算密集型：
   - 若轻型（如简单数据操作）→ 进入 **Compiler** 直接执行；
   - 若重型（如大规模模型训练）→ 进入 **Simulator** 进行预测；
   - 此外若编译器超时也会转到模拟器。
3. **Compiler（编译器）**：直接与真实执行环境交互，返回执行后的精确下一状态。
4. **Simulator（模拟器）**：基于 LLM（文中采用 Qwen3-8B）的过渡预测模型，无需实际执行即可预测下一状态，包括执行状态、输出、错误和性能信号。

### 优化策略
- **第一阶段：监督微调（SFT）**，在 8K 过渡轨迹上初始化模拟器。
- **第二阶段：反思式世界模型优化（Reflective World Model Optimization）**
  - 基于当前状态和动作，模拟器预测下一状态 $\hat S'$，与真实 $S'$ 比较生成反思反馈 $f$。
  - 利用反馈对预测进行精炼 $\hat S'_r$。
  - 对每个样本进行 $n$ 次 rollout，同时优化原始和精炼预测，损失函数使用 **GRPO**（Group Relative Policy Optimization）：
    $$L(\theta) = E\left[ \frac{1}{2n}\sum_{i=1}^n (L_{\text{clip}}(\hat S'_i, A_i) + L_{\text{clip}}(\hat S'_{r,i}, A_{r,i}))\right] - \beta_{\text{KL}} D_{\text{KL}}(\pi_\theta \|\pi_{\text{ref}})$$
    其中优势 $A_i = (R_i - \mu(R)) / (\sigma(R) + \epsilon)$。

### 训练数据构建（DSWorld-8K）
- **真实轨迹采集**：运行现有代理获取真实过渡 $(S, A, S')$，并用 LLM 生成 CoT 推理轨迹。
- **合成轨迹构建**：
  - **状态合成**：利用 MMTU 数据集中的真实表格，通过状态构造器生成多样状态。
  - **动作合成**：基于 NumPy/Pandas 操作和错误库，随机采样操作类型和错误类型，用 LLM 生成可执行代码。
  - **真实执行与验证**：执行合成动作获得真实下一状态，并验证是否符合预期状态和错误约束，仅保留一致样本。
  - 每个样本附带 CoT 推理轨迹。
