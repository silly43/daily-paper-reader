## 摘要
视觉-语言-动作（VLA）模型旨在将多模态输入映射到机器人动作。然而，由于大多数现有方法将所有视觉标记统一处理并使用人工选择因素进行推理，缺乏强调任务关键证据的机制且忽略了潜在因素，因此难以覆盖复杂的动态场景。为解决这一问题，我们提出LEEVLA，一种在潜在环境演化中关注关键信息的VLA架构，该架构在保留潜在世界表征结构化演化的同时，明确引导模型关注信息丰富区域。为识别显著且与指令相关的区域，我们引入漂移引导动态优先级（DGDP），其结合动态位置优先级（DPP）与语义漂移引导（SDG），在训练过程中引导VLA代理关注何处。在此基础上，我们引入结构化特征流生成（SFFG），通过原型到周边（P2P）预测对这些优先特征在潜在空间中如何演化进行建模，并引入互邻域对比（MC）损失以保持邻域间的拓扑一致性。DGDP与SFFG共同构成任务感知的“何处-如何”训练框架。在VLA基准上的大量实验表明，LEEVLA始终优于先前方法，证实了显式任务证据引导与结构化潜在推理对于可扩展VLA均至关重要。我们的代码可在https://github.com/LyuQi127/LEEVLA获取。

## Abstract
Vision-language-action (VLA) models aim to map multimodal inputs to robot actions. However, most existing approaches struggle to cover complex dynamic scenarios due to treating all visual tokens uniformly and reasoning with human-selected factors, which lack mechanisms to emphasize task-critical evidence and ignore underlying factors. To address this issue, we propose LEEVLA, a VLA architecture for seeing what matters in Latent Environment Evolution that explicitly guides the model toward informative regions while preserving the structured evolution of latent world representations. To identify salient and instruction-relevant regions, we introduce drift-guided dynamic prioritization (DGDP), which combines dynamic position prioritization (DPP) with semantic drift guidance (SDG) to guide the VLA agent where to attend during training. On top of this, we introduce structured feature flow generation (SFFG), which models how these prioritized features should evolve in latent space via prototype-to-periphery (P2P) prediction, and a mutual-neighborhood contrastive (MC) loss to maintain topological consistency among neighborhoods. Together, DGDP and SFFG form a task-aware "where-how" training framework. Extensive experiments on VLA benchmarks show that LEEVLA consistently outperforms prior methods, confirming that explicit task-evidence guidance and structured latent reasoning are both crucial for scalable VLA. Our code is available at https://github.com/LyuQi127/LEEVLA.

*   **核心问题**：现有视觉-语言-动作（VLA）模型在处理复杂动态场景时面临两大瓶颈：
    *   **“何处关注”的缺失**：大多数方法对所有的视觉 token（代表图像中的不同区域）一视同仁，无法突出显示对任务至关重要的区域（如机器人与目标物体交互的区域），导致模型在训练时，梯度信号被大量静态背景或无关物体所“稀释”。
    *   **“如何演化”的局限**：现有方法（如RT-2、OpenVLA）主要依赖人工定义的、具体的上下文线索（如子目标图像、分割掩码、深度图）进行推理。这严重依赖于这些外部线索的准确性，同时限制了模型在潜在空间中探索未知但任务相关的因素，导致模型泛化能力弱，在面对模态间变化或模态内相似物体时表现脆弱。
*   **研究动机**：作者认为，解决之道在于让VLA模型**直接在高维潜在特征空间中进行推理**，而非在人工限定的低维空间中。成功的视觉模型（如DINOv2）产生的特征本身就已经嵌入了丰富的多模态信息（如语义、外观、几何）。通过直接对这些特征进行演化推理，可以充分利用这些信息，并扩大策略的探索空间。同时，必须指导模型“关注”那些在动态变化和语义方向上与任务指令最相关的区域。
*   **整体含义**：论文提出 LEEVLA，一个 **“何处-如何”** 的训练框架。它通过两个核心模块——**漂移引导动态优先级（DGDP）** 和**结构化特征流生成（SFFG）**——显式地引导模型“关注”关键区域，并学习这些区域在潜在空间中的结构化演化方式，从而提升VLA模型的性能和泛化能力。

## 2. 论文提出的方法论

### 2.1 核心思想
LEEVLA的核心思想是**在训练过程中，通过辅助任务（未来特征预测）和注意力引导机制，让VLA模型学会有选择地关注并正确预测环境状态的潜在演化**。关键操作均在潜在特征空间完成，避免了对像素级重建或外部条件的依赖。

### 2.2 关键技术细节
LEEVLA框架由两个主要部分组成，仅在训练阶段启用，推理时无额外开销。

**A. 漂移引导动态优先级 (Drift-Guided Dynamic Prioritization, DGDP)**
该模块旨在回答“模型应该关注哪里”的问题，它由两个子模块组成：

1.  **动态位置优先级 (Dynamic Position Prioritization, DPP)**：量化每个空间位置的特征随时间变化的剧烈程度。
    *   计算时间 $t$ 和 $t+T$ 的视觉特征 $v_{t,i}$ 和 $v_{t+T,i}$ 之间的余弦相似度变化。
    *   变化越大（语义越动态），该位置的“动态性得分” $\theta_i$ 越高。
    *   <div align="center">
        $\theta_i = 1 - \cos(\mathbf{v}_{t, i}, \mathbf{v}_{t+T, i})$ 
        </div>

2.  **语义漂移引导 (Semantic Drift Guidance, SDG)**：确保模型关注的方向与语言指令一致。
    *   计算每个视觉 patch 与语言指令 token 的余弦相似度，得到“指令相关性得分” $r_{t,i}$。
    *   计算从时间 $t$ 到 $t+T$ 的指令相关性得分变化 $\Delta_i$，并归一化得到语义漂移引导因子 $\omega_i$。
        <div align="center">
        $r_{t,i} = \max_{1 \leq j \leq M} \langle \tilde{\mathbf{x}}_{t,i}, \tilde{\mathbf{c}}_j \rangle$
        </div>
        <div align="center">
        $\Delta_i = \text{clip}(\frac{r_{t+T,i} - r_{t,i}}{\tau}, -\delta, \delta)$
        </div>
        <div align="center">
        $\omega_i = \exp(\frac{\tilde{\Delta}_i}{\tau})$
        </div>
    *   该因子会**增强**那些语义向着任务指令方向演化（如背景变为目标物体的patch）的区域，并**抑制**那些语义与指令背离的区域。
3.  **优先级权重**：将动态性得分 $\theta_i$ 与语义漂移引导因子 $\omega_i$ 结合，得到最终的优先级权重 $\beta_i$，用于指导后续的损失计算。
    <div align="center">
    $\beta_i = \sigma(\omega_i \cdot \theta_i)$
    </div>

**B. 结构化特征流生成 (Structured Feature Flow Generation, SFFG)**
该模块旨在回答“如何让这些关注的特征正确演化”的问题，它由两个子模块组成：

1.  **原型到周边 (Prototype-to-Periphery, P2P) 预测**：替代传统的“扁平化 token 预测”，以保持特征空间的局部结构。
    *   **聚类**：对未来的多视角视觉特征 $f_{t+T}$ 进行聚类，得到若干簇 $c_{\ell}$，每个簇有质心 $\mu_{\ell}$。
    *   **排序**：在每个簇内，根据与簇质心的欧氏距离，将成员从近到远（原型 → 周边）排序，形成有序序列 $\overrightarrow{c_\ell}$。
    *   **损失计算**：根据排序后的序列，对每个成员的预测误差施加 **P2P 预测损失**。原型附近的 loss 权重更低（基础权重 $\alpha$ 加上优先级权重 $\beta_j$），周边权重更高。这鼓励模型先学习稳定的原型的演化，再学习细节的演化。
        <div align="center">
        $\mathcal{L}_{P2P} = \frac{1}{|\mathcal{C}|} \sum_{\ell=1}^{|\mathcal{C}|} \frac{1}{|\overrightarrow{c_\ell}|} \sum_{j \in \overrightarrow{c_\ell}} (\alpha + \beta_j) \phi(\hat{\mathbf{v}}_{t+T,j}, \mathbf{v}_{t+T,j})$
        </div>

2.  **互邻域对比 (Mutual-neighborhood Contrastive, MC) 损失**：在嘈杂的数据中，为对比学习构建更可靠的“正样本对”。
    *   **构建邻域图**：为每个特征点 $i$，构建一阶邻居 $G^{(1)}_i$（Top-K相似）和二阶邻居 $G^{(2)}_i$（一阶邻居的Top-M邻居的并集）。
    *   **筛选互邻居**：只保留那些互为邻居的节点作为正样本集合 $G^+_i$，这能有效过滤掉聚类噪声引入的虚假或不对称连接。
    *   **损失计算**：使用InfoNCE损失，将正样本对在特征空间中拉近，同时推开负样本。这有助于维持局部特征的拓扑一致性。
        <div align="center">
        $\mathcal{L}_{MC} = -\frac{1}{|I|} \sum_{i \in I} \frac{1}{|G^+_i|} \sum_{j \in G^+_i} \log \frac{\exp(S_{ij} / \tau_c)}{\sum_{l \in V \backslash \{i\}} \exp(S_{il} / \tau_c)}$
        </div>

**C. 总体训练目标**
LEEVLA的最终目标是三个损失的加权和：
<div align="center">
$\mathcal{L}_{total} = \lambda_1 \mathcal{L}_{action} + \lambda_2 \mathcal{L}_{P2P} + \lambda_3 \mathcal{L}_{MC}$
</div>

其中 $\mathcal{L}_{action}$ 是对真实动作的 L1 回归损失。

*   **零样本泛化能力**：论文主要关注在给定演示数据上进行策略学习，而没有探讨在完全无演示的新任务上进行零样本泛化的能力。
*   **超参数敏感性**：DGDP 中的温度 $\tau$、截断值 $\delta$ 等超参数，以及SFFG中的聚类数 $L$、K值、M值等，其设置可能对最终性能有影响，文中对这些参数的选择和敏感性分析不够深入。
*   **潜在偏差**：DGDP模块依赖于对特征的余弦相似度计算，这可能引入对视觉表象（appearance）的偏差。例如，外观变化剧烈但语义不变的运动（如机械臂自身关节运动与目标物体运动之间的混淆）可能难以完美区分。
