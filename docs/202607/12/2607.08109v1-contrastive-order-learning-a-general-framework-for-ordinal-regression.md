## 摘要
我们提出了对比有序学习（ConOrd），一种用于序数回归的对比学习框架，融合了对比学习和有序学习的优势。虽然对比学习有效地利用了批次中的所有样本，但它通常忽略了等级标签之间的内在顺序。相反，有序学习显式地建模标签的序数性，但通常依赖于局部的、基于边界的比较，限制了其捕捉全局序数结构的能力。ConOrd通过引入基于等级差异的软亲和度和差异权重的对比有序损失来克服这些限制，从而能够对批次内所有样本对之间的序数关系进行细粒度建模。在包括面部年龄估计、无参考图像质量评估和无参考视频质量评估等一系列序数回归任务上的大量实验表明，ConOrd始终达到最先进的性能，并且在各种序数回归场景中具有良好的泛化能力。源代码可在 https://github.com/cwlee00/ConOrd 获取。

## Abstract
We propose contrastive order learning (ConOrd), a contrastive learning framework for ordinal regression that integrates the strengths of contrastive learning and order learning. While contrastive learning effectively leverages all samples in a batch, it typically ignores the inherent ordering among rank labels. Conversely, order learning explicitly models label ordinality but often relies on local, margin-based comparisons, limiting its ability to capture global ordinal structure. ConOrd addresses these limitations by introducing a contrastive order loss with soft affinity and disparity weights based on rank differences, enabling fine-grained modeling of ordinal relationships across all sample pairs within a batch. Extensive experiments on a range of ordinal regression tasks, including facial age estimation, blind image quality assessment, and blind video quality assessment, demonstrate that ConOrd consistently achieves state-of-the-art performance and generalizes well across diverse ordinal regression scenarios. The source code is available at https://github.com/cwlee00/ConOrd.

# 结构化总结：Contrastive Order Learning: A General Framework for Ordinal Regression

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **问题**：序数回归（ordinal regression）旨在预测具有内在顺序的标签（如年龄、图像质量分）。现有方法存在两个主要局限：
  - **对比学习**（如SupCon、RnC）能有效利用批次中所有样本，但通常忽略标签间的序数关系，或将序数差异硬性二值化，丢失细粒度信息。
  - **有序学习**（如GOL）显式建模标签顺序，但依赖局部、基于边界的成对比较，无法捕获全局序数结构，且一旦满足边界即停止梯度。
- **目标**：提出一个统一框架，同时利用对比学习的批次级交互和有序学习的序数先验，实现全局一致且细粒度的序数表示学习。

## 2. 论文提出的方法论

### 2.1 核心思想
- 设计**对比有序损失**（Contrastive Order Loss, $L_{\text{ConOrd}}$），在批次内对所有样本对引入基于等级差异的**软亲和权重** $a_{ij}$ 和**软差异权重** $b_{ij}$，从而在单个损失中同时实现：
  - 对相似等级样本的吸引（affinity）
  - 对相异等级样本的排斥（disparity）
- 结合**中心损失**（center loss）$L_{\text{center}}$ 以提升类内紧凑性。

### 2.2 关键技术细节
- **相似度度量**：使用负欧氏距离 $\kappa_{ij} = -\|z_i - z_j\|_2^2$。
- **亲和权重**：$a_{ij} = 1 / ((r_i - r_j)^2 + \epsilon)$，随等级差距增大而减小。
- **差异权重**：$b_{ij} = (r_i - r_j)^2$，随等级差距增大而增大。
- **损失定义**：
  $$L_{\text{ConOrd}} = -\frac{1}{2N} \sum_{i=1}^{2N} \frac{1}{|A(i)|} \log \frac{\sum_{j \in A(i)} a_{ij} e^{\kappa_{ij}/\tau}}{\sum_{j \in A(i)} b_{ij} e^{\kappa_{ij}/\tau}}$$
  - $A(i)$ 为批次中除锚点 $i$ 外的索引集，$\tau$ 是温度参数。
- **梯度行为**：梯度的符号由 $(a_{ij}/\alpha_i - b_{ij}/\beta_i)$ 决定，其中 $\alpha_i = \sum_j a_{ij} e^{\kappa_{ij}/\tau}$, $\beta_i = \sum_j b_{ij} e^{\kappa_{ij}/\tau}$。使得相似等级样本被拉近，相异等级样本被推远。
- **指数核的局部性**：$e^{\kappa_{ij}/\tau}$ 权重仅对嵌入空间中已近的样本对生效，实现细粒度局部调整。
- **总损失**：$L_{\text{total}} = L_{\text{ConOrd}} + L_{\text{center}}$，其中 $L_{\text{center}} = \sum_i \|z_i - \mu_{r_i}\|_2$，$\mu_m$ 为等级 $m$ 的可学习参考点。
- **推理**：使用 $k$-NN 估计测试样本的等级：$\hat{r}_t = \frac{1}{k} \sum_{i: x_i \in \mathcal{N}} r_i$。
