## 摘要
社会影响力对话通过改变内部认知状态来改变用户行为。核心评估问题是用户的信念、愿望、意图和情感在对话过程中是否发生了可测量的变化，这是一个面向过程的准则，无论是表面级别的文本度量（BLEU/ROUGE）还是单轮评分的LLM判断都无法捕捉。我们提出了**认知世界模型（CogWM）**，一种基于LLM的用户模型，将多轮对话评估从“用户说了什么”重新定义为“用户的内部认知状态如何演变”。CogWM联合预测BDI/E认知状态和用户话语，既作为用户模拟器也作为评估平台，使用三级评估框架：轮次级保真度、轨迹级状态动态和任务级综合评分。通过我们的**总结与分配（SaA）**标注流程，在四个社会影响力场景的150,454个用户轮次样本上训练，CogWM达到了77.6%的情感准确率（是GPT-5.5的2.1倍）。在3600个多智能体判别试验中，它根据认知影响力区分了六个商业智能体，Llama-4-Scout排名第一（CTS +0.233）。CogWM将社会影响力对话评估从终端判断转向过程追踪。我们已发布代码\footnote{\scriptsize 代码：https://github.com/lucianma05-create/CogWM}和模型\footnote{模型：https://www.modelscope.cn/models/LucianMa/CogWM-14B}。

## Abstract
Social influence dialogue changes user behavior by altering internal cognitive states. The central evaluation question is whether the user's beliefs, desires, intentions, and emotions measurably change over the course of conversation, a process-oriented criterion that neither surface-level text metrics (BLEU/ROUGE) nor single-score LLM judgments can capture. We propose the \textbf{Cog}nitive \textbf{W}orld \textbf{M}odel \textbf{(CogWM)}, an LLM-based user model that reframes multi-turn dialogue evaluation from ``what did the user say'' to ``how did the user's internal cognitive state evolves.'' CogWM jointly predicts BDI/E cognitive states and user utterances and serves as both a user simulator and an evaluation platform, using a three-tier evaluation framework that covers turn-level fidelity, trajectory-level state dynamics, and task-level composite scoring. Trained via our \textbf{S}ummarize-\textbf{a}nd-\textbf{A}llocate \textbf{(SaA)} annotation pipeline on 150,454 user-turn samples across four social influence scenarios, CogWM achieves 77.6\% emotion accuracy (2.1$\times$ over GPT-5.5). In 3600 multi-agent discrimination trials, it distinguishes six commercial agents by their cognitive influence, with Llama-4-Scout ranking first (CTS +0.233). CogWM moves social influence dialogue evaluation from terminal judgment to process tracking. We have released our code\footnote{\scriptsize Code: https://github.com/lucianma05-create/CogWM} and models\footnote{Model: https://www.modelscope.cn/models/LucianMa/CogWM-14B}.

## 一、论文的核心问题与整体含义（研究动机和背景）

社会影响力对话（Social Influence Dialogue, SID）在情感支持、慈善劝说、个性化推荐等场景中普遍存在，其核心目标是通过对话改变用户的内部认知状态（信念、愿望、意图、情感）。然而，现有评估方法存在严重不足：

- **表面文本指标**（如BLEU/ROUGE）仅关注词法重叠，完全忽略对话的社会影响目标。
- **LLM-as-Judge**（如MT-Bench）虽能评估语义质量，但仍是终局性单次评分，无法反映认知状态在对话过程中的演化轨迹。
- **人工评估**成本高、难扩展，且难以在轮次粒度上追踪认知状态。
- **现有用户模拟器**（如DuetSim）仅预测用户下一句文本，不建模内部认知状态，无法解释“用户为什么这样说”。

因此，亟需一种能**从过程层面**追踪用户内部认知状态动态变化**的评估方法**。本文提出**认知世界模型（CogWM）**，将评估问题从“用户说了什么”重新定义为“用户内部认知状态如何演变”。

## 二、论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想

CogWM 是一个基于 LLM 的用户模型，同时预测用户的**BDI/E认知状态**（Belief-信念、Desire-愿望、Intention-意图、Emotion-情感）和**自然语言话语**。它将多轮对话建模为用户认知状态的轨迹，从而支持过程级的社会影响力评估。

### 2.2 BDI/E 认知状态表示

每个时间步的用户状态 $S_t$ 包含四个维度：

- **Belief**：用户相信、判断或解释的内容。
- **Desire**：用户想、需要或偏好的内容。
- **Intention**：用户计划、决定或承诺的内容。
- **Emotion**：当前情感状态及其强度。

情感用12个离散类别表示（如希望、焦虑、内疚等），每个类别有固定效价 $v_e$，强度 $s_e \in \{1,2,3\}$，量化得分为 $e_t = v_e \cdot s_e$。信念、愿望、意图则根据任务用 $[0,2]$ 的分数量化，具体含义因场景不同（见表3）。

### 2.3 三阶段评估框架

CogWM 作为一个评估平台，与被测对话智能体连接，逐轮输出用户的认知状态和话语，并采用三层评估体系：

1. **轮次层（Turn-level）**：评估单轮响应的质量，使用8个自动指标（E-Acc, B-Sim, D-Sim, I-Sim, E-MAE等）和5个LLM-as-Judge语义指标（Emo, Bel, Des, Int, Coh等）。
2. **轨迹层（Trajectory-level）**：用金融时间序列分析中的方法（AUC、PSR、Δ、Mono）建模多轮状态演化。基于任务加权的每轮综合分数 $Comp_t = w_E \cdot E\_val_t + w_B \cdot B_t + w_D \cdot D_t + w_I \cdot I_t$。
3. **任务层（Task-level）**：汇聚为两个互补指标——**复合轨迹得分CTS**（$0.40 \cdot AUC + 0.30 \cdot PSR + 0.30 \cdot \Delta$）和**良好结果GO**（由LLM Judge判断对话最终是否达成任务目标）。

### 2.4 数据构建与训练：Summarize-and-Allocate (SaA) 标注方法

使用四个公开对话数据集：DailyDialog（开放域）、ESConv（情感支持）、P4G（慈善劝说）、DuRecDial（任务导向推荐）。SaA 分两阶段：

- **阶段1（全局总结）**：从完整对话中提取全局BDI项目及其量化分数。
- **阶段2（时间分配）**：按轮次分配BDI/E状态，附证据来源和全局引用。

人工验证表明 SaA 有效：BDI召回率0.79，精确率0.77，情感Cohen's κ=0.69。

最终得到**150,454个用户轮次训练样本**，基于 Qwen3-14B Instruct 进行 LoRA 微调，联合优化状态预测和话语生成：$p(u_{t+1}, S_{t+1} \mid D_{\leq t}, P, C)$。

### 2.5 用户画像条件输入

包括大五人格（1-5分）、沟通风格、决策风格、任务相关特征，并附带置信度（1-3级）避免过拟合。

## 六、论文的主要结论与发现

1. **CogWM显著超越所有基线**：情感准确率77.6%（GPT-5.5为36.4%，2.1倍），BDI/E语义相似度也全面领先；话语长度比接近1.0（GPT-5.5为1.82），更接近真实对话节奏。
2. **联合训练的必要性**：仅训练话语生成的模型（utt-only-14B）BDI/E预测极差，说明认知状态追踪必须显式联合优化。
3. **智能体区分能力**：在3600次交互中，CogWM能有效区分不同商业智能体的认知影响力，Llama-4-Scout在CTS上排名第一（+0.233），Gemini-3-Pro最差（+0.140）。
4. **CTS与GO互补**：轨迹级认知改善（CTS）与对话级行为结果（GO）并不等价。Llama CTS最高但GO排第4，Qwen CTS第2但GO第1。案例C8-C9进一步展示相同/不同的CTS与GO组合。
5. **思维链（CoT）影响不对称**：GPT-5.5受益最大，已强的模型（Llama, Qwen）增益有限，DeepSeek几乎无变化。
6. **任务难度差异**：DuRecDial最容易（E-Acc 90.1%），ESConv和DailyDialog最难（~59%）。场景属性是性能的主要决定因素。
7. **画像贡献不对称**：单一项移除对状态预测影响小（<2pp），但移除所有画像使BLEU-4下降72%，说明画像对个性化生成至关重要。
8. **认知-情感分歧**：在推荐任务中，所有智能体改善了综合分数但降低了情感分数，揭示过程评价的必要性。

## 七、优点

1. **创新的问题定义**：将对话评估从终端判断转向过程追踪，首次显式建模BDI/E四维认知状态轨迹。
2. **完整的三级评估框架**：从轮次到轨迹到任务，提供可分解、可解释的评估体系。
3. **高效的SaA标注方法**：利用LLM进行全局总结+时间分配，产生大规模高质量标注（150K样本），人工验证有效。
4. **丰富的实验验证**：涵盖保真度、区分性、消融、规模、任务差异、案例分析，并与多个商业API对比，证明实用价值。
5. **可解释性与可控性**：BDI/E轨迹使智能体影响力的来源可追溯到具体维度与轮次。
6. **开源与可复现**：发布代码和模型，降低使用门槛。

## 八、不足与局限

1. **标注质量限制**：当前标注为LLM生成，虽经人工验证（BDI召回0.79，情感κ=0.69），但隐含信念、未表达愿望等精细状态可能被遗漏。需要扩展到更多真实人类标注。
2. **模拟用户而非真人**：实验全部基于CogWM模拟的用户，未与真实人类交互验证评估的有效性。模拟可能无法完全捕捉真实用户的复杂反应。
3. **场景覆盖有限**：仅包含情感支持、慈善劝说、推荐、日常对话四类，未涵盖谈判、辩论等其他社会影响场景。
4. **评估指标依赖LLM Judge**：部分指标（如GO）使用LLM Judge判断，可能引入偏见或与下游任务不一致。
5. **任务特定权重预设**：Comp_t的权重（表13）需手动设定，不同任务间通用性受限。
6. **模型训练资源**：仅基于单A100-80G训练14B模型，更大模型（32B）结果未报告（文中标注“pending”），限制了可扩展性结论。
7. **CTS权重设定**：公式(3)中AUC、PSR、Δ的权重（0.40, 0.30, 0.30）基于经验，缺乏严格最优性论证。
