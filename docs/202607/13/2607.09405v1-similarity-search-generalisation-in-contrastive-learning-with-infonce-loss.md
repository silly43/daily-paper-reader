## 摘要
相似性搜索是由对比学习训练的嵌入模型的主要应用。对于最流行的对比学习损失函数之一InfoNCE，我们展示了具有$k$个负样本的总体风险与期望交叉熵相差$O(1/k)$，该交叉熵量化了以下两者之间的偏差：i) 使用学习到的嵌入函数在未见数据上的softmax相似性搜索，以及ii) 使用正样本生成器中隐含表示的相似性对相同数据进行的理想化softmax搜索。这补充了在$k\to\infty$极限下对InfoNCE的现有解释，这些解释以互信息以及嵌入中的对齐与均匀性来表述。为了量化泛化性能，我们通过Gâteaux微分引入了一个新的InfoNCE损失连续性界。该界保留了损失函数中对负样本进行平均的结构，并具有一个“逆温度”参数，该参数可以调整以考虑算法温度。对于参数Lipschitz的嵌入函数，这简单地证明了InfoNCE损失中$k$个负样本的平均效应会随着$k$的增长而延续到泛化误差的稳定化。

## Abstract
Similarity search is a primary application of embedding models trained by contrastive learning. For one of the most popular contrastive learning loss functions, InfoNCE, we show that the population risk with $k$ negative samples is $O(1/k)$ close to an expected cross-entropy which quantifies deviation between i) a softmax similarity search over unseen data using the learned embedding function, and ii) an idealised softmax search over the same data but using similarity implicitly represented in the positive sample generator. This complements existing interpretations of InfoNCE in the $k\to\infty$ limit which are phrased in terms of mutual information, and alignment versus uniformity in embeddings. To quantify generalisation performance, we introduce a new continuity bound for the InfoNCE loss, obtained via Gâteaux differentiation. The bound preserves the structure of averaging over negative samples present in the loss function and features an ``inverse temperature'' parameter which can be tuned to account for the algorithmic temperature. For embedding functions which are Lipschitz in a parameter, this yields a simple demonstration that the averaging effect of $k$ negative samples in the InfoNCE loss carries over to stabilisation of the generalisation error as $k$ grows.

> 对于 InfoNCE 损失，当负样本数 $k$ 有限时，其总体风险与一个理想化的相似性搜索之间的差距是多少？如何量化嵌入函数泛化到未见数据时的性能？

整体含义：本文为 InfoNCE 损失提供了一种新的解释——将其与基于 softmax 的相似性搜索的期望交叉熵联系起来，并证明差距为 $O(1/k)$，同时通过 Gâteaux 微分导出了一个保留负样本平均结构的连续性界，从而说明 $k$ 的增大如何稳定泛化误差。这补充了现有理论，并为对比学习中负样本数量的作用提供了更精确的定量分析。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 解释 InfoNCE 总体风险与相似性搜索的关系

- **设定**：输入空间 $Z$，数据分布 $\pi_{\text{data}}$，正样本生成核 $M(z, \cdot)$。对于嵌入函数 $\phi \in B(Z, S^{d-1})$（$\|\phi(z)\|_2 = 1$），定义 Markov 核：
  - 理想核 $Q_\phi^\tau(z, A) = \frac{\int_A e^{\langle\phi(z),\phi(z')\rangle/\tau}\pi_{\text{data}}(dz')}{\int_Z e^{\langle\phi(z),\phi(z')\rangle/\tau}\pi_{\text{data}}(dz')}$；
  - 经验核 $\hat{Q}_{\phi,m}^\tau(z, A) = \frac{\sum_{i=1}^m e^{\langle\phi(z),\phi(\xi_i)\rangle/\tau}\delta_{\xi_i}(A)}{\sum_{i=1}^m e^{\langle\phi(z),\phi(\xi_i)\rangle/\tau}}$，其中 $\xi_i$ 为未见数据。
- **命题1**：对于任意 $\phi$，InfoNCE 总体风险 $R(\phi;k,\tau)$ 与 $\int_Z \text{CrossEnt}[M(z,\cdot)\|Q_\phi^\tau(z,\cdot)]\pi_{\text{data}}(dz)$ 之差为 $O(1/k)$，且界一致于 $\phi$。这意味着当 $k$ 大时，最小化 $R$ 等价于最小化 $M$ 与 $Q_\phi^\tau$ 之间的交叉熵，即学习 $M$。
- **命题2**：在假设 $M(z,\cdot) \ll \pi_{\text{data}}$ 下，风险 $R(\phi;k,\tau)$ 也 $O(1/k)$ 接近于期望的交叉熵 $\mathbb{E}[\text{CrossEnt}[\hat{M}_k(z,\cdot)\|\hat{Q}_{\phi,k}^\tau(z,\cdot)]]$，其中 $\hat{M}_k$ 是通过重要性加权构建的理想化经验核。这解释了 softmax 相似性搜索如何逼近 $M$ 隐含的相似性。

### 2.2 泛化分析：Gâteaux 微分与连续性界

- 为了量化泛化误差，论文采用经验 Rademacher 复杂度框架（Proposition 3）。关键创新是 **Proposition 4**：对于任意 $k,\tau,\beta\ge1$，InfoNCE 损失函数 $\ell(\phi,z,k,\tau)$ 关于 $\phi$ 满足：
  $$
  |\ell(\phi,z,k,\tau)-\ell(\phi',z,k,\tau)|
  \le \frac{4}{\tau}\|\phi(z_a)-\phi'(z_a)\|_2 + \frac{1}{\tau}\|\phi(z^+)-\phi'(z^+)\|_2
  + \frac{3}{\tau}e^{2/(\beta\tau)}\left(\frac{1}{k}\sum_{j=1}^k \|\phi(z^-_j)-\phi'(z^-_j)\|_2^\beta\right)^{1/\beta}.
  $$
  该界保留了对负样本的**平均结构**（而非最大值），其中 $\beta$ 为逆温度参数，可调节以适应算法温度。

- 基于该连续性界，若嵌入函数满足参数 Lipschitz 条件（假设 C）：$\|\phi_\theta(z)-\phi_{\theta'}(z)\|_2 \le C_\Phi \|z\|_2\|\theta-\theta'\|_2$，则利用 Dudley 熵积分可推出 **Proposition 5**：经验 Rademacher 复杂度以 $O(\tau^{-1}\sqrt{d_\Theta/n})$ 为上界，且其中出现的 $B_\tau$ 项包含负样本范数的幂平均，当 $k\to\infty$ 时该平均稳定，从而复杂度不受 $k$ 增长的负面影响。

- **Theorem 1** 综合以上结果，给出了以高概率成立的相似性搜索期望交叉熵的上界，包含三项：经验风险、复杂度惩罚（$O(n^{-1/2})$）、有限 $k$ 偏差（$O(1/k)$）。

### 2.3 对 DCL 损失的简化说明

- 对于移除“1+”项的 **Decoupled Contrastive Learning (DCL) 损失**，下界变为零，上界更简单（不含 $\log(1+e^{2/\tau}/k)$），且证明可以通过类似的泰勒展开得到 $O(1/k)$ 偏差。论文还构造了一个例子说明当 $\tau$ 很小时，$e^{1/\tau}$ 指数增长，导致 DCL 的 $O(1/k)$ 偏差可能远小于 InfoNCE 的偏差。

## 6. 论文的主要结论与发现

1. **InfoNCE 总体风险与理想相似性搜索的偏差为 $O(1/k)$**：该界一致于所有 $\phi\in B(Z,S^{d-1})$，且通过交叉熵解释与 $M$ 核学习联系起来。
2. **连续性界保留负样本平均结构**：通过 Gâteaux 微分导出的界避免了最大值算子，使负样本的方差随 $k$ 增大而减小，从而稳定泛化误差。
3. **Rademacher 复杂度对 $k$ 的依赖被消除**：对于 Lipschitz 嵌入函数，复杂度仅与参数维度 $d_\Theta$、样本量 $n$、温度 $\tau$ 有关，且随 $k$ 增加趋于稳定（因为 $B_\tau$ 中的幂平均在期望下收敛）。
4. **逆温度参数 $\beta$ 提供额外调节**：可通过选择 $\beta$ 匹配算法温度 $\tau$，优化泛化界（例如 $\beta=2/\tau$ 时 $e^{2/(\beta\tau)}=e$）。
5. **温度 $\tau$ 的双重作用**：低温（小 $\tau$）使 $Q_\phi^\tau$ 更灵活但泛化界更松（因为 $B_\tau$ 对负样本大范数更敏感），高温（大 $\tau$）则正则化 $Q_\phi^\tau$ 接近 $\pi_{\text{data}}$。
6. **早期停止可作为正则化**：若 $\theta_0$ 为优化起点，$R$ 为参数移动距离，则 $R\to0$ 时复杂度为零，支持早停的规则化效果。
