## 摘要
潜在世界模型通过学习条件于动作的预测动力学，并将其用作内部模拟器来想象和评估候选动作序列，已成为一种强大的规划范式。然而，随着规划视野的增长，性能越来越受限于提议质量：固定的候选预算必须在呈指数级增长的动作空间中进行搜索，这使得世界模型难以接触到高质量的候选未来用于评估。本文提出了一种先验条件规划器，用结构化指导替代随机提议初始化。在每个规划阶段，一个目标条件生成器会预测指定时间内可达到的下一个潜在子目标，并以此条件生成候选动作序列。为了捕获跨时间尺度的语义信息，我们使用不同持续时间的子目标作为先验，平衡细粒度的局部控制与更高层次的长期进展。然后，在执行前，冻结的世界模型会评估并优化这些受子目标条件约束的提议。在PushT和OGBench Cube上的实验表明，将潜在子目标分解与先验条件动作生成相结合，能在保持较强短期性能的同时显著提升长期规划能力。具体而言，当目标偏移量为150时，PushT的成功率从12.7%提升至64.7%，OGBench Cube的成功率从26.7%提升至67.3%。

## Abstract
Latent world models have emerged as a powerful planning paradigm by learning action-conditioned predictive dynamics and using them as internal simulators to imagine and evaluate candidate action sequences. However, as the planning horizon grows, performance becomes increasingly constrained by proposal quality: a fixed candidate budget must search an exponentially larger action space, making it difficult to expose the world model to high-quality candidate futures for evaluation. In this paper, we introduce a prior-conditioned planner that replaces random proposal initialization with structured guidance. At each planning stage, a goal-conditioned generator predicts the next reachable latent subgoal for a specified duration, which is then used to condition the generation of candidate action sequences. To capture semantic information across temporal scales, we use subgoals of varying durations as priors, balancing fine-grained local control with higher-level long-horizon progress. Then the frozen world model evaluates and refines these subgoal-conditioned proposals before execution. Experiments on PushT and OGBench Cube show that coupling latent subgoal decomposition with prior-conditioned action generation substantially improves long-horizon planning while preserving strong short-horizon performance. To be specific, when the target offset is $150$, it raises PushT success from $12.7\%$ to $64.7\%$ and OGBench Cube success from $26.7\%$ to $67.3\%$.

## 1. 论文的核心问题与整体含义（研究动机和背景）

潜在世界模型（Latent World Models）通过学习动作条件预测动力学，并利用其作为内部模拟器来想象和评估候选动作序列，已成为一种强大的规划范式。然而，随着规划时域（horizon）的增长，模型性能受到**提议质量**的严重制约：在固定候选预算下，动作空间呈指数增长，随机初始化难以采样到高质量的目标导向动作序列，导致世界模型无法接触到好的候选未来用于评估。现有方法如 LeWM、DINO-WM 等主要聚焦于改进预测模型本身，而忽略了**提议机制**的结构化设计。因此，本文提出 SAGE（Subgoal-Conditioned Action Generation），通过引入结构化先验（子目标条件动作生成）来提升长时域规划性能，同时保持短时域表现。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：将长时域规划分解为两个紧密耦合的决策：**预测可达的潜在子目标**，以及**条件于该子目标生成动作序列**。用结构化先验替代随机初始化，使动作搜索集中于可行行为。
- **两阶段框架**：
  1. **子目标生成器（Subgoal Generator）**：输入当前历史隐状态 $z_{t-k:t}$、低维状态 $x_t$、远目标隐状态 $z_{g_{t+\delta}}$、剩余目标偏移 $\delta$ 以及请求的局部时长 $\tau$，输出预测的局部子目标隐状态 $\hat{z}_{t+\tau}$。采用残差形式 $\hat{z}_{t+\tau} = z_{g_{t+\delta}} + D_\psi(\cdot)$，确保输出在 LeWM 隐空间中。使用四层 Transformer 解码器，训练时匹配冻结 LeWM 的真实局部隐状态（Smooth L1 + 余弦损失）。
  2. **子目标条件动作生成器（Action Generator）**：以历史隐状态、低维状态、预测子目标 $\hat{z}_{t+\tau}$、远目标隐状态以及 $(\delta,\tau)$ 为条件，生成时长 $\tau$ 的动作序列分布。使用三层 Transformer 解码器，输出一个高斯混合模型（GMM，8个模态），每个高斯对应一个完整的动作选项。动作查询嵌入每5个环境动作作为一组，通过时长掩码激活对应数量的查询。训练时最大化专家动作序列的对数似然。
- **规划流程**：在线规划时，将总时域 $H$ 分解为一系列局部时长 $\tau_1,\ldots,\tau_R$。在每一阶段，子目标生成器预测 $\hat{z}_{t+\tau_r}$，动作生成器从中采样 $K$ 个候选动作选项，冻结的 LeWM 根据与子目标的匹配程度对这些选项进行评分，并使用交叉熵方法（CEM）迭代优化 30 轮。选取最优动作序列执行 $\tau_r$ 步后进入下一阶段。
- **单一生成器支持多个时长**：$\tau \in \{15,20,25\}$，远目标偏移 $\delta \in \{15,20,\ldots,150\}$，共享参数，实现多时间尺度的统一规划。

## 6. 论文的主要结论与发现

- SAGE 在长时域规划上显著优于 Base CEM 和 PRISM。当 $H=150$ 时，PushT 成功率从 12.7% 提升至 64.7%，Cube 从 26.7% 提升至 67.3%。
- 短时域表现也保持甚至提升：$H=25$ 时 SAGE 达到 94.0%（PushT）和 98.7%（Cube）。
- 局部子目标生成本身已带来显著提升（Generator-only 在 $H=150$ 时 PushT 达 58.7%），而子目标条件动作提议进一步带来额外改进。
- 世界模型引导的细化（LeWM + CEM）是关键：直接执行先验（SAGE prior top）在 $H=150$ 时仅 16.0%，远低于完整 SAGE 的 64.7%。
- 时长调度选择影响性能：更频繁的重新规划（更多阶段）和合理的时长顺序能提升成功率。例如 $H=125$ 时，15×7+20 调度达到 80%，而 25×5 仅 62%。
- 模型容量增加可改善长时域表现。

## 7. 优点：方法或实验设计上的亮点

- **结构化先验设计创新**：将子目标生成与动作生成耦合，而不是仅使用子目标作为优化目标（如 FF-JEPA）或简单的动作先验（如 PRISM），更充分地利用了任务结构。
- **统一的多时间尺度支持**：单一生成器通过条件输入 $(\delta,\tau)$ 支持多种子目标时长，无需为每个尺度训练独立网络，实用性强。
- **冻结世界模型兼容性**：不修改 LeWM 的编码器、动力学或成本函数，直接提升其规划能力，便于即插即用。
- **消融实验设计精巧**：Generator-only 隔离了子目标的贡献，SAGE prior top 隔离了世界模型细化的贡献，清晰揭示了各部分作用。
- **调度实验揭示新洞见**：展示了时长顺序对结果的影响，为未来的自适应时长策略提供依据。
- **结果统计可靠**：使用三个种子固定清单，报告均值和标准差，附录提供全量数据。
