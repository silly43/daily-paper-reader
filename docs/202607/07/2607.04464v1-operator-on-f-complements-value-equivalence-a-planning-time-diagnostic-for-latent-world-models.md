## 摘要
基于模型的强化学习中的世界模型评估通常询问学习的模型是否能很好地预测奖励和价值，这可能会使模型中与规划相关的错误在潜在展开中未被测量。我们引入了一个互补的诊断方法，operator-on-F，它比较模型的k步潜在前推与环境在可观测子集F上的结果，使用模型自身的预测器。在cheetah-run上对TD-MPC2进行规模扫描，每个模型大小的奖励预测误差保持在[0.028, 0.091]之间——仅约3倍变化——因此非归一化的奖励拟合检查分辨能力有限，难以区分它们；（非归一化的）贝尔曼残差和奖励误差本身与回报的关系较弱（Spearman相关系数分别为-0.10和-0.30）。相同规模下，算子误差范围在0.28到2.62之间。在317M规模下，算子误差为2.62——比0.28-0.36簇高一个数量级——规划回报骤降至0.9，而奖励预测误差（0.091）是五个中最高，但仍保持在扫描其他部分相同的[0.028, 0.091]小范围内。算子误差与回报损失之间的秩相关系数为-0.90（在n=5个规模下，锚自举95%置信区间[-0.90, -0.70]；留一法去除任意单个规模后仍为-0.80或更强）。在TD-MPC2和纯SSL潜在世界模型之间的跨架构比较中，算子也返回了信息丰富、可区分架构的估计。算子诊断补充了值等价，而非替代它。

## Abstract
World-model evaluation for model-based reinforcement learning typically asks whether the learned model predicts reward and value well, which can leave planning-relevant errors in the model's latent rollouts unmeasured. We introduce a complementary diagnostic, operator-on-F, that compares a model's k-step latent pushforward to the environment's on an observable subset F, using the model's own predictor. On a TD-MPC2 size sweep over cheetah-run, reward-prediction error stays within [0.028, 0.091] for every model size - only about 3x variation - so an unnormalized reward-fit check has narrow resolution to distinguish them; the (unnormalized) Bellman residual and reward error themselves have weak relationships with return (Spearman -0.10 and -0.30). Operator error spans 0.28 to 2.62 over the same sizes. At 317M the operator error is 2.62 - an order of magnitude above the 0.28-0.36 cluster - and the planning return collapses to 0.9, while reward-prediction error (0.091) is the highest of the five but stays within the same small [0.028, 0.091] range as the rest of the sweep. The rank correlation between operator error and return loss is -0.90 (anchor-bootstrap 95% CI [-0.90, -0.70] at n=5 sizes; leave-one-out removal of any single size leaves it at -0.80 or stronger). The operator also returns informative, architecture-discriminating estimates in a cross-architecture comparison between TD-MPC2 and a pure-SSL latent world model. The operator diagnostic complements value-equivalence rather than replacing it.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **问题背景**：在基于模型的强化学习中，世界模型通常通过奖励预测误差或值误差来评估，即检查模型能否准确预测奖励和值函数。然而，这种评估可能遗漏与规划相关的潜在空间错误——即使奖励和值预测良好，模型的潜在动态推演（latent rollout）可能已经偏离了环境的真实动态。
- **核心动机**：现有值等价（value-equivalence）原则认为，对于规划而言，模型正确预测奖励和值就够了；但当学习和规划目标不一致时，奖励预测检查可能对规划关键的失败模式保持沉默。需要一个能在规划时识别潜在推演误差的互补诊断方法。
- **整体含义**：提出 operator-on-F 诊断，在可观测子集 F（如奖励、值或观测特征）上比较模型的 k 步潜在前推与环境编码的真实下一状态，从而揭示奖励/值预测无法捕捉的模型缺陷。该诊断补充而非替代值等价。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 定义 **operator-on-F**：对于锚点 $(s_t, a_{t:t+k-1}, s_{t+k})$，模型的 $k$ 步潜在推演记为 $\hat{z}_{t+k} = O^k(z_t, a_{t:t+k-1})$，环境编码的真实下一状态为 $z'_{t+k} = \text{enc}(s_{t+k})$。
- 选择一个可观测子集 $F$（包含奖励、值函数，或通过探针（probe）$\phi_F: Z \to F$ 从潜在空间读出的观测特征），计算每个功能 $\phi \in F$ 的逐锚点算子误差：
  $$e_\phi(t) = \frac{\phi(\hat{z}_{t+k}) - \phi(z'_{t+k})}{\sigma_\phi}$$
  其中 $\sigma_\phi$ 是 $\phi(z')$ 在锚点池中的标准差。
- 对每个功能使用 RMS 聚合，再对整个 $F$ 取 RMS 得到最终 operator-on-F 值。

### 关键技术细节
- **F 的构成**：
  - **值切片（value slice）**：$F = \{r, V\}$，使用模型自身的奖励头和值头。
  - **全 F（full-F）**：值切片加上一个基于编码的下一状态几何的学习 PCA 基（前 16 个主方向，用奇异值白化）。PCA 在保留的一半锚点上拟合，在另一半上评估，防止基自适应于算子误差。
- **探针协议**：使用岭回归（ridge regression）对每个可观测功能训练线性探针 $\phi_F$，特征标准化，$\lambda$ 通过网格搜索在保留子集上选择。报告每个可观测量的 $R^2$ 以保证探针质量。使用正则化探针避免高维潜在空间的容量-信息混淆问题（如未正则化的岭回归可能导致负 $R^2$）。
- **原生使用**：operator-on-F 使用模型自身的预测器（native predictor），在规划所用的相同 $k$ 步下（论文中 $k=5$ 个收集步骤）。对于 TD-MPC2，进行 5 次开环潜在动态滚动；对于 LeWM，直接使用其帧跳 5 的预测。
- **基本性质**：operator-on-F 是一种 Koopman 风格的推演比较，在可观测子集上比较模型与环境的潜在动态。它不是一个训练目标，而是诊断工具。

## 6. 论文的主要结论与发现

1. **operator-on-F 揭示了值等价忽略的失败模式**：在 TD-MPC2 规模扫描中，奖励预测误差在所有大小上仅变化约 3 倍（0.028-0.091），而 operator 误差跨越 0.28-2.62（一个数量级变化）。317M 模型 operator 误差最高，规划回报崩溃至 0.9，但奖励误差仍在小范围。
2. **operator 误差与回报损失强相关**：全 F operator 误差与回报的秩相关为 -0.90（锚自举 95% CI [-0.90, -0.70]），留一法均 ≤ -0.80。相比之下，贝尔曼残差与回报的秩相关仅 -0.10，奖励误差为 -0.30。
3. **operator 与值等价代理分歧**：全 F operator 与贝尔曼残差的秩相关为 +0.30，而值切片（归一化）与贝尔曼残差相关也仅 +0.10。未归一化的值误差与贝尔曼残差几乎一致（Spearman +1.00），说明归一化是关键。
4. **跨架构区分性**：LeWM 在共享观测级 $F$ 上的 operator 误差为 0.384 ± 0.009，单任务 TD-MPC2 为 0.840（95% CI [0.79, 0.89]），CIs 不重叠，且被 MLP 探针、常见良好可探子集等消融保持。表明 operator 能区分不同架构的世界模型规划能力。
5. **operator 是值等价的补充**：不声称值等价错误，而是推荐同时报告两种诊断。

## 7. 优点：方法或实验设计上的亮点

- **方法创新性**：提出在可观测子集 $F$ 上比较模型潜在推演与环境推演，充分利用模型自身预测器，在规划时实时诊断，无需额外训练或环境交互。
- **归一化设计**：每个功能误差以其真实推演的标准差归一化，使得不同功能可比，且大大提高了与回报的相关性（未归一化则相关很弱）。
- **探针协议严谨**：使用正则化探针（岭回归 + λ 网格搜索）、报告 $R^2$、进行探针家族消融和不对称控制，避免了典型探针混淆问题（如高维潜在空间的容量-信息权衡）。
- **实验分析深入**：
  - 展示 rank correlation 和 bootstrap CI，量化不确定性。
  - 留一法验证秩稳健性。
  - 部分相关控制混杂变量。
  - 跨架构比较时进行多种控制（探针类型、常见可探子集、预测模式），增加了结论可信度。
- **清晰定位**：明确 operator-on-F 是 Koopman 风格的推演比较，不是训练目标，而是诊断工具；强调其补充而非替代值等价。

## 8. 不足与局限

- **环境覆盖有限**：所有主要实验仅在 `cheetah-run` 一个任务上进行。跨任务（如 walker-walk 等）只有简要提及，未系统展示 operator-error 与 return 的关系。
- **规模扫描样本量小**：$n=5$ 个模型大小，相关结论可能受单个点（317M）驱动。虽然留一法稳健，但通用性仍需更多规模点和分布外情况验证。
- **架构谱系窄**：跨架构比较仅包括 TD-MPC2（基于值学习的 Actor-Critic）和 LeWM（纯自监督 JEPA 风格），缺少如 DreamerV3 等具有重建损失的中介架构，限制了“operator 能区分架构”这一论断的广度。
- **探针仍是混杂因素**：尽管做了多种控制，共享 $F$ 在不同潜在几何上必须通过探针读出，探针质量（$R^2$）可能依赖于潜在表示的可读性，而不仅仅是模型本身的动态质量。论文通过常见良好可探子集部分缓解，但无法完全消除。
- **计算开销未讨论**：operator-on-F 计算需要收集锚点数据并进行探针拟合，在在线部署时可能带来额外开销。论文未讨论实用性或计算成本。
- **未与其他潜在诊断方法对比**：如动作影响度量、潜在表示一致性度量等，缺少与现有替代诊断的横向比较。
