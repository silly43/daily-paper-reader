## 摘要
世界模型为长周期LLM智能体提供了一种原则性的前向预测能力：在执行前预测行动后果。然而，不可靠的预测可能被忽略、误用，甚至削弱下游决策。本文提出WorldEvolver——一种自进化的世界模型框架，它在保持下游智能体和所有模型参数冻结的同时，修正其部署时的上下文。WorldEvolver集成了三个模块：（i）情节记忆，通过基于检索的模拟利用真实行动转移；（ii）语义记忆，从预测-观察不匹配中提取持久启发式规则；（iii）选择性前瞻，在将低置信度预测融入智能体推理上下文之前进行过滤。我们在ALFWorld和ScienceWorld上评估WorldEvolver，在Word2World上测量世界模型预测准确率，在AgentBoard上测量下游智能体成功率。大量实验表明，WorldEvolver在三个主干上取得了最高的预测准确率，并在下游智能体成功率上领先其他世界模型基线，证明了测试时记忆修正能同时提升预测保真度和规划性能。

## Abstract
World models offer a principled way to equip long-horizon LLM agents with foresight: predictions of action consequences before execution. However, unreliable foresight can be ignored, misused, or even degrade downstream decision-making. In this paper, we introduce WorldEvolver, a self-evolving world model framework that revises its deployment-time context while keeping the downstream agent and all model parameters frozen. WorldEvolver integrates three modules: (i) Episodic Memory, which exploits real action transitions through retrieval-based simulation; (ii) Semantic Memory, which extracts persistent heuristic rules from prediction-observation mismatches; and (iii) Selective Foresight, which filters low-confidence predictions before integrating them into agent reasoning context. We evaluate WorldEvolver on ALFWorld and ScienceWorld, measuring world model prediction accuracy on Word2World and downstream agent success rate on AgentBoard. Extensive experiments show that WorldEvolver achieves the highest prediction accuracy across three backbones and leads other world model baselines on downstream agent success rate, demonstrating that test-time memory revision enhances both predictive fidelity and planning performance.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：大语言模型（LLM）智能体在长周期规划中常使用世界模型预测行动后果（前向预测），但预测可能不可靠，导致智能体忽略、误用甚至被误导，反而降低决策质量。
- **背景**：现有方法要么保持世界模型冻结（导致分布偏移时预测不准），要么通过参数更新进行离线调优（计算成本高且易引发遗忘），缺乏在部署时自适应的在线机制。本文提出一种无需参数更新的自进化世界模型框架，通过测试时记忆修正来同时提升预测保真度和规划性能。

## 2. 论文提出的方法论

- **核心思想**：在冻结智能体和世界模型参数的前提下，通过动态修正世界模型的**推理上下文**（而非权重）来提升预测质量。具体集成三个互补模块：
  - **情节记忆（Episodic Memory, ME）**：存储已执行的真实转移三元组 $(o_t, a_t, o_{t+1})$，当需要预测某个候选动作的结果时，通过动作词集的Jaccard相似度检索最相似的历史转移，并作为上下文提供。
  - **语义记忆（Semantic Memory, MS）**：将预测与观察的不匹配（通过因子化三元组比较）转化为持久性启发式规则（如“检查物体不会移动它”），每条规则附带证据分数，仅保留正分规则，用于约束后续预测。
  - **选择性前瞻（Selective Foresight, Ft）**：计算预测输出的几何平均词概率作为置信度，仅当置信度超过阈值 $\tau$ 时才将预测暴露给智能体，否则不提供任何前瞻信号，避免不可靠预测的干扰。
- **算法流程（Algorithm 1）**：
  1. 从冻结策略采样草稿动作 $a_t^{(0)}$；
  2. 从ME检索 $k_{ME}$ 个相似转移；
  3. 查询世界模型 $W_\theta$（结合检索和语义规则）得到预测 $\hat{o}_{t+1}$ 和置信度 $q_t$；
  4. 根据 $q_t \geq \tau$ 决定是否提供前瞻；
  5. 重采样最终执行动作 $a_t$；
  6. 若动作不同，重新查询世界模型用最终动作；
  7. 执行动作，更新ME（追加真实转移），更新MS（若存在不匹配则批量生成规则并更新证据分数）。
