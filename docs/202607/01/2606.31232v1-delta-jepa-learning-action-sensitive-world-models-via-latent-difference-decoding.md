## 摘要
学习用于规划的视觉世界模型需要紧凑的潜在动力学，这些动力学必须对动作保持敏感，然而无重构的联合嵌入目标可能导致对动作不敏感的表示。我们提出Delta-JEPA，一种端到端无重构的世界模型，它通过潜在差异动作解码器（LDAD）增强了潜在前向预测。与从串联端点嵌入推断动作的逆解码器不同，LDAD从连续观测之间的潜在位移中重构执行的动作。这种位移级监督直接正则化了转换几何：相邻嵌入不能在不丢失动作信息的情况下坍缩，并且不同的动作被鼓励引发可区分的潜在变化，从而支持基于推演的规划。Delta-JEPA仅使用潜在预测和动作重构，避免了像素重构和分布匹配正则化器。在四个视觉连续控制任务中，Delta-JEPA相较于基于JEPA和表示学习的世界模型基线提高了规划性能。消融实验表明，基于位移的动作解码始终比端点串联更有效，并且动作敏感性分析显示了更清晰的动作条件潜在响应。这些结果表明，监督潜在差异是一种简单且有效的机制，用于抗坍缩和动作敏感的世界模型学习。

## Abstract
Learning visual world models for planning requires compact latent dynamics that remain sensitive to actions, yet reconstruction-free joint-embedding objectives can collapse to action-insensitive representations. We propose Delta-JEPA, an end-to-end reconstruction-free world model that augments latent forward prediction with a Latent Difference Action Decoder (LDAD). Unlike inverse decoders that infer actions from concatenated endpoint embeddings, LDAD reconstructs the executed action from the latent displacement between consecutive observations. This displacement-level supervision directly regularizes transition geometry: adjacent embeddings cannot collapse without losing action information, and different actions are encouraged to induce distinguishable latent changes for rollout-based planning. Delta-JEPA uses only latent prediction and action reconstruction, avoiding pixel reconstruction and distribution-matching regularizers. Across four visual continuous-control tasks, Delta-JEPA improves planning over JEPA-based and representation-learning world model baselines. Ablations show that displacement-based action decoding is consistently more effective than endpoint concatenation, and action-sensitivity analyses show clearer action-conditioned latent responses. These results indicate that supervising latent differences is a simple and effective mechanism for collapse-resistant and action-sensitive world model learning.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题本质**：基于联合嵌入预测架构（JEPA）的无重构世界模型在端到端训练时，仅使用潜在预测损失（L2 loss）容易导致**表示坍塌**，即编码器和预测器学习将不同观测映射到几乎相同的常数表示。这种坍塌使得隐表示对**动作不敏感**，不同动作引发的转移几何无法区分，进而导致基于潜推演的**规划失效**。
- **现有方案不足**：
  - LeWorldModel（LeWM）使用SigReg高斯正则化稳定训练，但未显式约束动作敏感性，不同动作可能产生弱可分的隐转移。
  - PLDM组合VICReg、逆动力学和时间平滑性，但逆动力学从串联的端点嵌入 $[z_t, z_{t+1}]$ 解码动作。由于前向预测器已接收动作 $a_t$，目标表示 $z_{t+1}$ 可能已包含动作相关线索，逆解码器可“作弊”而不需要真正建模转移本身。
- **本文贡献**：提出**Delta-JEPA**，通过**潜在差异动作解码器（LDAD）**从相邻观测的潜在位移 $\Delta z_t = z_{t+1} - z_t$ 重构动作，直接正则化转移几何，避免坍塌并增强动作敏感性，同时保持简单的双目标训练（仅预测损失+动作重构损失）。

## 2. 方法论

### 核心思想
- 用共享编码器 $f_\theta$ 将连续观测 $o_t, o_{t+1}$ 映射为隐表示 $z_t, z_{t+1}$。
- 前向动力学预测器 $P_\phi$ 根据当前 $z_t$ 和动作 $a_t$ 预测下一隐表示 $\hat{z}_{t+1}$，损失 $L_{\text{pred}} = \|\hat{z}_{t+1} - z_{t+1}\|_2^2$。
- LDAD 解码器 $D_\Theta$ 从潜在位移 $\Delta z_t = z_{t+1} - z_t$ 重构动作 $\hat{a}_t$，损失 $L_{\text{action}} = \|\hat{a}_t - a_t\|_2^2$。
- 总损失 $L = L_{\text{pred}} + \lambda L_{\text{action}}$，端到端训练，无冻结编码器、stop-gradient 或分布匹配。

### 关键技术细节
1. **位移级逆动力学**：解码器仅输入 $\Delta z_t$，强制动作重构依赖“变化”而非端点信息，避免串接解码的捷径。
2. **抗坍塌机制**：若相邻隐表示坍塌为相同向量，则 $\Delta z_t \approx 0$，动作无法重构，从而阻止坍塌。
3. **多步动作解码扩展**：使用 Transformer 骨干和 $N$ 个可学习查询，从长程位移 $z_{t+N} - z_t$ 重构 $N$ 步动作序列，通过 AdaLN 注入位移特征，捕捉更长时间依赖。
4. **前向预测器**：6层因果 Transformer，动作通过 Adaptive Layer Normalization 注入；编码器为随机初始化的 ViT-Tiny。
