## 摘要
语言代理在执行长期任务时，必须维护关于工具状态、对象位置、图边和子目标依赖的信念。当这些信念发生漂移时，无论是更长的推理轨迹还是普通的自我反思都无法修复失败，因为缺失的证据存在于环境中。我们将环境探测形式化为结构化智能体世界模型的预算决策问题：在行动之前，代理可以查询一个信念字段的当前值，更新其表格，并支付一次交互步骤。我们提出了EnvProbe，一种简单的评分策略，结合了任务关键性、陈旧性、口头不确定性和依赖角色。通过类型分层分析，我们分离了信念修复的收益与替代任务行动的成本，并预测了程序性信念和空间信念的不同行为。在三个具有黄金信念状态的控制环境中，EnvProbe在程序性工具依赖任务上相比周期性探测将终端世界状态准确率提升了11.76个百分点，在空间任务上提升了3.79个百分点，总体提升了6.45个百分点。消融实验表明，任务结构项是收益的主要来源，而自我报告的不确定性在自信的错误信念下不可靠。结果表明，智能体校准应被视为一个基于环境证据的行动选择问题，而不仅仅是模型内部的推理问题。

## Abstract
Language agents acting over long horizons must maintain beliefs about tool states, object locations, graph edges, and subgoal dependencies. When these beliefs drift, failures can be fixed neither by longer reasoning traces nor by ordinary self-reflection, since the missing evidence lies in the environment. We formulate environment probing as a budgeted decision problem for structured agent world models: before acting, the agent may query the current value of one belief field, update its table, and pay one interaction step. We introduce EnvProbe, a simple scoring policy that combines task criticality, staleness, verbalized uncertainty, and dependency role. A type-stratified analysis separates the benefit of belief repair from the cost of displaced task actions and predicts different behavior for procedural and spatial beliefs. In three controlled environments with gold belief states, EnvProbe improves terminal world-state accuracy over periodic probing by 11.76 percentage points on procedural tool-dependency tasks, 3.79 points on spatial tasks, and 6.45 points overall. Ablations show that task-structural terms are the main source of the gains, while self-reported uncertainty is unreliable under confident wrong beliefs. The results suggest that agent calibration should be treated as an action-selection problem over environment evidence, not only as a model-internal reasoning problem.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：语言智能体在长期任务中需要维护结构化世界模型（信念表），但信念会随时间漂移（例如工具状态、对象位置、图边等）。当信念变陈旧时，即便智能体具备正确的推理轨迹或自我反思能力，也无法修复失败，因为缺失的证据只存在于环境中。
- **研究动机**：当前主流方法（如ReAct、Reflexion、LATS）将世界模型隐含在推理轨迹中，或通过观察、执行轨迹、反思来更新状态，但并未将环境探测视为一种专门的“校准动作”。智能体需要决定是否花费一个交互步骤去查询环境中的某个信念字段，而这与推进任务的动作存在预算竞争。
- **整体含义**：智能体校准不应仅看作模型内部的推理问题，而应看作一个基于环境证据的**动作选择问题**——需要在有限的探测预算下，决定何时、查询哪个信念字段，以最大化终端世界状态准确率和任务成功率之间的权衡。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想

- 提出**EnvProbe**：一个轻量级的环境探测策略，在规划与执行之间插入一个证据门控。在每次决策点，智能体已从信念表中提出下一个任务动作，但EnvProbe决定是否先探测一个可能陈旧的信念字段，然后更新信念表，再继续执行。
- 把环境探测形式化为**预算决策问题**：每个探测消耗一个环境步骤，不执行任务动作；总预算$B = \lfloor H/4 \rfloor$（H为地平线）。
- 设计了一个**评分函数**对信念字段排序，基于结构信号（任务关键性、依赖角色）和自我报告信号（陈旧度、口头不确定性）。

### 2.2 关键技术细节

- **信念字段评分公式**：

  $$\rho_i(t) = c_i + s_i(t) + u_i(t) + d_i(t)$$

  其中：
  - $c_i = w_i / \max_j w_j$：任务关键性，从任务权重表导出。
  - $s_i(t) = \min(1, \hat{\tau}_i(t)/10)$：自我报告的陈旧度，$\hat{\tau}_i(t)$是智能体估计的字段未检查步数。
  - $u_i(t) = 1 - \text{conf}_i(t)$：口头不确定性，1减去置信度。
  - $d_i(t) \in \{0, 0.5, 1\}$：依赖角色，根据该字段与下一步计划动作的依赖关系（直接阻塞、传递依赖、无关）。

- **评分分解**：

  $$\rho_i(t) = \underbrace{c_i + d_i(t)}_{\rho_i^{\text{str}}(t)} + \underbrace{s_i(t) + u_i(t)}_{\rho_i^{\text{self}}(t)}$$

  结构部分来自任务图和计划动作，自我报告部分来自模型的内存和置信度。

- **探测阈值**：固定阈值$\rho^\star = 1.5$，当最高分$\geq 1.5$且预算未用完时执行探测；否则执行任务动作。

- **算法流程**（EnvProbe-Simple，Algorithm 1）：
  1. 初始化信念表$b_0 = g_0$，任务图$G$，地平线$H$，预算$B$。
  2. 在每个步骤$t$，对所有字段计算$\rho_i(t)$。
  3. 如果$\max_i \rho_i(t) \geq 1.5$且探测次数$< B$，则选择最高分字段执行探测（更新信念表$b_{i^\star}^{t+1} \leftarrow g_{i^\star}^t$），增加探测计数，重置该字段陈旧度。
  4. 否则执行下一个任务动作。
  5. 重复直到$t > H$。

- **变体**：
  - EnvProbe-Judge：使用第二个LLM（与主智能体相同）对最高分候选字段进行二元覆盖（是否真的需要探测）。
  - EnvProbe-(c+d)：仅保留结构部分$c_i + d_i$，移除自我报告部分。
  - Oracle-Probe：使用真实金标准不匹配来决定探测（仅作诊断上限）。

## 6. 论文的主要结论与发现

1. **环境探测能修复世界模型**：EnvProbe-Simple相比Periodic-Probe，在程序型任务上提升终端准确率11.76个百分点，空间型3.79个百分点，总体6.45个百分点（均显著）。

2. **结构信号是收益主要来源**：关键性和依赖角色是负载承载项；移除它们使准确率大幅下降（分别下降15.92%和12.08%）。自我报告不确定性在程序型设置中是**反信号**：移除不确定性后准确率提升5.76%，但任务成功率下降（从20.5%到8.2%），说明不确定性会错误引导探测消耗任务步骤。

3. **空间型与程序型表现不对称**：程序型任务中探测收益大但易受动作顺序竞争；空间型任务中自报告不确定性几乎无益，结构+依赖方法（c+d）在所有指标上Pareto占优。

4. **自信错误率极高**：在自信的信念中，有约94%是错误的。不确定性导向的探测会主动避开这些最需要修复的字段。

5. **探测与任务动作存在Pareto前沿**：程序型任务中，高准确率与高任务成功率不可兼得；结构重探测（c+d）得到最高准确率但任务成功率低，轻探测方法得到高任务成功率但准确率低。空间型任务中c+d同时占优。

## 8. 不足与局限

- **仅测试单一LLM**：只用了GPT-4o mini，不同LLM（尤其开源模型）的置信度校准和探测收益可能不同，泛化性未知。
- **控制环境与真实场景差距**：合成环境的突变模式、任务图结构等可能与真实世界（复杂网页、物理机器人）差异显著，实际部署效果待验证。
- **探测预算固定**：预算$B = \lfloor H/4 \rfloor$是启发式设定，未优化或自适应调节。不同突变率下最优预算可能变化。
- **评分阈值固定不调优**：阈值1.5是固定值，实验声称为了分析清晰，但实际应用中可能需根据任务动态调整。
- **不确定性校准不充分**：论文明确发现自信错误，但未提出改进自信度的措施；EnviProbe直接使用LLM报告的不确定性，可能引入噪声。
- **任务成功率统计力较低**：任务成功率的差异在某些比较中不显著（如(c+d)相比完整评分任务成功率差异p=0.22），可能因二元指标和样本量限制。
- **未探索探测与反思的结合**：论文单独使用探测，但现实智能体可能同时使用自我反思（Reflexion）和环境探测，未做结合实验。
