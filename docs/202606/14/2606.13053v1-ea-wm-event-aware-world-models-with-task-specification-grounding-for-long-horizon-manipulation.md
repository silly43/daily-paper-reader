## 摘要
预训练特征世界模型为机器人想象提供了有用基板，但仅凭视觉或潜变量预测并不能判定想象未来是否满足任务相关事件。长时程操作需要具有关系性、谓词级别和物理基础的过程信号：物体是否移动、抽屉或接触状态是否改变、放置谓词是否满足、候选未来是否足够可靠以执行。我们提出EA-WM，一种事件感知世界模型框架，通过任务规范基础的事件预测与验证增强冻结的视觉特征动力学。EA-WM在预训练视觉特征空间中展开候选未来，将其解码为结构化事件状态，并使用任务进展、语义一致性、物理可行性和不确定性项进行评分。验证器指导基于采样的规划、门控候选动作，并在接触敏感的LIBERO酒架设置中，选取PPO生成的提议。在导航、可变形物体、墙壁约束和语言描述的操作研究中，EA-WM表明事件感知验证能使特征空间世界模型更具可解释性，并更好地与任务进展对齐。

## Abstract
Pretrained-feature world models provide a useful substrate for robot imagination, but visual or latent prediction alone does not determine whether an imagined future satisfies task-relevant events. Long-horizon manipulation requires progress signals that are relational, predicate-level, and physically grounded: whether an object has moved, whether a drawer or contact state has changed, whether a placement predicate is satisfied, and whether a candidate future is reliable enough for execution. We introduce EA-WM, an event-aware world-model framework that augments frozen visual-feature dynamics with task-specification-grounded event prediction and verification. EA-WM rolls out candidate futures in pretrained visual-feature space, decodes them into structured event states, and scores them using task-progress, semantic-consistency, physical-feasibility, and uncertainty terms. The verifier guides sampling-based planning, gates candidate actions, and, in the contact-sensitive LIBERO wine-rack setting, selects among PPOgenerated proposals. Across navigation, deformable-object, wall-constrained, and languagedescribed manipulation studies, EA-WM shows that event-aware verification can make featurespace world models more interpretable and better aligned with task progress.

- **核心问题**：长时程机器人操作任务中，仅依赖视觉或潜在特征预测的未来状态，无法判断是否满足了任务相关的具体事件（如物体是否移动、抽屉是否打开、放置谓词是否满足等）。传统的视觉世界模型（如 Dreamer、DINO-WM）在特征空间进行规划，但缺乏对任务进度、语义一致性、物理可行性和不确定性的显式验证。
- **研究动机**：人类技能学习是多模态的，结合演示、指令、规则、约束和反馈。机器人规划需要超越视觉预测，对“为什么动作合适”、“哪些前提条件成立”、“下一个事件应该发生什么”、“空间关系或物理接触是否达成”等进行结构化推理。现有工作将事件仅从视觉变化推断，仍可能忽略任务规则、动作历史和机器人状态约束。
- **整体含义**：EA-WM 提出一种“事件感知世界模型”框架，将任务规范（task specification）接地到事件预测和验证中，使基于特征空间的规划不仅关注视觉相似性，更关注可验证的任务事件进展，从而提升可解释性和任务对齐性。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- 在冻结的预训练视觉特征世界模型（如 DINO-WM 风格）之上，添加一个**任务接地的事件层**。对于每个候选动作序列，基础模型预测未来视觉特征；事件预测器将想象未来映射到结构化事件状态（对象状态变化、空间关系、进度信号、成功谓词等）；验证器（verifier）评估事件状态是否指示任务进展、语义一致性、物理可行性和确定性。
- 规划目标函数结合基础视觉特征代价和验证器得分，使得动作选择对任务事件进展敏感。

### 关键技术细节
1. **问题形式化**：
   - 观测历史 $o_{t-k:t}$，本体感觉 $p_{t-k:t}$，任务规范 $c$，候选动作 $a_{t:t+H-1}$。
   - 视觉编码器 $E$ 输出特征 $z_t = E(o_t)$。
   - 基础动作条件世界模型 $F_\theta$ 预测未来特征 $\hat{z}_{t+H} = F_\theta(z_{t-k:t}, p_{t-k:t}, a_{t:t+H-1})$。
   - 事件状态 $e_t = \{b_t, r_t, q_t, s_t, u_t\}$，包括二元事件、连续距离、关节/接触进度、任务成功、不确定性。
   - 事件预测器 $G_\psi$ 输出 $\hat{e}_{t+H} = G_\psi(\hat{z}_{t+H}, z_{t-k:t}, c, a_{t:t+H-1})$。
   - 验证器得分 $S_{EA} = S_{\text{task}} + \lambda_s S_{\text{semantic}} + \lambda_p S_{\text{physical}} - \lambda_u U$。
   - 规划目标 $J(a_{t:t+H-1}) = w_f C_{\text{feature}} - S_{EA}$。

2. **事件标签生成**：
   - 从模拟器状态和任务定义（BDDL规则）自动生成事件标签，无需人工标注。例如 PointMaze 中使用目标距离和归一化进度；LIBERO 中使用对象位置、关节角度等定义 moved, near, on, joint 等谓词。
   
3. **事件预测与验证**：
   - 训练事件预测器 $G_\psi$，监督信号来自自动标签。使用二元交叉熵、平滑L1回归、分类损失。
   - 验证器额外使用**排名损失**，对成对窗口（成功窗口 vs 随机/零动作/混洗窗口）学习相对排序。
   - 不确定性 $U$ 通过低置信度惩罚实现，例如成功概率熵、阈值边际或集成方差。
   - 验证器不是第二个动力学模型，它评分事件预测器的输出。

4. **验证器引导的 CEM 规划**：
   - 在每个决策点，CEM 采样动作窗口，通过特征世界模型展开，预测终端事件，按组合目标 $J$ 排序，精英更新采样分布。
   - 在在线 LIBERO 中，保守混合门控比较 CEM 得分与演示动作得分，仅在验证器边际且安全条件满足时才接受 CEM 动作。

5. **规划器感知的 PPO 提议（仅用于酒架任务）**：
   - 提出残差 PPO 策略 $\pi_\phi$，生成围绕演示动作的候选动作窗口 $a^{\text{ppo}} = a^{\text{demo}} + \Delta_\phi$。
   - PPO 训练使用终端奖励 $r = I[\text{env.check\_success()}]$，更新时使用剪切替代目标。
   - 部署阶段：采样 K 个 PPO 候选，由验证器/重新排名器选择（仅前两候选），否则回退到演示动作。为接触敏感放置额外添加沉降尾巴（settle tail）。

### 算法流程（文字描述）
- 输入：观测历史、本体感觉、任务规范、候选动作窗口。

## 6. 论文的主要结论与发现

- **主要发现**：事件感知验证能有效提升特征空间世界模型在长时程操作中的实用性和可解释性。
  - PointMaze：验证器引导的 CEM 将随机目标成功率从 0.90 提升至 0.94，且保留数据集目标性能（1.00）。
  - Deformable：检索初始化 + 保守 EA-CEM 达到 94% 成功率（vs 零初始化 0%）。
  - Wall-Single：EA-CEM 最终策略 0.92，早期存档验证达到 0.95（基线 0.88）。
  - LIBERO-goal：离线验证器 AUC 0.993947；Goal10 保守混合门控从演示 87/100 提升至 88/100，但直接 CEM 替换下降至 75/100（说明需要门控）。
  - 酒架任务：PPO 提议 + 9步沉降 + top2 验证器混合达到 97/100，匹配 Oracle@32，表明事件感知选择能支持接触敏感放置。
- **重要性**：验证器必须平衡特征代价，过度主导会损害规划（表2显示特征权重 10 最好，20 下降）。

## 7. 优点：方法或实验设计上的亮点

- **事件自动标记**：从模拟器和任务规范自动生成事件标签，免除人工标注，可扩展。
- **模块化设计**：视觉世界模型可冻结复用，事件验证层独立，易于集成到现有特征空间规划管道。
- **验证器多维度**：结合任务进度、语义一致性、物理可行性、不确定性，提供结构化评分。
- **保守混合门控**：在弱候选时回退到演示，强候选时信任事件验证，提高实际部署稳健性。
- **PPO 提议结合验证器选择**：利用强化学习生成更优候选，再通过验证器精筛，避免直接使用未验证的 PPO 动作。
- **多种场景验证**：覆盖简单导航到复杂接触操作，展现广泛适用性。
- **可解释性**：事件状态为结构化谓词，验证器输出明确得分，便于人类理解规划依据。

## 8. 不足与局限

- **依赖模拟器事件标签**：现实世界需要鲁棒感知、VLM 辅助或手动审计，论文承认此限制。
- **短期窗口评估**：LIBERO 在线评估仅为 H=20 窗口，非完整自主长时程执行。Goal10 的改进幅度较小（1/100），统计意义存疑。
- **PPO 提议仅限一个任务**：酒架任务，且包含任务特定的沉降尾巴，不是通用方法。
- **验证器部分规则部分学习**：复杂且可能不易扩展到全新任务，缺乏可学习的端到端任务条件对接。
- **计算资源未报告**：不利于可重复性评估。
- **实验统计不充分**：缺乏多次运行、置信区间、显著性检验。
- **消融实验有限**：如不确定性项仅用低置信惩罚，未与其他不确定性估计方法对比；语义和物理项的具体贡献未单独消融。
- **与最新视觉语言模型的比较缺失**：未与 RT-1、OpenVLA 等端到端 VLA 策略对比（尽管论文声称互补，但可做场景化的 baseline 对比）。
