## 摘要
本工作提出了RepWAM，一种基于表示视觉-动作分词器的以表示为中心的世界动作模型（WAM）。现有的WAM通常从预训练的视频生成模型中继承面向重建的视频分词器。尽管这些分词器保留了视觉保真度，但仅依靠像素重建对于学习将未来预测与机器人控制相连接的指令跟随动态所提供的指导有限。为解决这一问题，我们探索了一种语义视觉-动作潜在空间，用于以表示为中心的世界动作建模。具体而言，我们训练了一个表示视觉-动作分词器，将视觉输入映射为对齐的视觉和潜在动作标记。然后，我们预训练WAM以联合建模在语言指令下连接它们的未来视觉状态和潜在动作，随后适应真实机器人轨迹以实现闭环操作。在实际操作任务和仿真基准上的实验表明，RepWAM在多种操作场景中均表现出色，消融研究则凸显了语义视觉-动作分词相比面向重建替代方案的价值。这些结果确立了表示视觉-动作分词作为世界动作模型的一个有前景的基础，并向通用机器人策略迈出了一步。代码和权重将在https://github.com/wdrink/RepWAM提供。

## Abstract
This work presents RepWAM, a representation-centric world action model (WAM) built on representation visual-action tokenizers. Existing WAMs typically inherit reconstruction-oriented video tokenizers from pretrained video generation models. Although these tokenizers preserve visual fidelity, pixel reconstruction alone provides limited guidance for learning instruction-following dynamics that connect future prediction with robot control. To address this, we explore a semantic visual-action latent space for representation-centric world action modeling. Specifically, we train a representation visual-action tokenizer that maps visual inputs into aligned visual and latent action tokens. We then pretrain our WAM to jointly model future visual states and the latent actions that connect them under language instructions, followed by adaptation to real robot trajectories for closed-loop manipulation. Experiments on real-world manipulation tasks and simulation benchmarks show that RepWAM delivers strong performance across diverse manipulation settings, while ablations highlight the value of semantic visual-action tokenization over reconstruction-oriented alternatives. These results establish representation visual-action tokenization as a promising foundation for world action models and a step toward generalist robot policies. Code and weights will be available at https://github.com/wdrink/RepWAM.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现有世界动作模型（WAM）通常从预训练视频生成模型中继承“面向重建”的视频分词器（如 WAN2.2 VAE）。这类分词器优化像素保真度，但忽略了视觉语义和机器人动作的表示——导致两个关键缺陷：
  1. **视觉浅层化**：潜变量空间被背景纹理等低级外观占据，而物体身份、空间关系、交互线索等对操作至关重要的语义信息未被充分表征，使得指令条件下的世界模型学习效果差；
  2. **动作解耦**：视觉潜变量与电机指令处于分离空间，迫使逆动力学模型（IDM）在每个步骤都需弥合模态鸿沟，降低了效率与可控性。
- **研究动机**：探索一个“以表示为中心”的视觉-动作潜空间，使视觉状态及其由动作引发的变换能被联合表示，从而提升WAM的指令跟随能力与可迁移性。
- **整体含义**：RepWAM提出了一种新的范式——不依赖像素重建，而是利用语义视觉-动作分词器构建统一潜空间，为通用机器人策略奠定基础。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
构建一个**表示视觉-动作分词器（RepViTok）**，将视觉输入映射为语义对齐的视觉token，并诱导出在同一空间中捕捉时序动态的潜在动作token。在该潜空间上，预训练一个因果扩散Transformer，联合建模未来视觉状态与潜在动作；随后通过少量真实机器人演示进行微调，实现闭环操作。

### 关键技术细节

1. **视觉分词器**（Visual Tokenization）：
   - 使用ViT自动编码器，将首帧分为16×16 patch，后续帧分为4×16×16 tubelet，编码器包含时间-因果掩码的全空间注意力，解码器对称。
   - 除重建损失（L1 + 感知损失 + 对抗损失）外，额外引入**特征对齐损失**：将视觉潜变量$z$通过线性投影$W_{align}$后，与冻结的视觉基础模型（Perception Encoder）的输出进行均方误差最小化：
     $$\mathcal{L}_{align} = \left\| \text{avg}(W_{align}z) - \text{avg}(G(o)) \right\|_2^2$$
   - 总目标：$\mathcal{L}_{vis} = \mathcal{L}_{rec} + \lambda_{align}\mathcal{L}_{align}$。

2. **潜在动作分词器**（Latent Action Tokenization）：
   - 冻结视觉分词器，训练一个由**逆动力学模型（IDM）**$q_\phi$与**前向动力学模型（FDM）**$f_\psi$耦合的系统。
   - 对连续潜帧$z_t, z_{t+1}$，IDM压缩得到低维动作token $\ell_t \in \mathbb{R}^{d_\ell}$（$d_\ell \ll d_v$）；FDM将其实现为传输矩阵$K_t$和残差$\delta_t$：
     $$\ell_t = q_\phi(z_t, z_{t+1}), \quad K_t, \delta_t = f_\psi(z_t, \ell_t), \quad \hat{z}_{t+1} = K_t z_t + \delta_t$$
   - 训练损失包括前向预测损失和反向一致性损失：
     $$\mathcal{L}_{fwd} = \sum \|\hat{z}_{t+1} - z_{t+1}\|_2^2, \quad \mathcal{L}_{cons} = \sum \|\hat{z}_t - z_t\|_2^2$$

3. **因果世界动作模型**（Causal World Action Models）：
   - 采用**因果扩散Transformer**，使用块因果掩码，视觉与动作token共享注意力权重但使用模态专用前馈网络。
   - 语言指令通过预训练文本编码器嵌入，经交叉注意力注入。
   - 训练目标为条件流匹配损失，联合作用于视觉和潜在动作分支：
     $$\mathcal{L}_{FM} = \mathbb{E}\left[ \|F_\theta^v - \dot{x}_\alpha^v\|_2^2 + \lambda_a \|F_\theta^a - \dot{x}_\alpha^a\|_2^2 \right]$$
   - 推理时，设置块大小为2，注意力窗口大小为32，视频专家和动作专家分别采用5步和10步。

## 6. 论文的主要结论与发现

1. **语义视觉-动作分词显著优于面向重建的分词**：
   - 在AgiBot评估集上，RepViTok相比WAN2.2 VAE将gFVD降低9.5%-13.2%，OLS（开放环路动作准确率）提升约3-5个点。
   - 真实机器人PickFruit任务成功率从20%（WAN2.2 VAE）提升至30%（RepViTok）。
2. **两阶段潜在动作训练是最优方案**：
   - 相比无潜在动作预训练（w/o）或联合预测（Joint Pred），两阶段训练在gFVD、PSNR、SSIM、OLS上均为最优，真实PickFruit成功率从30%提升至50%。
3. **RepWAM在真实世界和仿真中均优于或持平强基线**：
   - 真实世界：RepWAM-5B在所有三个任务上均为最优或并列最优，尤其在长时域（Push drawer 80%）和精细操作（Insert tube 60%）上大幅领先$\pi_{0.5}$和Lingbot-VA。
   - 仿真：RepWAM-5B在Easy和Hard平均成功率分别为89.3%和88.4%，仅次于Lingbot-VA（主因Lingbot-VA使用了WAN视频生成预训练权重，而RepWAM从头训练）。
4. **RepViTok可降低视频CFG依赖**：
   - 在CFG scale=1.0时RepWAM即达最佳性能，说明语义对齐的潜空间已足够好，无需额外CFG extrapolation。
5. **潜在动作具有良好的可迁移性**：
   - 通过冻结动作潜变量训练IDM解码电机指令，RepViTok的IDM损失低于LAPA，表明其潜在动作更易于映射到机器人动作空间。

## 7. 优点

- **方法创新性**：首次提出“表示视觉-动作分词器”，将视觉语义与潜在动作在同一语义空间中统一建模，解决了现有WAM两个关键瓶颈（视觉浅层+动作解耦）。
- **实验完整性**：覆盖真实物理机器人、仿真基准、多组消融（分词器、训练策略、CFG依赖），且包含开放环路和闭环评估。
- **分析深入**：通过可视化潜在动作、IDM损失对比，直观展示了RepViTok的优势；还探讨了CFG依赖降低带来的推理效率提升。
- **代码和权重开源**：承诺提供代码与权重，可复现。
- **资源效率**：从头训练（未使用大规模视频生成预训练）即能达到甚至超越有预训练的基线，表明表示设计本身的价值。

## 8. 不足与局限

- **训练数据规模有限**：预训练仅使用机器人域视频（AgiBot等），未利用大规模互联网视频（如人类第一人称视频），限制了行为多样性的学习（论文自身也指出这是未来工作）。
- **真实世界实验场景少**：仅3个任务，且每个任务仅50个演示，缺乏对多任务、多场景、不同机器人形态的充分验证。
- **潜在动作解释性有限**：虽然可视化表明其更聚焦于操作相关变化，但其物理含义（如对应哪些具体力学量）仍不明确。
- **与Lingbot-VA的差距**：在RoboTwin 2.0上RepWAM-5B仍低于Lingbot-VA（尤其Easy任务），尽管消融表明RepViTok优于WAN2.2 VAE，但整合预训练权重后Lingbot-VA仍占优，说明“从头训练”与“预训练+微调”之间存在效果差距。
- **消融实验不完全公平**：消融实验中WAN2.2 VAE基线未使用语义对齐，但Lingbot-VA本身可能包含额外技巧，不完全归因于分词器。
- **计算开销**：训练5B模型需128 H20 GPU，资源需求较高；推理时使用5步（视频）+10步（动作）可能延迟较高，未报告实际推理时间。
- **缺乏对泛化性深入分析**：未测试零样本新场景、新物体或不同机器人形态的能力（虽然RoboTwin有域随机化，但任务集固定）。
