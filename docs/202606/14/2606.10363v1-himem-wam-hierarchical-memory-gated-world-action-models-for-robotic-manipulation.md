## 摘要
世界动作模型（WAMs）已成为具身智能的一种新的强大范式，通过学习与动作相关的视觉动态，显著增强了泛化能力和鲁棒性。然而，现有的WAMs在长时程机器人操作中仍难以处理与任务相关的记忆。为此，我们提出HiMem-WAM，一种层次化记忆门控WAM，它集成了运动中心潜在动作、高层技能潜在变量以及边界触发的记忆更新。具体来说，我们开发了一个层次化潜在动作框架，联合学习底层运动和高层技能潜在变量，提供结构化的时间抽象。同时，一个边界感知记忆门在预测的技能转换处写入紧凑的任务状态，无需在测试时生成未来视频或光流估计即可实现因果推理。在LIBERO、LIBERO-PLUS、RMBench以及真实世界任务上的评估表明，HiMem-WAM中层次化潜在变量改善了部署扰动下的鲁棒性，而记忆模块显著有益于依赖记忆的长时程操作。

## Abstract
World Action Models (WAMs) have emerged as a new powerful paradigm for embodied intelligence, learning action-relevant visual dynamics that significantly enhance generalization and robustness. However, existing WAMs still struggle with task-relevant memory in long-horizon robotic manipulation. To address this, we present HiMem-WAM, a Hierarchical Memory-Gated WAM that integrates motion-centric latent actions, high-level skill latents, and boundary-triggered memory updates. Specifically, we develop a hierarchical latent action framework that jointly learns low-level motion and high-level skill latents, providing structured temporal abstraction. Meanwhile, a boundary-aware memory gate writes compact task states at predicted skill transitions, enabling causal inference without test-time generation of future video or optical flow estimation. Evaluated on LIBERO, LIBERO-PLUS, RMBench and real-world tasks, HiMem-WAM shows that hierarchical latents improve robustness under deployment perturbations, and the memory module substantially benefits memory-dependent long-horizon manipulation.

## 1. 论文的核心问题与整体含义（研究动机和背景）

现有世界动作模型（World Action Models, WAMs）通过预测未来视觉动态来学习与动作相关的表征，在泛化性和鲁棒性上优于直接端到端的视觉-语言-动作（VLA）模型。然而，WAMs在**长时程机器人操作任务**中普遍缺乏对任务相关记忆的有效管理，导致在需要回忆遮挡子任务状态、适应部分完成后的继续执行等场景下性能显著下降。具体表现为：

- 大多数WAMs依赖固定长度的观测历史或密集的过去信息聚合，无法在技能边界处高效保留关键任务状态。
- 现有模型缺少对**底层运动**与**高层技能**的分层抽象，使得长时程任务难以分解为可复用的子技能。
- 推断阶段常需要生成未来视频或光流，引入额外的计算开销和因果性不足。

HiMem-WAM旨在解决上述问题，通过引入**层次化潜在动作框架**和**边界触发记忆门控模块**，在不牺牲因果推理效率的前提下，增强WAMs对长期记忆依赖任务的适应能力。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式

### 核心思想
HiMem-WAM将机器人操作策略分解为三个层次：**高层技能潜变量**（skill latent）、**底层运动潜变量**（low-level latent action）以及**动作解码**。同时，在技能边界处由门控机制控制记忆的写入与读取，使得策略能够根据当前观测和历史任务状态进行因果推断。

### 关键技术细节

1. **层次化潜在动作框架**
   - **底层潜在动作学习**：使用变分分词器（variational tokenizer）从多视角光流、RGB观测、本体感受和语言指令中编码低层潜在动作$z_t^l$，并通过重建光流和（若存在动作标签）弱对齐真实动作来训练：
     $$
     \mathcal{L}_l = \|\hat{\Phi}_t - \Phi_t\|_1 + \lambda_a I_t^{\text{act}} \|\hat{a}_t - a_t\|_2^2 + \beta D_{\text{KL}}\left(q_\phi(z_t^l|c_t) \| \mathcal{N}(0, I)\right)
     $$
   - **高层技能潜变量发现**：通过对低层潜在序列进行层次化边界检测和段池化，自动发现技能边界。每层通过查询-键相似度计算边界分数，输出技能序列$z^h$和边界标签$\bar{b}_t$。技能发现损失包括预测下一个低层潜在、运动重建、边界比例约束和一致性损失。

2. **记忆门控模块**
   - **读取门**：从外部记忆库$M_t$中检索与当前状态相关的上下文$c_t^m$，通过标量门$\alpha_t^r$控制注入程度，形成记忆适应状态$\tilde{x}_t$。
     $$
     \tilde{x}_t = x_t + \alpha_t^r W_m c_t^m,\quad \alpha_t^r = \sigma(G_r(x_t, c_t^m))
     $$
   - **写入门**：利用预测的边界分数$\hat{b}_t$和当前状态，用逻辑门$\alpha_t^w$决定是否将紧凑的记忆令牌$\gamma_t$写入记忆库：
     $$
     \alpha_t^w = \sigma(G_w(\tilde{x}_t, \hat{z}_t^h, \hat{b}_t)),\quad M_{t+1} = \begin{cases} U_\psi(M_t, \gamma_t), & \alpha_t^w > \eta \\ M_t, & \text{otherwise} \end{cases}
     $$
     写入门用BCE损失监督，鼓励只在真实技能转换处写入，同时加$\ell_1$稀疏正则。

3. **三阶段训练流程**
   - **Stage I**：仅在动作标签/光流上训练低层潜在动作分词器。
   - **Stage II**：冻结分词器，利用发现的高层技能和边界预训练规划器（Qwen3-VL-4B-Instruct）和执行器（无记忆），损失包括技能MSE、低层潜变量MSE和边界BCE。
   - **Stage III**：激活记忆模块，在完整动作标注数据上联合微调策略，加入动作损失、门控损失等。
   - 推断时完全因果，仅需当前RGB、本体、指令和记忆库，无需生成视频或光流。
