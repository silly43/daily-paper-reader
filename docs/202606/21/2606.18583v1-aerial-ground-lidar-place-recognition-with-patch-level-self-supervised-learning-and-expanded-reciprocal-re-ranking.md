## 摘要
激光雷达地点识别用于确定在先前点云地图上的位置。最常研究的地面级激光雷达地点识别存在预访问要求、覆盖不完整和视角有限等问题。使用预先获取的全覆盖机载激光扫描（ALS）数据作为空中先验地图可克服这些缺点，使得跨视角地点识别成为必要且有利。然而，空中-地面激光雷达地点识别面临重大挑战，包括空中与地面点云之间的域差距以及初始检索中的误报。为解决这些挑战，我们提出了一种新颖的空中-地面激光雷达地点识别检索与重排序框架。基于邻近点云块与锚点块共享相似语义的先验知识，我们的检索网络在多个尺度上引入块级自监督学习模块，并与场景级学习集成，以提高空中与地面点云之间全局特征的区分性。此外，利用ALS点云的结构化空间分布，我们引入了一种扩展互反（ER）重排序算法，以最大化利用邻域信息，并基于邻域特征对每个特征进行细化，然后用于更新相似性矩阵以进行最终排序。大量实验表明，我们的检索网络优于现有最先进（SOTA）方法，在CS-Urban-Scenes数据集上平均Recall@1提高了9.8%，平均Recall@1%提高了3.2%，同时在CS-Campus3D数据集上也展现出最佳性能。此外，我们的ER重排序算法在无需额外训练的情况下，将CS-Campus3D上的平均Recall@1进一步提高了4.9%，CS-Urban-Scenes上提高了10.2%。

## Abstract
LiDAR place recognition determines one's position on a prior point cloud map. The most studied ground-level LiDAR place recognition suffers from pre-visit requirements, incomplete coverage, and limited perspectives. Using pre-acquired, full-coverage Airborne Laser Scanning (ALS) data as an aerial prior map overcomes these drawbacks, making cross-view place recognition necessary and advantageous. However, aerial-ground LiDAR place recognition faces significant challenges, including the domain gap between aerial and ground point clouds, and false positives during initial retrieval. To address these challenges, we present a novel retrieval and re-ranking framework for aerial-ground LiDAR place recognition. Based on the priors that neighboring point cloud patches share similar semantics with anchor patch, our retrieval network introduces patch-level self-supervised learning modules at multiple scales and integrates with scene-level learning to improve global feature discriminativeness between aerial and ground point clouds. Furthermore, leveraging the structured spatial distribution of ALS point clouds, we introduce an Expanded Reciprocal (ER) re-ranking algorithm to exploit neighborhood information maximally and refine each feature based on neighbor features, which are then used to update the similarity matrix for final ranking. Extensive experiments demonstrate that our retrieval network outperforms existing state-of-the-art (SOTA) methods, achieving a 9.8\% improvement in average Recall@1 and a 3.2\% improvement in average Recall@1\% on the CS-Urban-Scenes, while also showing the best performance on the CS-Campus3D dataset. Additionally, our ER re-ranking algorithm further boosts the average Recall@1 by 4.9\% on CS-Campus3D and 10.2\% on CS-Urban-Scenes without additional training.

#### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程
论文提出一个两阶段框架，分为初始检索和重排序。

-   **第一阶段：特征检索网络（核心思想：多尺度块级自监督学习）**
    -   **核心思想**：基于一个先验知识，即在点云中，与锚点（anchor）空间邻近的块（patch）应具有相似的语义信息。利用这一特性设计一个异步蒸馏框架，通过自监督方式学习更加稳健的局部和全局特征，以弥合跨视角域差距。
    -   **关键技术细节**：
        1.  **骨干网络**：采用**OctFormer**作为特征提取骨架 $h(\cdot)$，它基于八叉树（octree）结构将点云序列化，提取多尺度特征 $f_o^{(i)}$。
        2.  **多尺度块级自监督学习**：
            -   在每个八叉树深度 $o$ 上，对于中心块 $x_o^{(i)}$，在其空间邻域内筛选语义最相似的块，构成正候选组 $\mathcal{J}_o^{(i)}$。
            -   设计一个**教师网络**（参数 $\tilde{\theta}$，通过EMA更新），通过交叉注意力聚合正候选组的特征，生成目标表示 $\tilde{y}_{\tilde{\theta},o}^{(i)}$。
            -   **学生网络**（参数 $\theta$）的任务是让自身特征 $f_{\theta, o}^{(i)}$ 与教师网络生成的表示进行对齐。
            -   自监督损失函数 $L_{SSL}$ 为：
                $$L_{SSL} = \sum_{o \in \mathcal{O}} \frac{1}{N_o} \sum_{i=1}^{N_o} \mathcal{H}\left(g_\theta(f_{\theta, o}^{(i)}), \text{sg}\left(g_{\tilde{\theta}}(\tilde{y}_{\tilde{\theta},o}^{(i)})\right)\right)$$
                其中 $\mathcal{H}$ 是交叉熵损失，$\text{sg}(\cdot)$ 是停止梯度操作，$g$ 是投影头。

        3.  **联合训练**：将场景级的全局三元组损失 $L_{global}$ 与块级自监督损失 $L_{SSL}$ 结合，得到总损失函数：
            $$L_{total} = L_{global} + \lambda L_{SSL}$$
            其中 $\lambda$ 是平衡超参数。这种设计既保证了检索的基本要求（正样本对距离小于负样本对），又增强了特征的域鲁棒性。

-   **第二阶段：扩展互反（ER）重排序（核心思想：利用ALS结构化空间分布）**
    -   **核心思想**：鉴于ALS数据库是连续且均匀采样的，其具备结构化空间分布。利用互反邻居（reciprocal neighbors）的概念，并通过邻域扩展，可以剔除初始检索结果中的假阳性。
    -   **算法流程**：
        1.  **构建联合集**：将查询点云集 $\mathcal{Q}$ 和数据库点云集 $\mathcal{D}$ 合并为 $\mathcal{U} = \mathcal{Q} \cup \mathcal{D}$。
        2.  **计算互反邻居**：对于联合集中的每个点云 $i$，找到其 $k$ 个最近邻 $N(i, k)$。若点云 $j$ 在 $N(i, k)$ 中，且点云 $i$ 也在 $N(j, k)$ 中，则 $j$ 是 $i$ 的互反邻居 $R(i)$。
            $$R(i) = \{j \mid (j \in N(i,k)) \land (i \in N(j,k))\}$$
        3.  **邻域扩展**：为了防止遗漏，将每个互反邻居的互反邻居也包含进来，得到扩展互反邻居集 $E(i)$。
            $$E(i) = R(i) \cup \bigcup_{j \in R(i)} R(j)$$
        4.  **特征细化**：使用 $E(i)$ 中所有点云特征的均值来细化点云 $i$ 的特征 $f'(i)$。
            $$f'(i) = \frac{1}{|E(i)|} \sum_{x \in E(i)} f(x)$$
        5.  **最终距离计算**：基于粗细特征，计算查询 $q$ 和数据库点 $m_i$ 之间最终的对称性距离 $d_{final}(q, m_i)$，该距离综合了双方邻域信息。
