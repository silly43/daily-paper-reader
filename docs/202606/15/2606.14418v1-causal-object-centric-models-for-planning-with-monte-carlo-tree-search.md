## 摘要
我们提出了COMET（面向高效树搜索的因果对象中心模型），这是一种基于模型的强化学习算法，在槽结构潜在空间中执行蒙特卡洛树搜索。COMET将冻结的无监督对象中心编码器与基于Transformer的世界模型配对，通过一种新颖的动作-槽融合机制将动作绑定到对象上，该机制用于槽转移预测。策略和价值头使用对象因果注意力，通过学习的每个槽相关性分数调节令牌交互，使决策集中在任务相关实体上。COMET为MuZero风格的潜在规划添加了显式的对象级归纳偏置。在来自Object-Centric Visual RL基准、ManiSkill、Robosuite和VizDoom的八个视觉和动态多样的任务中，与对象中心和单一基线相比，COMET在训练早期实现了更高的平均归一化分数。

## Abstract
We introduce COMET (Causal Object-centric Model for Efficient Tree search), a model-based reinforcement learning algorithm that performs Monte Carlo Tree Search in a slot-structured latent space. COMET pairs a frozen unsupervised object-centric encoder with a transformer-based world model, in which actions are bound to objects through a novel action-slot fusion mechanism that is used in slot transition prediction. Policy and value heads use object-causal attention, modulating token interactions by learned per-slot relevance scores so that decision-making concentrates on task-relevant entities. COMET adds an explicit object-level inductive bias to MuZero-style latent planning. Across eight visually and dynamically diverse tasks from the Object-Centric Visual RL benchmark, ManiSkill, Robosuite, and VizDoom, COMET achieves a higher mean normalized score during the early stages of training compared to object-centric and monolithic baselines.

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：COMET（Causal Object-centric Model for Efficient Tree search）将**冻结的无监督物体中心编码器**与**基于Transformer的世界模型**结合，在**槽结构潜在空间**中执行MCTS规划。通过**动作-槽融合机制**进行转移预测，并使用**物体因果注意力**使策略/价值网络聚焦于任务相关物体。

- **关键技术细节**：
    1. **槽提取器（Slots Extractor）**：使用预训练的物体中心模型（SLATE、DINOSAUR、Slot Contrast）将观测图像$o_t$映射为槽集合$\bar{s}_t = \{s_t^1, \dots, s_t^n\}$（$n$为固定槽数）。为保持时间一致性，下一帧槽初始化依赖当前帧槽。
    2. **物体中心令牌处理**：基于UniZero的Transformer骨干。将槽$\bar{s}_t$输入骨干生成隐表示$\{h_t^1,\dots,h_t^n\}$，用于策略/价值预测。对于转移预测，将动作$a_t$与每个槽拼接并通过共享MLP得到**槽条件化动作嵌入**$\bar{a}_t = \{a_t^1,\dots,a_t^n\}$，再送入Transformer生成$\bar{z}_t$，通过共享观测头预测下一时刻槽$\hat{\bar{s}}_{t+1}$，并将$\bar{z}_t$求和后经奖励头预测$\hat{r}_t$。注意力掩码设计为：槽可关注同块内所有槽及历史槽与动作，动作可关注自身及所有历史/当前槽。
    3. **物体因果注意力（Object-Causal Attention）**：借鉴STICA，对每个槽学习因果分数$\alpha_t^k \in [0,1]$，表示该槽对策略/价值预测的相关性。构造因果图$G$（目标、因果物体、非因果物体三类）和权重矩阵$W_t$，通过$W_t G W_t^\top$调制注意力：
       $$CA_t = \text{Norm}\left( \text{softmax}\left(\frac{Q_t K_t^\top}{\sqrt{d}}\right) \odot W_t G W_t^\top \right) V_t$$
       从而使注意力集中在高因果分数的物体上。
    4. **训练目标**：联合优化状态预测、奖励、策略和价值损失：
       $$L_{\text{COMET}}(\theta) = \mathbb{E}\left[ \sum_{t=0}^{H-1} \left( \beta_s \frac{1}{n}\sum_{i=1}^n \|\hat{s}_{t+1}^i - s_{t+1}^i\|_2^2 + \beta_r CE(\hat{r}_t, r_t) + \beta_p CE(\pi_t, p_t) + \beta_v CE(\hat{v}_t, v_t) \right) \right]$$
       其中$p_t$由MCTS的访问计数归一化得到，$v_t$和$r_t$为软目标。

## 7. 优点

- **方法创新**：
    - 提出**动作-槽融合机制**，将动作与每个槽独立拼接并通过共享MLP和Transformer处理，缓解了从单一动作嵌入压缩多槽信息的瓶颈。
    - 将**物体因果注意力**引入MuZero框架的策略/价值头，使决策聚焦于任务相关物体，提升可解释性。
    - 结合**冻结的物体中心编码器**与**端到端训练的世界模型**，复用无监督表示，减少RL阶段对标注的依赖。
- **实验设计**：
    - 使用**平均归一化分数**统一跨任务性能，便于整体评估。
    - 在多样的环境（物体推理、机器人操作、FPS游戏）上验证，覆盖离散/连续动作、稀疏/稠密奖励。
    - 提供了丰富的可视化（轨迹预测、因果分数、注意力图），直观展示模型行为。

## 8. 不足与局限

- **实验局限**：
    - **缺乏消融实验**：无法区分动作-槽融合、因果注意力、Transformer骨干各自贡献。
    - **编码器依赖**：仅使用SLATE、DINOSAUR、Slot Contrast三种，且部分预训练、部分在随机策略数据上训练；未测试更先进的物体中心模型（如SAVi++、STEVE）。
    - **对比不完全**：SOLD仅在连续任务上比较；未与STICA（原文引用但未作为基线）直接对比。
    - **评估仅关注早期训练**：未报告最终收敛性能或更长时间尺度的样本效率。
- **方法限制**：
    - **物体中心编码器不可靠**：在复杂场景（遮挡、模糊边界）下分割质量差，限制了任务上限（如Block Lifting）。
    - **Transformer二次复杂度**：随着槽数增加，计算成本急剧上升，难以扩展到大规模多物体环境。
    - **因果注意力限于策略/价值**：未将因果结构应用于转移预测，可能丢失物体交互的因果链。
- **应用限制**：当前在模拟环境中验证，未见真实机器人或开放式任务实验。
