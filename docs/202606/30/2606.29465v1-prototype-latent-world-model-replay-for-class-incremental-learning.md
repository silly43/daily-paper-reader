## 摘要
类增量学习要求模型在学习新类的同时保持对旧类的决策区域。当原始旧样本不再可用时，这变得困难。我们提出原型潜在世界模型重放，一种无需记忆的框架，将旧类存储为稳定隐藏状态上的分布，而非图像。冻结的ImageNet预训练编码器将每张图像映射到潜在状态空间。在此空间中，每个类由若干个以原型为中心的分布总结，这些分布具有类特定的方差。当新类到来时，模型从该原型世界模型中采样旧的潜在状态。然后，它使用采样的旧状态和真实的新类特征训练轻量级适配器和分类器。我们还在适配器空间中添加监督对比项，以促进类内紧凑性和旧-新类分离。在Split CIFAR-100上，我们的方法在Inc5、Inc10和Inc20下相比微调有所改进，且无需存储原始样本。完整的Ours-LWM+Con模型在Inc5、Inc10和Inc20中分别将LastAcc从4.55%提升至31.64%，从9.06%提升至37.06%，以及从16.96%提升至43.10%。它还在AvgAcc上分别达到了45.86%、52.19%和56.18%。消融和保留分析表明，稳定的潜在状态重放是性能提升的主要来源。对比分离进一步优化了旧-新类的几何结构。这些结果表明，原型潜在记忆保留了可重用的类状态分布，而不仅仅是拟合当前的分类器。

## Abstract
Class-incremental learning requires a model to learn new classes while preserving decision regions for old ones. This is difficult when raw old samples are no longer available. We propose Prototype Latent World Model Replay, a memory-free framework that stores old classes as distributions over stable hidden states rather than as images. A frozen ImageNet-pretrained encoder maps each image into a latent state space. In this space, each class is summarized by several prototype-centered distributions with class-specific variances. When new classes arrive, the model samples old latent states from this prototype world model. It then trains a lightweight adapter and classifier using both sampled old states and real new-class features. We also add a supervised contrastive term in the adapter space to promote intra-class compactness and old-new class separation. On Split CIFAR-100, our method improves over fine-tuning under Inc5, Inc10, and Inc20 without storing raw exemplars. The full Ours-LWM+Con model raises LastAcc from 4.55% to 31.64%, from 9.06% to 37.06%, and from 16.96% to 43.10% in Inc5, Inc10, and Inc20, respectively. It also achieves AvgAcc of 45.86%, 52.19%, and 56.18%. Ablation and retention analyses show that stable latent-state replay is the main source of the gain. Contrastive separation further refines the old-new geometry. These results suggest that prototype latent memory preserves reusable class-state distributions, rather than only fitting the current classifier.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：类增量学习（Class‑Incremental Learning, CIL）要求模型按顺序学习新类别，同时保持对已学旧类别的识别能力。由于旧类原始样本在后续阶段不可用，标准神经网络在仅优化新类数据时会发生**灾难性遗忘**：旧类决策区域被覆盖或漂移，导致旧类准确率急剧下降。
- **现有方法的局限**：
  - 正则化方法（如EWC）不直接保留旧类分布；
  - 基于样本回放的方法（如iCaRL）需要存储原始图像，受内存和隐私限制；
  - 生成式回放（如GAN）需要训练像素级生成器，成本高且不稳定；
  - 蒸馏方法依赖先前模型，但表示层仍可能漂移。
- **本文动机**：能否在不存储或生成原始图像的前提下，通过**稳定潜在状态空间中的类条件分布**来保留旧类知识？受世界模型启发，将记忆从图像样本转移到**可重用的隐藏状态分布**上。

## 2. 方法论：核心思想、关键技术细节

### 2.1 整体框架

- 将学习系统分解为两个空间：
  - **稳定潜在状态空间 $\mathcal{H}$**：由冻结的 ImageNet 预训练编码器 $E$ 产生，提供固定的语义坐标系。
  - **任务自适应分类空间 $\mathcal{Z}$**：由可训练的轻量适配器 $A$ 和分类器 $G$ 组成，在 $\mathcal{H}$ 的基础上进行任务特定变换和分类。
- **关键原则**：
  1. 编码器 $E$ 冻结，确保存储的旧类分布在语义上不漂移；
  2. 旧类知识以 **多原型高斯分布** 形式存储，而非单个特征模板；
  3. 新任务训练时，从旧类分布中采样潜在状态进行回放，同时使用监督对比损失改善旧‑新类的几何分离。

### 2.2 原型潜在世界记忆

- 每个旧类 $c$ 的样本经过 $E$ 得到潜在状态集合 $H_c$。
- 使用 **K‑means 聚类**将 $H_c$ 分成 $K$ 个组，每组计算均值和方差：
  $$
  \mu_{c,k} = \frac{1}{|I_{c,k}|}\sum_{i\in I_{c,k}} h_i,\quad \sigma_{c,k}^2 = \frac{1}{|I_{c,k}|}\sum_{i\in I_{c,k}} (h_i - \mu_{c,k}) \odot (h_i - \mu_{c,k})
  $$
- 类 $c$ 的记忆为 $M_c = \{(\mu_{c,k},\sigma_{c,k}^2)\}_{k=1}^K$，由此定义的类条件分布为：
  $$
  p(h|c) = \frac{1}{K}\sum_{k=1}^{K} \mathcal{N}(h; \mu_{c,k}, \text{diag}(\sigma_{c,k}^2))
  $$

### 2.3 潜在世界模型回放

- 在新任务 $t>1$ 时，从 $p(h|c)$ 采样旧潜在状态 $\tilde{h}_{\text{old}}$，直接输入适配器和分类器：
  $$
  \tilde{z}_{\text{old}} = A(\tilde{h}_{\text{old}}),\quad \tilde{o}_{\text{old}} = G(\tilde{z}_{\text{old}})
  $$
- 回放损失：$\mathcal{L}_{\text{replay}} = \text{CE}(\tilde{o}_{\text{old}}, y_{\text{old}})$，以类平衡方式采样。

### 2.4 新类学习与监督对比约束

- 新类样本正常前向传播：$h_{\text{new}} = E(x_{\text{new}})$，$z_{\text{new}} = A(h_{\text{new}})$，$o_{\text{new}} = G(z_{\text{new}})$，损失 $\mathcal{L}_{\text{new}} = \text{CE}(o_{\text{new}}, y_{\text{new}})$。
- 为减少旧‑新类在适配空间 $\mathcal{Z}$ 中的重叠，引入**监督对比损失**：将当前batch中的真实新类特征和采样旧特征混合，拉近同类、推开异类。
- 总损失：$\mathcal{L} = \mathcal{L}_{\text{new}} + \lambda_r \mathcal{L}_{\text{replay}} + \lambda_c \mathcal{L}_{\text{con}}$。

### 2.5 训练流程

1. 冻结编码器 $E$（ImageNet 预训练 ResNet‑18）。
2. 第一个任务仅用 $\mathcal{L}_{\text{new}}$ 训练 $A$ 和 $G$，然后为该任务每类聚类并存储原型。
3. 后续任务：每个mini-batch混合真实新样本和采样旧状态，优化总损失。
4. 任务结束后，为新类构建原型记忆并加入世界记忆。

## 6. 主要结论与发现

- **稳定潜在状态回放是性能提升的主要来源**：引入冻结预训练编码器 + 回放，使 LastAcc 从 4.55% 飙升至 31.65%（Inc5），远超过无稳定记忆的微调。

- **方法本质**：将遗忘问题转化为“在新类适应过程中保持旧类潜在状态分布”的问题，而非仅拟合当前分类器。

## 7. 优点

1. **无需存储原始图像**：仅存储原型均值和方差（几KB/类），内存友好且规避隐私风险。
2. **利用预训练模型冻结**：稳定潜在空间避免了表示漂移，使旧类分布长期有效。
3. **多原型建模**：通过K-means聚类捕捉类内多模态，比单原型更精确地描述类分布。
4. **适配器+分类器轻量更新**：冻结编码器只更新小参数，训练高效。
5. **几何正则化**：监督对比损失明确分离旧‑新类特征，减少干扰。
6. **全面的分析**：任务保留矩阵、t‑SNE可视化直观验证了世界记忆的可重用性。

## 8. 不足与局限

1. **依赖预训练编码器质量**：若编码器欠佳（如在域差异大的数据上），潜在空间可能无法有效分离语义，导致原型重叠。
2. **原型建模简单**：采用各向同性对角高斯分布和K-means，可能不足以表达复杂流形；未来可考虑使用归一化流、扩散模型等更灵活的密度估计。
3. **实验覆盖面有限**：只在CIFAR‑100上评估，缺少在大规模数据集（如ImageNet‑100、CUB‑200）或域迁移场景下的验证，方法的泛化能力待确认。
