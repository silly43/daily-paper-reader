## 摘要
我们研究以动作条件的世界建模作为一种可扩展的方式，为机器人学习学习可迁移的动力学先验。通过预训练一个模型来预测动作如何驱动视觉场景演变，由此产生的世界模型捕获了超越外观级别视频生成的可复用交互动力学。具体而言，我们在具有真实动作标注的大规模机器人操作数据上预训练了一个多视图交互基础扩散世界模型A2World。我们从两个互补的角度验证了所学习的动力学先验。首先，我们将A2World适配为任务或场景专用的真实世界模拟器A2World-sim，其长程推演通过用世界模型推演替换真实机器人推演，支持基于模拟器的策略评估和可扩展的假设分析。其次，从相同的预训练权重出发，我们将A2World适配为视频-动作联合预测模型A2World-policy，该模型在视觉和指令条件下预测动作。在模拟基准测试和真实机器人设置上的实验表明，以动作条件的世界模型预训练产生了可迁移的动力学先验，这对以模拟器为中心和以策略为中心的机器人学习都有益处。

## Abstract
We study action-conditioned world modeling as a scalable way to learn transferable dynamics priors for robot learning. By pretraining a model to predict how actions drive visual scene evolution, the resulting world model captures reusable interaction dynamics beyond appearance-level video generation. Concretely, we pretrain a multi-view interactive base diffusion world model, A2World, on large-scale robot manipulation data with real action annotations. We validate the learned dynamics priors from two complementary perspectives. First, we adapt A2World into a task- or scene-specialized real-world simulator, A2World-sim, whose long-horizon rollouts support simulator-based policy evaluation and scalable what-if analysis by replacing real-robot rollouts with world model rollouts. Second, starting from the same pretrained weights, we adapt A2World into a video-action joint prediction model, A2World-policy, that predicts actions under visual and instruction conditioning. Experiments across simulation benchmarks and real-robot settings demonstrate that action-conditioned world model pretraining yields transferable dynamics priors that benefit both simulator-centric and policy-centric robot learning.

- **整体含义**：本文提出**动作条件的世界建模**（action-conditioned world modeling）作为一种可扩展的学习可迁移动力学先验的方法。直觉上，动作提供了操作中场景演变的因果监督：尽管物体、场景、视角在各数据集间变化，但交互规则（如接触、抓取、推、释放）是由动作如何引起状态变化决定的。通过预训练模型**基于初始帧和未来动作预测未来视频**，迫使模型编码可控的、以动作为基础的动力学，从而获得可复用的交互先验，同时有益于**模拟器中心**（用作低成本策略评估）和**策略中心**（用作指令条件下的控制策略）的机器人学习。

## 2. 方法论：核心思想、关键技术细节、算法流程

- **核心思想**：在多样化的大规模机器人操作数据上预训练一个多视角扩散世界模型（A2World），该模型以初始帧和未来动作序列为条件，生成未来的多视角视频。预训练后，同一权重可以分别微调为两种变体：
  - **A2World-sim**：长程自回归模拟器，用于策略评估。
  - **A2World-policy**：视频-动作联合预测模型，作为指令条件下的机器人策略。

- **关键技术细节**：
  - **A2World (基础世界模型)**：
    - 条件化：动作编码由 MLP 映射为嵌入，加入扩散时间步嵌入，通过自适应层归一化（AdaLN）调制每个 DiT 块。
    - 多视角生成：将 V 个视角拼接在时间维度上，输入为 $(B, C, V \cdot T, H, W)$，使用可学习的视角嵌入 $\epsilon_{\text{view}}(v)$ 标识相机，并在 DiT 块中插入跨视角注意力（cross-view attention）以保持一致性。
    - 损失函数：EDM 去噪分数匹配，$\mathcal{L}_{\text{A2World}}(\sigma) = \mathbb{E}_{z,n} \left[ \| \text{A2World}(z+n; \sigma, c=0, a) - z \|_2^2 \right]$。
  - **A2World-sim**：
    - 历史注入：采用**姿态引导的历史采样**（算法1），基于相对动作的弧长均匀选择关键历史帧，以固定预算覆盖运动轨迹。历史帧经分词后作为交叉注意力的条件，并额外在自注意力中拼接 K/V 记忆。
    - 自回归生成：逐块预测未来帧，并采用**Self-forcing**训练策略（用自身生成的帧作为条件），提高长程稳定性。
  - **A2World-policy**：
    - 联合视频-动作扩散：对视频潜变量和动作潜变量独立加噪，共享基础噪声水平 $\sigma_{\text{base}}$，但按模态缩放：$\sigma_v = m_v \sigma_{\text{base}}, \sigma_a = m_a \sigma_{\text{base}}$。
    - MoE-like 结构：每个 DiT 块内，视频 token 和动作 token 共享一个自注意力模块（交互），但保留模态特定的 AdaLN 和 MLP 分支（类似于专家混合）。
    - 目标函数：加权联合去噪目标，$\mathcal{L}_{\text{A2World-policy}} = \mathbb{E}[ w(\sigma_v)\|\hat{z}_v - z_v\|_2^2 + \lambda_a w(\sigma_a)\|\hat{z}_a - z_a\|_2^2 ]$。
    - 推理时，对视频和动作分别使用分类器无指导的引导（CFG），可设置不同的引导标度。
  - **数据统一化**：将不同数据集的动作统一为共享的双臂格式（每臂7维：末端执行器姿态+夹爪状态），单臂机器人缺失的臂补零。

## 6. 主要结论与发现

- **动作条件预训练优于文本条件预训练**：在两种下游任务（模拟器和策略）上，基于动作的视频预训练（A-pre）相比基于文本的视频预训练（T-pre）或直接使用通用视频模型（C-init）带来更稳定的性能提升。
- **可迁移性**：同一份预训练权重可以同时受益于模拟器评估（A2World-sim）和策略学习（A2World-policy），无需专门为各下游设计不同的预训练目标。
- **模拟器一致性**：A2World-sim 的 rollout 成功率与真实世界的成功率高度相关（Spearman ρ=0.916，R²=0.93），可作为可靠的策略评估环境。
- **策略性能**：A2World-policy 在 LIBERO 上达到 98.6% 平均成功率，超越所有基线；在 OOD 泛化上也取得领先。真实机器人上显著优于同类策略，尤其长程和接触密集型任务。
- **视频-动作联合训练的正耦合**：视频预测误差与动作预测误差在训练过程中呈正相关，联合训练优于冻结视频分支。

## 7. 优点

- **新颖的预训练范式**：明确提出**动作条件世界模型预训练**作为可迁移动力学先验的通用方法，统一了模拟器和策略两类下游。
- **大规模多样性数据**：整合 20+ 种体现、2.1M+ 轨迹，覆盖广泛任务和环境，增强泛化性。
- **高效迁移**：A2World-policy 仅需在预训练模型基础上添加轻量级动作分支和跨注意力，无需额外的动作预训练阶段。
- **姿态引导历史采样**：利用动作轨迹的弧长均匀选择关键帧，在固定预算下有效保留运动信息，提升长程 rollout 质量。
- **充分的实验验证**：同时考察模拟器忠实度、策略成功率、OOD 泛化，并进行了消融、耦合分析，证实力。
- **开源与可复现性**：提供代码仓库，公开预训练数据集信息。

## 8. 不足与局限

- **实验覆盖的局限**：
  - 真实机器人实验只涉及一个定制的双臂平台（Flexiv），场景数量有限（5个任务），缺乏更广泛平台的验证。
  - 模拟器评估仅基于 LIBERO 和 RoboNet，未在更复杂环境（如厨房、灵巧手任务）上测试。
  - OOD 实验仅针对视觉背景、语言、光照等，未测试动态物体分布或因果干扰（如外力干扰）。
- **模型规模与计算开销**：A2World 系列参数量达 2.5B–3.0B，预训练和微调均需大量 GPU（64/32块 H200），对中小实验室可及性有限。
- **动作空间限制**：动作统一为 7 维双臂格式（夹爪状态+末端位姿），可能不适合高自由度灵巧手或非固定基座机器人，且零填充策略可能导致学习偏差。
- **长程 rollout 稳定性**：虽然采用了 Self-forcing 训练，但在极长序列或复杂接触中仍可能出现漂移，论文未报告超长（>200 帧）的定量评估。
- **评估指标局限**：模拟器质量主要关注帧级相似度和光流，缺乏任务成功率对齐（“模拟器是否真的可以用作策略验证”仅用 8 个点验证）。
- **潜在偏差风险**：预训练数据偏向公开高质量数据集（如 AgiBot、DROID），可能隐含特定操作习惯或场景分布，在极端分布偏移下的表现未知。
