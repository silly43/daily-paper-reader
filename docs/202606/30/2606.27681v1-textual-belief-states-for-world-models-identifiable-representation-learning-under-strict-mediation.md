## 摘要
在部分可观测环境中，世界模型依赖于总结交互历史的潜在表示，但在许多现代基于LLM的架构中，由于历史旁路（history bypass）的存在，预测性能无法反映表示质量，导致潜在状态不可辨识。严格的潜在状态中介（strict latent state mediation）要求预测仅依赖于潜在状态和动作，这是解决该问题的经典原则，但在基于文本的环境中实施这一原则仍是一个开放挑战：文本潜在状态是离散且不可微的，无法进行变分训练，而具有强表达能力的LLM解码器容易忽略瓶颈。我们展示了如何在文本领域实现严格中介。我们形式化了其必要性，证明严格中介使表示质量具有经验可测试性，而历史泄露架构则破坏了这种联系。接着，我们引入了文本潜在状态，它们是离散、可解释且可变长度的，以及分解式GRPO（fGRPO），一种树结构强化学习方法，在训练过程中强制执行严格中介。在TextWorld和ScienceWorld上的实验表明，该方法在保持单步预测准确性的同时，表示质量提升了高达57%，展开性能提升了98%，且增益随任务复杂度和时间范围增加。

## Abstract
World models in partially observed environments rely on latent representations that summarize interaction history, but in many modern LLM-based architectures predictive performance fails to reflect representation quality due to history bypass, rendering the latent state unidentifiable. Strict latent state mediation, requiring predictions to depend only on the latent state and action, is a classical principle that resolves this, but enforcing it in text-based settings is an open challenge: textual latent states are discrete and non-differentiable, precluding variational training, and expressive LLM decoders readily ignore the bottleneck. We show how to make strict mediation work in the text domain. We formalize why it is necessary, showing that strict mediation makes representation quality empirically testable while history-leaky architectures break this connection. We then introduce textual latent states, which are discrete, interpretable, and variable-length, and factorized GRPO (fGRPO), a tree-structured reinforcement learning method that enforces strict mediation during training. Experiments on TextWorld and ScienceWorld show preserved one-step prediction accuracy alongside up to 57\% gains in representation quality and 98\% improvements in rollout performance, increasing with task complexity and horizon.

## 1. 核心问题与整体含义（研究动机和背景）

大型语言模型（LLM）被广泛应用于构建文字游戏等部分可观测环境的世界模型。然而，现有 LLM 世界模型普遍采用“历史泄露”架构——即使引入了显式的潜在状态，解码器仍可以直接访问完整的交互历史。这种设计导致**历史绕过（history bypass）**：模型可以利用原始历史直接做出准确的预测，而潜在状态可能完全不包含有效信息，变得**不可辨识**。

**核心问题**：预测性能无法反映表示质量，潜在状态缺乏可辨识性，也无法通过预测准确率来诊断表示是否充分。

**本文意义**：作者提出**严格中介（strict mediation）**原则——所有预测信息必须通过潜在状态，禁止历史绕过。该原则在经典 POMDP 信念状态中是标准做法，但在文本领域面临离散、不可微瓶颈训练困难。本文通过**文本潜在状态 + 因子化 GRPO（fGRPO） 强化学习**首次在文本域实现了严格中介，使表示质量变得可测试、可保证，并显著提升了长程 rollout 的稳定性和表示紧凑性。

## 2. 方法论：核心思想、关键技术细节、算法流程

### 2.1 核心思想
- **严格中介**：编码器从历史 $\mathbf{h}_t$ 生成潜在状态 $\hat{s}_t$，之后的状态转移和观测解码**只能基于** $\hat{s}_t$ 和动作 $a_t$，不能回看历史。
- **文本潜在状态**：将潜在状态表示为离散、可解释、可变长度的 JSON 事实列表（例如 `{"predicate": "at", "arguments": ["P", "kitchen"]}`），与 LLM 自然对齐，且易于检查。

### 2.2 模型架构（单一 LLM，三阶段共享参数）
1. **编码（Encoding）**：$\hat{s}_t \sim p_\theta(\cdot \mid \mathbf{h}_t)$
2. **状态转移（Predicting）**：$\hat{s}_{t+1} \sim p_\theta(\cdot \mid \hat{s}_t, a_t)$
3. **解码（Decoding）**：$\hat{o}_{t+1} \sim p_\theta(\cdot \mid \hat{s}_{t+1}, a_t)$

三阶段使用相同的预训练 LLM（如 Qwen 系列），仅通过不同提示区分角色。严格中介要求解码和转移阶段**不访问历史** $\mathbf{h}_t$。

### 2.3 训练方法：因子化 GRPO (fGRPO)
由于文本状态离散不可微，无法使用变分自编码器（VAE）训练。作者将每个阶段的文本生成为**随机策略**，用强化学习优化。

**fGRPO 流程**（见图 1d）：
- 给定一条训练数据 $(\mathbf{h}_t, a_t, o_{t+1})$，构建**树结构 rollout**：
  - 编码阶段采样 **A** 个候选状态 $\hat{s}_t^{(a)}$；
  - 每个 $\hat{s}_t^{(a)}$ 下采样 **B** 个下一状态 $\hat{s}_{t+1}^{(a,b)}$；
  - 每个 $\hat{s}_{t+1}^{(a,b)}$ 下采样 **C** 个观测 $\hat{o}_{t+1}^{(a,b,c)}$。
- 叶子节点的奖励使用**观测事实 F1** 与真实 $o_{t+1}$ 比较，并向上传播（子节点平均奖励作为父节点奖励）。
- 每个层级（编码 / 转移 / 解码）内部计算**组相对优势（group-relative advantage）**，所有层级合并为一个 batch 更新 LLM 参数。

### 2.4 奖励设计
最终奖励 $R$ 综合多项指标：
$$
R = \begin{cases}
R_{\text{obs}} \cdot \gamma_{\text{pen}}, & \text{if } R_{\text{fmt}} = 0 \\
R_{\text{obs}} + \lambda_{\text{dedup}} R_{\text{dedup}} + \lambda_{\text{abl}} R_{\text{abl}} + \lambda_{\text{sup}} R_{\text{sup}}, & \text{if } R_{\text{fmt}} = 1
\end{cases}
$$
- **$R_{\text{obs}}$**：观测事实 F1（主奖励）；
- **$R_{\text{fmt}}$**：状态格式合法性；
- **$R_{\text{sup}}$**：支持奖励，衡量预测观测中的事实是否被下一状态覆盖；
- **$R_{\text{dedup}}$**：去重奖励，惩罚状态中的冗余/矛盾事实（使用 NLI 模型）；
- **$R_{\text{abl}}$**：消融奖励，衡量每个事实去除后是否降低预测准确性，促进紧凑性。

## 3. 实验设计

### 3.1 数据集与环境
- **TextWorld** (Côté et al., 2018)：2726 条轨迹，121054 步，涵盖 261 种游戏配置（房间数、食谱长度等）。
- **ScienceWorld** (Wang et al., 2022)：600 条轨迹，19481 步，30 种任务类型。
- 两种环境均部分可观测，但游戏引擎可提供完整符号状态用于评估（对模型不可见）。

### 3.2 基线方法（对应三种架构）
| 基线 | 描述 |
|------|------|
| **Stateless** | 无显式状态，直接从历史 + 动作预测观测（SFT 训练） |
| **LeakyState** | 引入文本潜在状态，但解码仍允许访问历史（标准 GRPO 训练） |
| **StrictState-Emb** | 连续嵌入潜在状态，使用变分目标（类似 Dreamer），同样强制严格中介 |

### 3.3 评估指标
- **观测 F1 (obs.F1)**：预测观测与真实观测之间事实集合的 F1。
- **状态 F1 (state.F1)**：预测潜在状态与真实世界状态中用于渲染观测的事实子集之间的 F1。
- **压缩比 (CR)**：历史长度 / 潜在状态长度。
- **Rollout 稳定性**：不同预测地平线 $H$ 下的状态 F1。

## 6. 主要结论与发现

1. **严格中介不牺牲单步预测准确性**：StrictState-Text 的 obs.F1 与 LeakyState、Stateless 持平（表 1）。
2. **表示质量显著提升**：state.F1 最高提升 **57%**（ScienceWorld 4B，高难度 M≥30），且增益随难度增大而增大。
3. **泄露模型预测好但状态差**：验证命题2——LeakyState 可达到高 obs.F1，但状态 F1 远低于 StrictState。
4. **超长 rollout 稳定性优势**：state.F1 在 H=9 时提升最高达 **98%**（TextWorld 4B），且差距随地平线增长而扩大（支持命题3）。
5. **奖励组件重要性**：支持奖励 $R_{\text{sup}}$ 对长程性能最关键；去重和消融奖励提升压缩比而不损害预测准确性。
6. **更好的压缩校准**：StrictState 的压缩比与参考复杂度相关性更高（Pearson $\rho=0.62$ vs. 0.18），避免过度压缩。

## 8. 不足与局限

- **环境局限性**：仅使用两个合成文本环境（TextWorld、ScienceWorld），可能不反映真实世界的复杂性和噪声。结论向现实场景泛化的能力需进一步验证。
- **任务覆盖不足**：评估仅限表示质量（预测准确率和状态 F1），未涉及下游规划、任务完成率或智能体性能提升，无法直接证明严格中介对实际决策的价值。
- **编码器不可增量**：严格中介要求单次编码器一次性从整个历史生成状态，错过中间信息不可恢复；没有递归或增量更新机制。
- **辅助奖励依赖结构化抽取**：事实抽取、NLI 模型等依赖领域知识，在非结构化或高度自由文本环境下需要替代方案（如学习到的相似度或 LLM 评判）。
- **训练成本较高**：fGRPO 的树结构导致生成和计算开销大（4B 模型每千步 90 GPU 小时），可能限制大规模或实时应用。
- **收敛性假定**：误差传播的有界性依赖于转移函数本身是压缩映射（$L_S<1$），但文中未验证该条件在实际训练中是否总被满足。
- **单任务离线数据**：所有训练基于离线数据集，未涉及在线交互或分布外场景，可能引发分布漂移问题。
