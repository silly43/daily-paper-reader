## 摘要
世界模型为长周期LLM智能体提供了一种原则性的方式来赋予其预见能力：在执行前预测行动后果。然而，不可靠的预见可能被忽略、误用，甚至损害下游决策。本文介绍了WorldEvolver，一个自我进化的世界模型框架，它在保持下游智能体和所有模型参数冻结的同时，修改其部署时的上下文。WorldEvolver集成了三个模块：(i) 情景记忆，通过基于检索的模拟利用真实动作转换；(ii) 语义记忆，从预测-观测不匹配中提取持久的启发式规则；(iii) 选择性预见，在将低置信度预测融入智能体推理上下文之前进行过滤。我们在ALFWorld和ScienceWorld上评估WorldEvolver，在Word2World上测量世界模型预测准确率，在AgentBoard上测量下游智能体成功率。大量实验表明，WorldEvolver在三个骨干网络上取得了最高的预测准确率，并在下游智能体成功率上领先其他世界模型基线，表明测试时记忆修订增强了预测保真度和规划性能。

## Abstract
World models offer a principled way to equip long-horizon LLM agents with foresight: predictions of action consequences before execution. However, unreliable foresight can be ignored, misused, or even degrade downstream decision-making. In this paper, we introduce WorldEvolver, a self-evolving world model framework that revises its deployment-time context while keeping the downstream agent and all model parameters frozen. WorldEvolver integrates three modules: (i) Episodic Memory, which exploits real action transitions through retrieval-based simulation; (ii) Semantic Memory, which extracts persistent heuristic rules from prediction-observation mismatches; and (iii) Selective Foresight, which filters low-confidence predictions before integrating them into agent reasoning context. We evaluate WorldEvolver on ALFWorld and ScienceWorld, measuring world model prediction accuracy on Word2World and downstream agent success rate on AgentBoard. Extensive experiments show that WorldEvolver achieves the highest prediction accuracy across three backbones and leads other world model baselines on downstream agent success rate, demonstrating that test-time memory revision enhances both predictive fidelity and planning performance.

- **研究动机**：传统的冻结世界模型（图1a）会因分布偏移而预测失准；而通过梯度更新吸收每个不匹配（图1b）在LLM规模下计算成本高，容易导致过度编辑或灾难性遗忘。因此，需要一种**自我进化**的世界模型（图1c），能够在线检测预测与观测之间的差异并自适应调整，而无需更新模型参数。
- **整体含义**：论文提出**WorldEvolver**框架，通过**修改部署时的外部上下文**（而非更新模型权重），来提升世界模型的预测保真度和下游智能体的规划成功率。这为长周期LLM智能体提供了一种低成本、可审计的在线适应方案。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
保持世界模型$W_\theta$和智能体策略$\pi_\theta$的全部参数**冻结**，仅在推断时通过一个**非参数记忆存储**$M_t = (M_t^E, M_t^S)$来提供上下文证据。记忆包含：
- **情景记忆（Episodic Memory, $M^E$）**：存储已执行的真实转换 $(o_i, a_i, o_{i+1})$，通过检索最相似的过去动作来指导当前预测。
- **语义记忆（Semantic Memory, $M^S$）**：从预测-观测不匹配中提取持久的启发式规则（如“检查物体不会移动它”），表示为规则-证据分数对。
- **选择性预见（Selective Foresight）**：基于预测置信度（几何平均token概率）过滤低置信度的预测，只有$q_t \ge \tau$时才会将预测暴露给智能体。

### 2.2 关键技术细节
- **情景记忆检索**：给定候选动作$a_t$，从$M_t^E$中检索$k_{ME}$个最相似（Jaccard相似度基于动作词集）的过去转换，作为上下文提供。
- **语义记忆提取**：利用因子化状态表示（将观测文本转化为$(subject, predicate, object)$三元组），比较预测三元组$\hat{z}_{t+1}$和实际三元组$z_{t+1}$。当不匹配时，LLM批评器生成候选规则$r_i$，并分配初始证据分数$e_i=1$，后续根据是否支持/矛盾更新分数，仅保留$e_i>0$的规则。
- **选择性置信度**：$$q_t = \exp\left(\frac{1}{n}\sum_{i=1}^n \log p_\theta(y_i \mid y_{<i}, s_t, a_t, M_t)\right)$$，阈值$\tau$从校准曲线中选择（见表3）。
- **算法流程（Algorithm 1）**：
  1. 采样草稿动作$a_t^{(0)} \sim \pi_\theta(\cdot | s_t)$。
  2. 检索情景记忆$M_t^E$。
  3. 世界模型预测$\hat{o}_{t+1}$及置信度$q_t$。
  4. 选择性过滤：若$q_t \ge \tau$，则将预测传递给智能体；否则不提供预见。
  5. 智能体基于$s_t$和（可选的）$F_t$采样最终执行动作$a_t = a_t^{(1)}$。
  6. 若$a_t$与$a_t^{(0)}$不同，用$a_t$重新查询世界模型以获得对齐的预测。
  7. 执行$a_t$，获取真实观测$o_{t+1}$，更新情景记忆（追加转换）和语义记忆（更新规则）。

## 3. 实验设计

### 3.1 数据集和基准
- **世界模型预测**：使用**Word2World**基准（Li et al., 2025b），它提供了ALFWorld和ScienceWorld的转换数据集。测试集包含每个环境195条轨迹。
- **智能体规划**：使用**AgentBoard**（Ma et al., 2024），包括134个ALFWorld任务和90个ScienceWorld任务。每个配置运行$L=5$次试验，每次最多30步。

### 3.2 对比方法
- **Zero-Shot**：标准零样本预测（无检索或记忆）。
- **RAWM-ϕ**（Yang et al., 2025）：离线检索基线，使用余弦相似度从固定库中检索最相似的top-1转换（仅检索编码器，无PPO训练）。
- **ITP-I**（Liu et al., 2026）：训练自由版本的Imagine-then-Plan，预测时固定为1步想象，规划时可选择多步。
- **WorldEvolver的消融变体**：
  - w/o $M^E$：移除情景记忆。
  - w/o $M^S$：移除语义记忆。
  - w/o $F_t$：移除选择性预见（即始终传递预测）。
  - w/ $F_t$：完整方法。

### 3.3 智能体类型和骨干模型
- **智能体策略**：ReAct 和 ReflAct（后者添加目标状态反思）。
- **骨干模型**：
  - 世界模型预测：Gemma-4-26B-A4B、Qwen3.5-9B、Gemma-4-31B。
  - 智能体规划：Gemma-4-26B-A4B 和 GPT-5.4-mini。

### 3.4 评估指标
- **世界模型预测**：Exact Match（标准化字符串匹配）、Token F1（token级别词重叠）、Cosine Similarity（Qwen3-Embedding-8B嵌入的余弦相似度）。
- **智能体规划**：Success Rate（任务完成率），取best-of-5。

## 6. 主要结论与发现

1. **世界模型预测准确性**：WorldEvolver在ALFWorld和ScienceWorld上，使用Gemma-4-26B-A4B、Qwen3.5-9B、Gemma-4-31B三个骨干，在所有指标（Exact Match、Token F1、Cosine Similarity）上均达到最高。
2. **智能体规划成功率**：WorldEvolver w/ Ft在所有8个设置中均优于其他世界模型基线（RAWM-ϕ、ITP-I），并在大多数设置中超过无世界模型基线。选择性预见（Ft）进一步提升了成功率。
3. **情景记忆是主导因素**：增大kME（从1到5）带来显著提升（+16.8/23.5 Exact Match），而语义批次大小kMS的影响较小。
4. **在线持续学习有效**：随着试验次数增加，WorldEvolver性能逐渐提升（图4），尤其是ScienceWorld + Gemma-4-26B-A4B组合，显示部署时间记忆积累的优势。
5. **选择性预见关键**：对于较弱骨干（Gemma系列），置信度门控可以显著降低不可靠预测的负面影响；对于强骨干（GPT-5.4-mini），改进相对较小但仍有用。
6. **任务类型影响**：世界模型远见对“动作敏感型”任务（如PICK2、Lifespan）提升明显，而对“信息量大但动作变化小的任务”（如State Change）提升有限。

## 7. 优点（亮点）

- **创新性**：首次提出**测试时通过外部记忆而非参数更新**来进化世界模型，避免了LLM在线梯度更新的高成本和副作用。
- **模块化设计**：情景记忆（利用具体经验）、语义记忆（抽象规则）和选择性过滤（判别可靠性）三者互补，可独立消融。
- **轻量级**：仅需检索和提示修改，与骨干模型无关，适用于各种LLM。
- **广泛消融**：包含多个骨干、智能体类型、记忆超参数、难度分解以及置信度校准分析，实验详实。
- **可解释性**：语义记忆生成可读规则，支持审计和调试。
- **实际有效性**：在多个长周期文本环境中显示出比现有离线方法更优的预测和规划性能。

## 8. 不足与局限

- **实验范围有限**：
  - 仅评估了ALFWorld和ScienceWorld两个文本环境，未涵盖网页导航、代码生成、机器人、多模态交互等更广泛领域。
  - 环境都是相对受控的文本模拟器，真实世界复杂性可能不足。
- **置信度估计依赖**：
  - 需要token级概率，这在某些封闭API中不可用（如GPT-5.4-mini可能不提供），此时需要替代方法（自一致性、学习校准等）。
  - 置信度与准确度之间的关联（图11）虽然支持筛选，但在不同环境和骨干下可能变化。
- **语义记忆的通用性**：
  - 规则提取依赖因子化状态表示（三元组），这需要针对特定环境设计映射函数$g$；对于非结构化观测可能不适用。
  - 规则可能过于特定或重复，需要证据分数管理，但在极端稀疏数据下难以积累可靠规则。
- **计算开销**：尽管比ITP-I更高效，但相较于Zero-Shot仍有约40%的额外运行时，在延迟敏感场景下可能受限。
- **动态调整未涉及**：阈值$\tau$是超参数（表3），但论文未提出自动化调参方法。
- **泛化性分析不足**：未测试世界模型在不同领域间的迁移（如从ALFWorld到ScienceWorld的规则重用）。
- **潜在偏差**：所有实验基于特定骨干（Gemma、Qwen、GPT），不同模型家族的分布差异可能导致结论偏移；AgentBoard的任务难度分布可能不具代表性。
