## 摘要
连续环境中的视觉与语言导航（VLN）要求智能体在自我中心观测中理解指令，同时跨长动作序列保持空间理解。近期导航基础模型通过扩展视觉-语言模型取得了显著进展，但它们通常主要将导航学习为直接动作生成，而未显式建模世界状态或预测其未来演化。我们提出FutureNav，一种基于VLM的视觉与语言导航统一世界-动作建模框架。具体而言，FutureNav联合编码文本、视觉和空间特征并输入LLM，优化四个目标以同时进行世界和动作建模：用于导航动作预测的动作策略目标、用于建模状态转移的逆动力学和正向动力学目标，以及用于预测未来空间状态的未来生成目标。这种统一架构在保持推理速度的同时，既强化了动作预测又显式建模了世界。大量实验表明，仅使用4B规模的主干网络，FutureNav在多个VLN基准上达到最先进性能，大幅超越先前VLN方法，为未来VLN世界-动作模型铺平了道路。我们将发布代码和模型以支持未来研究。

## Abstract
Vision-and-language navigation (VLN) in continuous environments requires an agent to ground instructions in egocentric observations while maintaining spatial understanding across long action sequences. Recent navigation foundation models have shown strong progress by scaling vision-language models, but they often learn navigation primarily as direct action generation, without explicitly modeling world states or predicting their future evolution. We introduce FutureNav, a VLM-based unified world-action modeling framework for vision-and-language navigation. Specifically, FutureNav jointly encodes text, visual, and spatial features and feeds them into the LLM, and optimizes four objectives for simultaneous world and action modeling: an action policy objective for navigation action prediction, inverse and forward dynamics objectives for modeling state transitions, and a future generation objective for predicting future spatial states. This unified architecture strengthens action prediction while explicitly modeling the world, without sacrificing inference speed. Extensive experiments show that, with only a 4B-scale backbone, FutureNav achieves state-of-the-art performance on multiple VLN benchmarks and substantially outperforms prior VLN methods, paving the way toward future world-action models for VLN. We will release the code and models to support future research.

## 2. 方法论

### 核心思想

- FutureNav 基于 VLM 骨干网络，同时编码文本指令、视觉观测和显式空间特征，并将它们融合后输入 LLM。在训练时，模型同时优化**四个互补目标**：
  1. **动作策略**（Action Policy）：直接预测下一步导航动作（STOP / MOVE_FORWARD / TURN_LEFT / TURN_RIGHT）。
  2. **逆动态**（Inverse Dynamics）：从前后观测的隐藏状态差异推断出中间执行的动作。
  3. **前向动态**（Forward Dynamics）：给定当前观测隐藏状态和真实动作隐藏状态（教师强制），预测下一观测的空间特征。
  4. **未来生成**（Future Generation）：不借助动作信息，仅从当前观测隐藏状态预测下一观测的空间特征（动作无偏先验）。
- **推理时**：仅使用动作策略分支进行直接动作解码，无额外计算开销。

### 关键技术细节

1. **输入编码**：
   - 文本与视觉：使用 VLM 的 tokenizer 和视觉编码器处理指令和观测序列，得到文本 token 和视觉 token 嵌入 $E_q^t$。
   - **空间编码**：利用冻结的 **VGGT** 空间编码器从每帧观测中提取空间感知特征 $G_t \in \mathbb{R}^{N_g \times 2048}$，经过分组、RMS 归一化和两层 MLP 投影到 VLM 隐藏空间 $E_g^t$。
   - **残差融合**：最终视觉嵌入为 $E_v^t = E_q^t + \alpha E_g^t$，其中 $\alpha = 0.2$。这使得 VLM 能够同时访问语义和空间信息。

2. **世界-动作建模头**（均为训练时可训练的轻量 MLP）：
   - **动作策略**：标准自回归解码，损失为交叉熵 $L_{\text{policy}}$。
   - **前向动态**：将当前观测隐藏状态 $h_{\text{obs}}^t$ 与动作隐藏状态 $h_{\text{act}}^t$ 拼接，通过 MLP 预测下一观测的池化空间特征 $\hat{z}_{t+1}$，损失为 MSE：
     $$L_{\text{forward}} = \|\hat{z}_{t+1} - z_{t+1}\|_2^2$$
   - **逆动态**：上下文隐藏状态 $h_{\text{ctx}}^t$、前后观测的均值池化隐藏状态及其差分拼接，通过分类头预测动作 $a_t$（4 类），损失为交叉熵。
   - **未来生成**：上下文隐藏状态与当前观测均值池化隐藏状态拼接，预测下一空间特征，损失为 MSE（无需动作输入）。

3. **最终训练目标**：
   $$L = L_{\text{policy}} + \lambda_f L_{\text{forward}} + \lambda_i L_{\text{inverse}} + \lambda_g L_{\text{gen}}$$
   其中权重 $\lambda_f = \lambda_i = \lambda_g = 0.1$。仅优化 VLM 语言部分、投影器和四个头；视觉编码器和空间编码器冻结。

- **性能领先**：仅 4B 参数的 FutureNav 在 R2R-CE 和 RxR-CE 上均达到 SOTA，全面超越 7B/8B 的先前方法（如 JanusVLN、NavFoM）。
